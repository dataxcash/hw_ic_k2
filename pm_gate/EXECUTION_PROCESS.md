# K2 pm_gate — AGENT 执行流程法（EXECUTION PROCESS）

> **地位**：K2 pm_gate 下所有 EDA 求解/判定任务的 AGENT 执行法。依据 = `_shared/docs/LAYOUT_CONSTITUTION.md`
> （宪法）+ `IMPLEMENTATION_LAYER_PHASING.md`（L2 工序）+ `KNOWLEDGE_REUSE_SDD.md`（学习体系）。
> 与宪法冲突以宪法为准；本文件是宪法在"AGENT 会话执行"上的落地程序。
> **效力**：任何 AGENT（含 LLM 主会话）承接任务必须先过本流程；本流程条款由
> EXECUTION_GATES.md（禁令附录）+ 物理强制机制（第 5 章）保障，不靠自觉。
> **版本**：v1.0（2026-09-03，m13 Q2 事故后立法）

---

## 1. 为什么有本法（事故锚）

m13 Q2 求解 session 证明：**文档与门禁代码存在 ≠ 被执行**。AGENT 绕过既有宪法/gate 自创
求解器、暴力迭代（120 布局全败仍试）、在未盘点空间时下"无解"倾向结论、把模型/学习资产
空转。根因不是"不知道规范"，是**没有把规范变成 AGENT 绕不过的物理强制**。本法三件事：
① 流程（该怎么做）② 禁令（不该做什么）③ **物理强制（绕不开）**。

## 2. 执行流程（每任务必走，缺工件禁下一步）

```
【定位闸】任务属哪层(L1/L2/L3)？产出什么冻结物？上游约束包络=哪个已冻结文档？
          裁判标准+裁判权归谁？ —— 答不清 → 上报，禁止开工
   │
【学习闸】提取本问题拓扑特征 → 匹配 kb.sqlite3（KNOWLEDGE_REUSE_SDD，必做不可跳）
          命中 produced=true → 模板=候选主来源（仍须验证）
          命中 produced=false → 仅候选参考
          未命中 → 记录"未覆盖形态"，结论只能到证据级，上报缺口
   │
【生产链 8 步】（宪法第四章，每步一工件，缺工件禁下一步）
  ①测量(BoardParser/板文件/spec→测量记录, 逐条标来源 L0-L2)
  ②约束(每条带出处: SPEC条款/工艺规则/冻结文档 → 约束清单)
  ③计算(容量/净距/预算 纯数学 → 计算书; 放不下=正常结果非失败)
  ④候选(≥2 个自洽方案, 必含案例模板候选 → 候选集含淘汰项)
  ⑤竞标(同套裁判工具打分 → 打分表)
  ⑥裁决(选定+记录理由 → 裁决记录)
  ⑦冻结(写入该层冻结文档 → 约束包络)
  ⑧归档(入库+回写案例库 solves/known_gaps → 学习闭环)
   │
【对抗评审】完整性/一致性/可验证性/物理性(非执行者复核数学闭合)/裁决性 → PASS/FAIL 记录
   │
【回退唯一通道】= 变更单(ECO/ECN)：装不下 → 停机 → 抛 MUS 失败载荷 →
  回对应上层 → 更新冻结文档 → 归档。禁止私下妥协/运行时 fallback。
```

**输入来源分级**：L0 真板文件 > L1 spec/config/模型层 > L2 案例/文档(标注几何前提) >
L3 手工推导/临时脚本(仅证据不背书结论) > **L4 问用户(仅 L0-L3 全缺且属产品决策)**。

## 3. 执行禁令（细则，与 EXECUTION_GATES.md 同源）

1. 禁止暴力迭代：同参数重跑 ≥2 次、单对求解 >5s、失败后改参续跑——一律停转 Plan。
2. 禁止脚本/AGENT 在运行时做设计决策（簇 x/y、布线序、形态、stagger、挪件——全部须冻结）。
3. 禁止未盘点空间就下"无解"结论：无解前必须有空间盘点工件（可用层/区/通道/每 lane 候选路线）。
4. 禁止单一默认模型：候选必须 ≥2 且竞标（"16 线挤一条走廊"式单模型 = 违规建模）。
5. 禁止约束无出处：每条净距/口径必须标来源；0.6 vs 0.38 之类歧义未裁定前不得开跑。
6. 禁止跳层：L1/L2 未冻结不进 L3；本任务(布局可行性)属 L2 物理可行性证据，禁止用 L3
   施工脚本 + 暴力迭代充当 L2 判定。
7. 禁止绕过学习闸：检索案例库是固定环节；未命中 = 未覆盖 = 上报，不是跳过自己发明。
8. 禁止绕开物理强制：冻结物/宪法文件只读，写须走解锁通道（第 5 章）；AGENT 不得 chmod 自解。

## 4. 判定场景（遇到问题对照，处置即条款）

| 现场 | 处置 |
|---|---|
| "找不到解，再试一轮/换个参数" | §3.1 暴力迭代。停。判定缺口→方案级修输入→一次重解 |
| 想不清信号怎么走/障碍怎么绕 | 宪法第八章第 9 条。画草图→找障碍→大白话方案→一次实现；想不清=方案层缺口回 L1/L2 |
| 需要知道层叠/分区/层分配 | L1 来源（板文件/config/模型层），禁止问用户（L4 仅产品决策） |
| "空间够不够" | §3.3 空间盘点工件。盘点没做，无解/有解结论均无效 |
| 案例库没这个形态 | §学习闸未命中 → 未覆盖报告（模型缺口），结论限证据级 |
| 想改宪法/冻结物/流程 | 解锁通道（第 5 章），须用户/架构裁决，禁止自解自改 |

## 5. 物理强制机制（本法不被绕开的保障）

| 机制 | 对象 | 强制方式 | 解锁通道 |
|---|---|---|---|
| OS 写保护(chmod 444/555) | 宪法文档(_shared/docs)、引擎(_shared/eda_core)、知识库(_shared/knowledge)、冻结物(L1/L2 frozen)、真板 k2_v4.kicad_pcb、本法+EXECUTION_GATES | 文件系统级，任何进程(含 bash) 新建/删改=Permission denied（**当前主强制，实测生效**） | `k2/pm_gate/freeze_ctl.sh unlock`（立法/ECN 授权后）→ 完事必须 lock |
| PreToolUse hook | Write/Edit 工具对冻结清单的写 | 已配置 `~/.claude/settings.json` + `~/.opencode/hooks/guard_constitution.py`，但 OhMyOpenCode dev 运行时未加载（配置迁移 ~/.omo/omo.jsonc，挂载点待确认）→ **第二层，启用前不依赖** | 无 |
| Gate 状态绑定 | 任务结论/归档 | 结论只有过 pm_gate 状态机(planned→…→closed)才算数；gate 外产出无效 | task_gate.regress/enter |

**纪律**：AGENT 发现文件只读 → 说明那是法/冻结物 → 走 ECN，**禁止 chmod 自解**（§3.8）。
锁管理用 `k2/pm_gate/freeze_ctl.sh {lock|unlock|status}`（勿手打 chmod 散命令）。
**副作用已知**：冻结区锁死后 git pull/checkout/commit 会 Permission denied —— git 操作前 unlock、后 lock。
