# L1 候选方案 B：U3/U4 靠边对置（电容墙外移）

> 竞标候选 B — 核心思路：把 ReDriver 向左右两侧推开，AC 电容墙移到芯片与连接器之间的**中间走廊**，形成两条独立对称的"信号主干道"。

## 器件分区

- **右区**：J2 SlimSAS x8 @ (133.8, 53.7) 保持
- **中区**：U3 右移至 x≈108（靠 J2）、U4 左移至 x≈80（靠 MCIO），**两芯片不再上下对齐**
- **左区**：J3/J4 @ (59.5, 44.5/62.7) 保持
- **外围**：低速区不变

## 接口朝向

- J2 朝右、J3/J4 朝左不变；信号流左→右不变
- U3 rot=0（J2 侧入口），U4 rot=180（MCIO 侧入口），芯片本体朝向反转使**焊盘朝外**

## 信号流向

- 下行 8 lane：J3 → 左走廊 AC 墙 → U4 → 右走廊 AC 墙 → J2（U4 反向承接）
- 上行 8 lane：J4 → 左走廊 AC 墙 → U3 → 右走廊 AC 墙 → J2
- 关键：**每颗 ReDriver 只服务一路信号方向**，电容墙两侧完全对称

## 电源域划分

- 同候选 A；U3/U4 分开后电源去耦电容可各自贴芯片两侧，不再共享窄空隙

## 电容墙构型

- **双走廊墙**：左走廊（x≈62~78）16 个 AC 电容（J3/J4 侧）；右走廊（x≈110~128）16 个 AC 电容（J2 侧）
- 每走廊内电容**双列交错**（奇数 pin 0.8mm、偶数 pin 2.0~3.0mm 打孔方案自然适配）
- 上下行对称，两路信号各自独占半幅走廊，无跨行交叉

## 走廊预检

- 左走廊 x∈[64.9,88.8] 净宽 23.9mm 只走 8 对（U4 下行）→ 每对 3.0mm 带距，余量充足
- 右走廊 x∈[98.8,132.7] 净宽 33.9mm 只走 8 对（U3 上行）→ 每对 4.2mm 带距，**比 A 案少 50% 拥挤**
- 垂直逃逸：U4 朝向反转后，MCIO 焊盘 0.6mm 脚距 + 芯片焊盘 0.4mm 脚距各自对走廊直出

## 等长预算

- 两段链路长度不对称：J3→U4 ~20mm + U4→J2 ~42mm（下行）；J4→U3 ~45mm + U3→J2 ~28mm（上行）
- 段间长度差 ~22mm 需在短段补偿，**蛇形区需求比 A 案大**，走廊余量可吸收

## 优势 / 劣势

- 优势：每路独占半幅走廊、拥挤度减半、去耦电容空间充裕、AC 墙双列交错自然适配
- 劣势：链路长度不对称（等长补偿压力）、两芯片错位导致电源平面分区略碎、板中心空旷利用率低
