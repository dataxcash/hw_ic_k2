# L1 候选方案 C：U3/U4 上下对置居中 + 电容墙贴芯片

> 竞标候选 C — 核心思路：保持 U3/U4 居中上下对齐（同 A），但把 AC 电容墙**贴紧芯片焊盘**（而非贴连接器），缩短高速段、把走廊留给等长蛇形。

## 器件分区

- **右区**：J2 SlimSAS x8 @ (133.8, 53.7) 保持
- **中区**：U3 @ (93.8, 44.7)、U4 @ (93.8, 62.7) 居中上下对齐（同 A）
- **左区**：J3/J4 @ (59.5, 44.5/62.7) 保持
- **外围**：低速区不变

## 接口朝向

- J2 朝右、J3/J4 朝左不变；信号流左→右不变

## 信号流向

- 下行 8 lane：J3 → MCIO 侧墙 → U3 → J2 侧墙 → J2
- 上行 8 lane：J4 → MCIO 侧墙 → U4 → J2 侧墙 → J2
- 与 A 案相同拓扑，仅电容墙位置从"连接器侧"改为"芯片侧"

## 电源域划分

- 同 A 案；芯片侧贴墙后，去耦电容（MLCC_0603 C67/C68/C72）与 AC 墙共享芯片周边带

## 电容墙构型

- **贴芯片墙**：MCIO 侧墙 x≈84~91（贴 U3/U4 左缘 88.8），J2 侧墙 x≈95~100（贴 U3/U4 右缘 98.8）
- 每墙 16~18 个 MLCC_0201，上下两带对称
- 墙与芯片焊盘间距 ≤1.5mm，走线短且直（<3mm 逃逸）

## 走廊预检

- J2↔U 走廊 x∈[100,132.7] 净宽 32.7mm，**其中前段无电容占用**（电容已贴芯片），蛇形区可用宽度增大
- U↔MCIO 走廊 x∈[64.9,84] 净宽 19.1mm（被贴墙吃掉 4.8mm），8 对需每对 2.4mm 带距——**紧张但闭合**
- 垂直逃逸：电容贴墙后，芯片焊盘→电容→走廊三段共线，逃逸路径最短

## 等长预算

- 高速段最短：J2↔U ~30mm、U↔MCIO ~20mm
- 段内等长 <0.15mm 蛇形区可占用走廊前段（电容已移走），**蛇形空间最充裕**
- 总链路 ~50mm，为三案最短，插损最优

## 优势 / 劣势

- 优势：链路最短（插损最优）、蛇形空间最大、逃逸路径最短、AC 墙走线短直
- 劣势：MCIO 侧走廊净宽降至 19.1mm 接近容量极限（8 对 × 2.4mm）、贴墙后 DFM 检查（B.7 AC 焊盘下 GND 挖空）操作空间小、对元件定位精度敏感
