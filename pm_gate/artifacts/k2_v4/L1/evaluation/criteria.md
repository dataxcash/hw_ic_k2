# L1 裁判标准 criteria（宪法第六章：同一套裁判工具应用于所有候选）

> 裁判维度与权重（满分 100）。所有候选必须按此标准逐项打分，维度不可增删。
> v1.2（2026-08-14）：接入工艺常识强条 `doc/PCB_DESIGN_RULES.md`——方案必须遵守规则集。

## 裁判维度

- 走廊闭合（权重 25）：每对差分带距是否 ≥ 对间最小间距（规则集 R3-2 对间 ≥0.875mm），容量余量
- 信号完整性潜力（权重 20）：链路总长、蛇形空间、逃逸路径长度
- DFM 可制造性（权重 20）：AC 焊盘下 GND 挖空可操作空间、贴墙敏感度、元件定位容差
- 电源/PDN 合理性（权重 15）：去耦电容空间、电源平面分区完整性
- 可维护性（权重 10）：调试探针可达、维修替换便利、丝印可读
- 架构清晰度（权重 10）：上下行对称性、信号流直观性、布局规整度

## 工艺常识强条（硬门禁，G1.5 前置 — 宪法强条附件，一票否决）

> 每个候选在竞标前必须遵守 `doc/PCB_DESIGN_RULES.md`（工艺常识规则集），预检含：

1. **差分出/进焊盘形式**（R1-1~R1-5）：端部出线、45° 斜出、P/N 对称、0 过孔
2. **蛇形走线规则**（R2-1~R2-5）：布局必须**预留蛇形窗口**（每对 ≥10mm×2mm）、节距 ≥0.615mm、振幅 ≤0.875mm
3. **对间/对内间距**（R3-1~R3-4）：对内恒距 0.175、**对间 ≥0.875mm（3W 原则）**、等长 <0.15mm
4. **转弯规则**（R4-1~R4-3）：45° 斜角，无 90° 直角
5. **焊盘墙穿透检查**（G1.5）：走廊带/逃逸路径横穿密集焊盘墙即 FAIL

**任一 FAIL → 候选直接出局，不得进入打分。器件位置可作为变量调整后重出候选。**

## 得分

- 每维度 0~10 分 × 权重系数
