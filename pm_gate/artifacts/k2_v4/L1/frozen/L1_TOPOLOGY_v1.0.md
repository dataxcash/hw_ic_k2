# L1 冻结：整体方案 A — 双侧对称电容墙（v1.0）

> 状态：已冻结（2026-08-13）。本文件为 L2 结构设计的约束包络，L2 不得违反本文件任何决策。

## 器件分区（冻结）

- 右区：J2 SlimSAS x8 @ (133.8, 53.7)，74-pin，焊盘 y∈[42.9,64.5]
- 中区：U3 @ (93.8, 44.7)、U4 @ (93.8, 62.7)，WQFN64，上下对齐
- 左区：J3 @ (59.5, 44.5) rot=180、J4 @ (59.5, 62.7) rot=0，MCIO 38P
- 外围低速区：U1 MCU @ (36,52)、U2 DCDC @ (33,37)、U5 @ (44.5,52)、E2 @ (44,60)、边带排针 x=26.5 列

## 接口朝向（冻结）

- J2 朝右、J3/J4 朝左；信号流左→右：MCIO → ReDriver → SlimSAS

## 信号流向（冻结）

- 下行 8 lane：J3 → AC 墙 → U3 → AC 墙 → J2
- 上行 8 lane：J4 → AC 墙 → U4 → AC 墙 → J2
- REFCLK0/1 独立路由，不共网不交叉

## 电容墙构型（冻结 — 修正对角缺陷）

- **上下行对称**：上行（U3 侧）与下行（U4 侧）电容墙必须同时存在于 MCIO 侧与 J2 侧
- MCIO 侧墙：x≈75~90，AC 电容分上下两带（上带 y≈44~47 对应 J3/U3、下带 y≈60~66 对应 J4/U4）
- J2 侧墙：x≈93~128，AC 电容分上下两带
- 两行电容 y 坐标镜像对齐，禁止跨行绕线

## 电源域划分（冻结）

- L3/L5 电源分区：P3V3 / P3V3_AUX / MCU_VDD
- In1/In3 完整 GND 平面（F.Cu 微带参考面）
- U3/U4 去耦电容摆放需在 L2 解决窄空隙（9.2mm）约束

## 硬约束（L2 必须满足）

1. 18 对 PCIe 差分全 F.Cu 微带，零过孔（ECO #12 Option B）
2. 85Ω 差分（w/g 待 JLC SI9000 重算，当前基准 w=0.227/g=0.15）
3. 对内等长 <0.15mm；对间间距 ≥0.875mm（R3-2 3W 原则，2026-08-15 强条；原 0.5 旧口径已提升）
4. JLC06161H 工艺极限：线宽/距 ≥0.09/0.10mm、过孔 0.20/0.35 孔环 ≥0.075、板边铜 ≥0.30
5. 走廊预算：J2↔U 净宽 33.9mm（8 对）、U↔MCIO 净宽 23.9mm（8 对）
