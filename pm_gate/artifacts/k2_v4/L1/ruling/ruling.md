# L1 裁决记录 ruling（2026-08-13）

## 淘汰理由

- **C 淘汰（6.55）**：MCIO 侧走廊净宽 19.1mm 触容量极限（8 对 × 2.4mm 带距仅勉强闭合），且 AC 焊盘下 GND 挖空（B.7）操作空间过小——DFM 风险不可接受。链路最短的优势不足以抵消制造风险。
- **B 淘汰（7.25）**：链路长度不对称导致 ~22mm 等长补偿压力，蛇形需求最大；芯片错位布局牺牲了 PDN 平面完整性与可维护性。每路独占半幅走廊的优势在当前密度下（对间 ≥0.5mm 已满足）非刚性需求。
- **A 中选**：唯一在走廊闭合、DFM、可维护性三项同时达到 8 分且无致命短板的方案。上下行对称 + 现状修正（补齐对角电容墙缺陷）风险最低、可直接进入 L2 结构设计。

## 裁决人

- 系统架构（PM/用户评审会，2026-08-13）

## 中选依据（简）

- 3 项硬指标（走廊/DFM/可维护）无短板
- 修正现默认布局的对角电容墙缺陷是 L1 必要动作
- 对称结构为 L2（叠层/走廊矩阵/过孔策略）提供最规整的约束包络

## 假设标注（红队 R2 强制 — 裁决假设必须可质疑）

> **本裁决基于以下假设。任一假设被证伪，本裁决即须重审。**

1. **假设 H1（信号流向）**：J3↔U3、J4↔U4 的上下行配对关系成立（即 J3 对应 U3、J4 对应 U4）。
   - 若错：信号配对可能为交叉映射，电容墙对称修正将失效 → 触发段：L3 施工逃逸段；处置：ECN 回 L1 重裁决
2. **假设 H2（现状缺陷）**：现有布局"AC 电容墙对角分布（J2 侧走上行、MCIO 侧走下行）"是缺陷而非有意设计。
   - 若错：原布局设计者可能有未记录的信号完整性理由（如特定参考平面约束）→ 触发段：L3 施工段 1/2 落线时；处置：ECN 回 L1 重裁决
3. **假设 H3（走廊数学）**：IPC-2141 近似 + JLC SI9000 参数下的走廊容量计算（每对 1.104mm）成立。
   - 若错：走廊实际需求增大 → 触发段：L3 逃逸预检；处置：ECN 回 L2 改走廊分配
4. **假设 H4（DFM 对称性）**：上下行对称电容墙不引入额外制造风险（贴片/焊接对称性）→ 触发段：G3.3 可建造性评审；处置：回 L1 或 L2 变更
