**指纹（决定性）**：
- 两轮「失败网优先」时，**只布通 4**（即 4 集），其余 12 全失败；否则布通 12。⇒ **12 集 ⊻ 4 集**（从不同时），两向皆 **0 违规**。
- ⇒ **两独立方法（顺序硬避让 / 协商拥塞真硬分离）落在同一堵墙上、且墙的位置逐条相同** ⇒ 与 **F-6（A/B 嵌套序 4 组相邻互换）**一致 ⇒ **强候选「守恒级不可行」结构性机制**。
- **但**：本指纹为**启发式实证**，**非严格证书**（自由域为绕墙环带 ⇒ 理论上可借绕行换序）；严格证书需「**束序不变量**」之数学证明或**精确 MILP**。
