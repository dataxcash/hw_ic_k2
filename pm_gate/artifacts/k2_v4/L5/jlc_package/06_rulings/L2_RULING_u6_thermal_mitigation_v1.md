# L2 裁定 v1.0 — U6 热机械派生实现要求（CO-149；解 CO-148 R4-2）

> 依据：LAYOUT_CONSTITUTION 第二章（**热机械** = L2 自裁）；**监理定值 Ta = 40.0°C 保留不变**（不动需求输入）。
> 本件把「输入冲突」转为**派生实现要求**：不是改环境，而是导出达成 Tj 上限所需的系统散热实现。

## 1. 两路线一致性核对（**非独立证据**）

- A（手册参考板）：θJA(high-K) = **17.4 °C/W**
- B（本板一阶）：ψJB 5.9 + 1/(h_nat·2A) = 5.9 + 1/(8.0×0.01104) = **17.22 °C/W**
- 互差 1.0% ⇒ **一致性核对通过**（B 路线复用手册 ψJB 与声明 h ⇒ 非独立证据，不作模型独立性主张）

### 1.1 敏感度（CO-151 F-4 披露）

- 板侧路线改用同表**热阻 RθJB = 6.1**（而非表征参数 ψJB = 5.9）⇒ 所需 h 由 **[8.14, 16.38] → [8.29, 16.99] W/m²K**（更保守，+1.84%）。
- 声明自然对流 h = 8.0 的敏感度：h = 8.0 覆盖 **0/4** 档；h = 8.5 覆盖 **1/4** 档（增量 = U6_EQ0-2_typ）⇒ 『自然对流不足以覆盖全档』结论不因该敏感度改变。

## 4. 裁定

**R5-1**：**自然对流（现状）在全部 EQ 档均不可达**（θJA_est 17.22 > 最轻档要求 17.02）⇒ 系统侧散热投入为**必需项**，非可选项。
**R5-2**：**最低要求** = 强制风冷使 h_eff ≥ 8.14–16.38 W/m²K（约 1–3 m/s 板面风速）；**推荐** = 顶部散热片 + 风冷（θJC 路径），预算 θ_HS + R_int ≤ 4.93–10.52 °C/W。
**R5-3**：PCB 侧**不做几何改动**：散热瓶颈为「板→空气」（占 θJA 的 66%），U6 域热过孔仅影响 ψJB（5.9 项，≤ 数 °C/W 收益）⇒ 为边际收益触发 G4 全链重基线不成立；CO-148 R4-1 的「GND via 阵列」由**义务**降为**可选项**。
**R5-4**：终判需实板热测/仿真（本件为闭式一阶派生）；监理定值 Ta=40.0°C 与压降 3% 均不变。
