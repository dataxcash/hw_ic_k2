# L3 前置风险闭环记录（2026-08-13）

> 解决 L2 冻结（L2_STRUCTURE_v1.0.md）标记的 2 项遗留风险。闭环后才可进入 SPEC 提取。

## 风险 1：阻抗参数冻结（已闭环）

### 问题

- L2 冻结采用 IPC-2141 过渡基准 w=0.227/g=0.15（源自 stackup-impedance-report.md，H1=3.91mil/Er1=4.1）
- 6 项复核报告 #5：JLC 官方 SI9000 模型 **H1=5.0mil/Er1=4.3**，IPC-2141 近似不可直接用

### 重算（JLC 官方参数，IPC-2141 同口径公式）

- 输入：H1=0.127mm（5.0mil）、Er1=4.3、T=0.035mm（1oz）
- 旧基准复核：w=0.227/g=0.15 → **77.2Ω**（距 85Ω 目标 -9.2%，超 ±10% 容差边缘下沿，不可接受）
- 全扫描最优点：
  - w=0.195/g=0.150 → 85.0Ω（w+s=0.345mm）
  - **w=0.205/g=0.175 → 85.1Ω（w+s=0.380mm）← 中选（工艺稳健，线宽略宽）**
  - w=0.215/g=0.200 → 84.6Ω（w+s=0.415mm，备选）

### 裁决

- **冻结 w=0.205/g=0.175（85.1Ω）** 为 L3 SPEC 阻抗参数
- 保留 w=0.215/g=0.200（84.6Ω）为板厂复核备选
- 走廊容量复核：w+s=0.380mm，每对占宽 = 2×0.205+0.175+0.5 = 1.085mm，8 对 = 8.68mm ≤ 33.82/23.93mm —— **容量闭合不变**
- 强制项：打样前板厂 SI9000 出 coupon 实测（checklist D.1），若偏移 >±3% 回 L2 变更单

## 风险 2：过孔孔环确认（已闭环）

### 问题

- L2 冻结过孔 0.20/0.35mm，孔环 (0.35-0.20)/2 = 0.075mm 恰好达标 JLC 极限

### 确认

- AGENTS.md 修正条款 1 实测口径：0.20/0.35 或 0.15/0.30 均满足环宽 ≥0.075mm（物理可行）
- 0.20/0.35 为 JLC 标准工艺（非极限钻头），良率稳健
- 0.15/0.30 为极限工艺，仅 S2 候选曾采用（已淘汰），不采用

### 裁决

- **冻结过孔 0.20/0.35mm（drill 0.20/outer 0.35，孔环 0.075mm）** 为 L3 SPEC 过孔参数
- 低速/电源换层用；高速 18 对 0 过孔不变
