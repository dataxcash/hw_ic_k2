## 4. Oracle Q2 结论（本 session 回收，bg_50fec30d，explore 提取摘要）

Q1 顺序迷宫布线**不健全**：不能证明 NO（假阴性），但**成功 + 精确校验 = YES 构造性证书**。
Q2 上/下带分离**安全但需验证充分条件**：存在横贯走廊全宽、无 pad 穿越的分隔线 y=yd
（本例 yd≈63.0，上带最高特征 62.9 / 下带最低 63.3 之间）→ 走廊分解为两个单连通子区域，
两组独立免交叉。**必须实测验证 yd 线无 pad 铜穿越**（U3 pad 在右墙 58.5-67.3 的 scallop、
cap 上下排 pad 侵入深度 ~58.5-58.7）。组内对序与簇 x 序单调匹配（DN0..DN3 两侧同向）→
梳状无交叉可行。
Q3 单边扇出到可移动内部簇：无固有排序障碍，排序反转可被"垂直分层车道"吸收；
**真瓶颈 = 相邻对几何交织的余量 knife-edge**（簇_i 坐在对_{i+1} 锚列下方；bundle_{i+1}
须右绕 ~1.15-1.2mm 或下穿 ~1.2-1.5mm；上带垂直预算仅 3.98mm 簇窗，4 对纯垂直堆叠需
5-6mm → **必须借 x 右推混合下穿/右绕**）。咽喉实例：N1 下穿 DN0 簇需 y≥62.1+1.08≈63.2
> 62.9 上带界 ✗ → **只能右绕或把 DN0 簇放浅放右**。
Q4 推荐方法：**两阶段构造**——(1) 簇布局搜索（x∈[min-x, 右界]、y∈组带、P/N 0.55-2.0、
异对簇 via ≥1.225，阶梯摆放 + 右推）；(2) 固定拓扑序逐对梳状布线 → 全量精确几何验证，
通过即 YES 证书；对 NO 需拓扑障碍论证或簇配置覆盖枚举，**裸迷宫找不到 ≠ 无解**。

**陷阱清单（写报告时逐条对照）**：把"迷宫找不到"当无解；不验证 yd 分隔线无 pad；
4 簇纯垂直堆叠（>3.98mm 预算）；假设簇 y 序须匹配 U3 pad 序（In2 承担转序，簇内 P/N
顺序/旋转自由）；忽视 P/N 两线互不交叉。
