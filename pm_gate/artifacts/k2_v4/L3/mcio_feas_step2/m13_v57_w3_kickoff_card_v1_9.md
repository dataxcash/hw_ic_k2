# m13 v57 — W3 开工卡 **v1.9**（W3-C8：复核"杠杆穷尽"结论）

> 版本 bump（v1–v1.8 不动）。授权来源：**监督工单 W3-C8**（质疑 C7 的"通道化 319 ⇒ 劣化"实测）。

## R-33（复核：交叉分解与折线实现）

- **确认监督分解**（基线 straight = 264）：同帧扇面 200 + 跨帧 64（`B.Cu J3/dn × J4/dn`）。
- **复核通道化实现**：v1.7 的通道化采用 **forward 通道序**（通道列 = `via_x + dir·0.6`，与 via 序同向）
  ⇒ 与 lane 序同向，Z 形扇面**平面性所需的反序**未成立 ⇒ 319 是**实现口径**的必然结果，非该族不可行。
- **Z 族闭式（W3-C8 补充）**：Z 形（共享源行 trunk）**无法同时满足平面与合法铜**：
  - **forward 通道序** ⇒ 违反平面序 ⇒ 交叉（实测 319）；
  - **reverse 通道序** ⇒ trunk 跨度 ≥ (n−1)·pitch + gap > 相邻 via 间隙 ⇒ **trunk 共线重叠**（非法铜）。
  详见 `m13_v57_w3_r1_5_lever_analysis.json`（`reverse_Z_reason`）。

## R-34（45°/135° 阶梯族的闭式预算）

仅用 45°/水平段的阶梯路径满足 `|Δy|_path = Σ|Δx|_45 ≤ |Δx|_avail`；
故**逐页条件**：`|dx_i| ≥ |dy_i|`。分析件给出逐帧逐页失败计数（`pages_failing_dx_ge_dy`）。
凡失败页，该族**不可能**在 `no_90deg` 约束下到达其 lane ⇒ 该族在这些页上闭式不可行。

## R-35（结论修正：不宣告"穷尽"，但给出每杠杆的闭式/实测依据）

| 杠杆 | 依据类型 | 结论 |
|---|---|---|
| lane 序按源序 | 闭式（card v1.3 §R-8 ③） | 不可行 |
| Z/trunk 族（forward/reverse） | 闭式（本卡 §R-33） | 不可行（或违反平面序，或 trunk 重叠） |
| 45°/135°-only 阶梯 | 闭式预算（§R-34 逐页 `dx ≥ dy`） | 在失败页上不可行 |
| straight 段（现行） | 实测 | 264 交叉（同帧 200 + 跨帧 64） |
| R1 逃逸域放宽 / F-5 序修订 / 连接器球重映射 | 上游（需 owner 授权） | 待裁（请求卡） |

⇒ **剩余路径**：上游输入变更（请求卡三项，各含闭式依据）或**全局不可行证明**（构造域证书不据以停机）。
