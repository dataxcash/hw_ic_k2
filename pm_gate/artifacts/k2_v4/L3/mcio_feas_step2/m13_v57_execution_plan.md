# m13 v57 — 整改执行计划（图纸层重建：权威端点 → 生成器 → 施工闭环）

> 依据：DRAWING IRON LAW v57（铁律）+ m13_v57_contract_violations_remediation.md（违约清单）。
> 执行纪律：阶段顺序 S0→S1→S2→S3 **串行**；每阶段 = 开工前设计/证明 → 编码 →
> **机器验收（本文件列明的 A×，全部必须通过）** → lock + commit → 才进下一阶段。
> **任一验收谓词不过 = 立即停止，不得带病进入下一阶段**（L7）。

---

## S0 — 权威端点模型与单向审计（地基；关闭 V1/V3 的锚点来源问题）
**输入**：DS320 ballmap（+ 连接器手册）、k2_sch 网表连接性、placement（含当前板文件
只作坐标参考源之一，不作正确性标准）。
**产出**：
1. 权威端点模型（34 网 × 双端）：每端 = {base, segname, 器件, 引脚, 几何坐标,
   几何来源（ballmap 引脚/网表/放置变换），依据文档}，机器可复现生成；
2. 单向审计报告：escape_spec 引脚表 / 当前板焊盘 / 现存图纸行 vs 权威端点 → 差异清单。
**验收谓词（A0，全过才进 S1）**
- A0.1 端点模型生成脚本可复现：同输入两次输出逐字节一致；含来源指纹链。
- A0.2 溯源完备：34 网每网双端均可回溯到权威源（器件+引脚+几何+依据），
      无"来源=板文件反猜/窗口扫描"的端点。
- A0.3 差异清单落盘：现存派生物 vs 权威端点逐项 = 一致 | 权威优先待改 | 孤儿待裁。
- A0.4 无未裁差异进入任何生成/消费路径；待裁项 ≤ 明确上限（逐项记录理由）。
**不过即停**：停在 S0，报告差异，整改重验，不进 S1。

## S1 — 图纸生成器（主体；实现 L2/L3/L5）
**开工前交付**：设计细案（资源层编码 / 每层守恒条件 / 确定性构造规则 / 证书格式 /
序无关论证 / 与 alloc、landing、v53/v54 簿的职责边界）。
**实现**：对输入（权威端点+规则+资源+只读锚）确定性求解：可行 → 全 34 段联合图纸
（构造性保证合法）；不可行 → 守恒证书（层+资源+最小需求集）。禁贪婪/顺序耦合。
**验收谓词（A1，全过才进 S2）**
- A1.1 守恒判定正确性：对每组资源层，可行/证书判定与独立穷举基准一致（合成反例集，
      含"看似有隙实则无解"与"看似无解实则可行"两族）；证书=最小不满足集。
- A1.2 序无关：同输入，任意确定性枚举序（正序/倒序/密度序），图纸与证书逐字节一致。
- A1.3 生成即合法：生成器标记"图纸可行"的段，其全部节点过几何不变量套件
      （P/N 间距、净空、同列/同格密度、锚定只读），**不依赖 DRC 兜底**；不变量
      违例=生成器 bug（红级，当场修生成器，不许落到施工）。
- A1.4 单向性：无"生成→图纸可被施工/下游改动"回写路径；无 max-x/x-window 反猜残留。
**不过即停**：停在 S1。

## S2 — 施工消费闭环（连连看；保持 L1 闸门）
**实现**：solve 消费 S1 图纸（含 chip_landing 独立命名空间接线）；缺图仍 fail-closed；
施工只连线+不变量。
**验收谓词（A2，全过才进 S3）**
- A2.1 每段状态 ∈ {图纸连线 SOLVED, 守恒证书 INFEASIBLE}，无第三种/无自搜计数。
- A2.2 图纸齐全段的连连看 100% 通过（施工不改节点即成功）；任一失败 = 图纸错误红级
      → 回 S1 修图，不许施工将就。
- A2.3 双跑全文件字节一致（确定性延续）。
- A2.4 不变量断言套件零违例。
**不过即停**：停在 S2。

## S3 — 全局证书与设计层接口（封环）
**实现**：守恒证书结构化（可直接与 alloc/SPEC/权威端点对账）；设计层接口文档 +
样例（改输入的唯一合法通道）；真图纸合格数报表。
**验收谓词（A3）**
- A3.1 证书可复现且与输入直读对账（无隐藏常量/无 guess 字段）。
- A3.2 设计层接口：变更输入=唯一出墙通道；文档+调用样例。
- A3.3 终态报表 = 真图纸合格数口径，无"另卡/已知账"出口字段。

---

## 全局纪律（每阶段通用）
1. 全前台零委派；冻结区改动先 unlock + 该步验收通过后 lock。
2. 每步 commit 信息标注验收谓词结果；失败提交不允许推进。
3. 图纸/施工单向下游；任何违例即停机上报（铁律 §3）。
