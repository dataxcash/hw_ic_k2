## R-37（证明过程暴露：仍有未穷尽的**合法构造**，C9 第 3 条）

**残余交叉的真实根因（W3-CN.2 复算）**：各帧 P/N 的 x ramp **均单调**（已验），但同帧内出现
`P-P` / `N-N` 交叉（EAST/up 28 + EAST/dn 21 + WEST/dn/J4 6）——共线源 + 单调 x + 单调靶**不可能**相交，
故**源点并非共线**：R1 的 y 吸附逐页选了各自的行，破坏了"同帧同极性同一水平行"的平面扇面前提。

**未穷尽的合法构造（下一轮第一步，零搜索、可复核）**：
1. **共线行扇面**：每 `(frame, polarity)` 选**同一 via 行**——闭式取"对该帧全页均可容许且使
   `max|y−pad_y|` 最小"的行（行候选来自冻结域的 0.05 网格）。
2. x ramp 与极性交错规则沿用（同帧单调 + 同侧）。
3. **层分配 = 反演图着色**（置换图贪心扫描，2 色 = `In2.Cu`/`B.Cu`）——本卡 §R-36 的团数=2 即为其依据。

   跨帧由 2 色反演着色分离。
- **预期**：同帧交叉 → 0；跨帧由着色分离 ⇒ 目标 `同层交叉 = 0`（进而 FEASIBLE_ALL）。
