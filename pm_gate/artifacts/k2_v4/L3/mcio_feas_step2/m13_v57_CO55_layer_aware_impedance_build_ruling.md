# CO-55 — 【L2/SI 自裁】层感知 Zdiff → **反向下达 8L 叠层要求**（取消"等板厂输入"；几何零改动）

> 2026-09-12｜定层 **L2/SI**（LAYOUT_CONSTITUTION 第二章：**叠层分配** + SI 物理承载；裁判权 = SI/PI 工程师）⇒ **自裁，无 owner 闸口**
> 前置：CO-53（开放项）、CO-54（漂移清单/输入缺口可达性实测）。触发：监理自动续推"L2 自裁勿停"。

## 1. 为什么必须反解（CO-53/CO-54 的结构缺陷）
SPEC 只有一个阻抗口径 `JLC_SI9000_H1_5.0mil_Er1_4.3`（即 **F.Cu 微带**，h=0.127/Er=4.3，w=0.205/gap=0.175 → 85.1Ω），
却被套用到**全部信号层**（L2 v2.0「In2 段线宽冻结为 0.205mm（85Ω，与 F.Cu 相同）」）。
交付实测：34 对中 **32 对**的决定性平行段在 **In2/In6**（内层，结构 = 带状线 / 单参考），而内层 Zdiff 对介质厚度的敏感度与微带完全不同
⇒ 单 (w,gap) 跨层通用 **不成立**，且 8L 介质表缺失使判定悬空。**解法（L2）：把介质厚度当作自由度去满足已建成几何**（如不满足才回退改几何）。

## 2. 层结构判定（LID.1：F/In1(G)/In2(S)/In3(G)/In4(P)/In5(G)/In6(S)/B(S)）

| 信号层 | 参考结构 | 变量 | 结论 |
|---|---|---|---|
| F.Cu | 微带（参考 In1） | `d(F-In1)` | 可控 |
| In2.Cu | 带状线（参考 In1+In3，**非对称**） | `b(In1-In3)=d(In1-In2)+d(In2-In3)` | 可控（须对称化/近端参考） |
| In6.Cu | 单参考（参考 In5；下方 B.Cu 为**信号层**） | `d(In5-In6)` | 可控（须 B.Cu 净空） |
| B.Cu | **无平面参考**（In6 为信号） | — | **非阻抗控制层** |

## 3. 机判结果（工具 `tools/p3_v57_co55_layer_aware_zdiff.py`；交付几何来自 CO-54 audit）

模型保真度：SPEC 自陈基准（H=0.127/Er=4.3, w=0.205, s=0.175）⇒ **85.05Ω vs 85.1Ω**（同源）。
交付对内 gap 档（主导）：**0.295**（中心 0.5，90 处）与 **0.395**（中心 0.6，32 处）；另含少数局部档（0.345…0.445，见 audit）。

**反解所需介质厚度（使 w=0.205 的交付几何落 85±10%）**

| 间隙 | ±10% 允许带 | 裁定目标（标准料） | 交付各档 Zdiff |
|---|---|---|---|
| `d(F.Cu–In1.Cu)` | **0.097–0.1215** | **0.1164**（JLC **2116×1**，Er 4.16） | 88.4–91.2Ω（+4.0…+7.3%）✓ |
| `d(In5.Cu–In6.Cu)` | **0.0875–0.110** | **0.0994**（JLC **3313×1**，Er 4.10） | 85.5–87.4Ω（+0.6…+2.8%）✓ |
| `b(In1.Cu–In3.Cu)` | **0.5815–0.947** | **0.72**（`d(In1–In2)=d(In2–In3)=0.36`，对称，Er 3.99） | 82.1–89.2Ω（−3.5…+4.9%）✓ |

**厚度闭合（1.6mm，机判 delta=0.000）**：铜 0.175（外 1oz×2 + 内 0.5oz×6）
+ `d(F-In1) 0.1164` + `0.36+0.36` + `0.1528×2`(1080×2) + `d(In5-In6) 0.0994` + 自由余隙 `d(In6-B)=0.1836` = **1.6000**。
⇒ **该叠层在 1.6mm 8L 内自洽且用料为 JLC 标准 prepreg/core。**

**对照：若沿用 6L 型假设（h=0.127 / b≈0.599）**：F.Cu +10.2%（临界）、**In6 +17.7%（超差）**、In2 −3.3…−9.1%（临界）
⇒ 正是 CO-53 无法结案的原因；反解后全档进带。

## 4. L2 裁定（自裁，取代"等输入/等 owner"）

- **R1（下达 8L 叠层要求）**：`d(F–In1)=0.1164`(2116×1)、`d(In5–In6)=0.0994`(3313×1)、`b(In1–In3)=0.72`（**近端参考 `d(In1–In2)` 同 F.Cu 口径；对称为 0.36+0.36**）；余隙按总厚 1.6mm 闭合（示例见表）。
**几何零改动**：交付 w=0.205 / 对内中心 0.5–0.6 在此叠层下全部落 85Ω ±10%（一阶）⇒ **无需 W3/L4/L5 re-open**。
- **R2（回退，若板厂不能给 b ≥ 0.582）**：In2 线宽须重导 `w*(b)`：`b=0.35→0.12 / 0.40→0.13 / 0.45→0.14 / 0.50→0.15 / 0.55→0.16 / 0.60→0.17`
  ⇒ 触发 W3/L4/L5 re-open（L2 授权；变更单 + 版本 bump）。
- **R3（无参考层）**：**B.Cu 判非阻抗控制层**（低速/边带/铺铜）；**In6 阻抗关键段下方 B.Cu 不得并行铺铜/走线**（否则 In6 单参考假设失效）。
- **R4（SPEC ECO rev-4 内容；**已由 CO-56 落盘**，rev-4 = `1c4eecb0edf4a446`）**：`stackup`（8L 材料 + 逐层介质表=本裁定）、`impedance` 增 **`per_layer` 分层口径**（保留原标量字段兼容消费方）、`net_classes.PCIe85.diff_pair.p_gap` 语义 = **下限**（DRC clearance 0.175）而几何真源 = 交付 (0.205, 0.295)。
  裁定：该不变量为**规则文件自洽性**校验（`drc_rules.diff_pair` 派生 1.46 = 冻结 PITCH），与 `corridors[].bands[].tracks_y` 的**布线轨距 1.20 属不同对象** ⇒ CO-56 以 `inter_pair_spacing_scope` **记录二者口径**（数值均未改），不需要改动该不变量。
- **R5（缺口取消）**：CO-53/CO-54 的"8L 介质叠层输入缺口"**取消**：不再索取板厂表，改为下达本要求 + 板厂券终判（`coupon_required=true` 本就是 SPEC 既有路径）。
