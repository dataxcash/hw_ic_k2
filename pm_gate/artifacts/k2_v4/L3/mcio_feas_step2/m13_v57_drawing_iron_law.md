# k2 高速域施工方案模块 — 图纸层铁律（DRAWING IRON LAW v57）

> 状态：**铁律（不可违抗）**。用户裁决 2026-09-09 批准。适用：k2 高速域
> "施工方案模块"（权威端点装配 → 图纸生成 → 施工连连看 → 守恒证书）。
> 任何代码/流程/分析与此冲突 = 违反即停机：停止 → 报告 → 整改 → 机器验收 → 才可继续。
> 前置关联：容器根 AGENTS.md §8（可行性=守恒级硬约束存在性证明）；本项目 LAYOUT 宪法。

## 0. 术语（定义即约束）
- **上游权威源（authority，唯一能定义"画什么"）**：
  1. 器件数据手册几何 —— DS320 ballmap / 连接器手册（引脚是谁、几何坐标、网络功能）；
  2. 原理图网表连接性意图 —— k2_sch（哪条网必须连哪个器件哪个脚）；
  3. 放置 placement（器件在板上的坐标/旋转；其正确性由放置层自己的上游验证负责）；
  4. 注入的设计规则与守恒约束（净空/间距/极性/容量）。
- **图纸（drawing / 施工图）**：每段一张，含 权威双端锚 + 全部几何节点（芯片端
  出逃列/via/桩、连接器端落点/via、走廊轨道）+ 层声明。**图纸是施工唯一可消费对象。**
- **施工（construction）**：按图纸机械连线（连连看）+ 不变量断言。**零设计决策。**
- **派生物（derived，一律禁止用作正确性标准）**：k2_v4.kicad_pcb（当前板文件）、
  escape_spec 引脚表、landing/登记簿、各类 report。派生只能单向对齐权威源，
  绝不能反向校核上游或图纸（循环论证）。

## 1. 铁律
- **L1 施工=连连看**：缺图即拒（打回图纸层）；禁自搜、禁兜底、禁现场改设计、禁贪心将就。
  （闸门已落地：drawing_only fail-closed，保持开启，永久。）
- **L2 图纸正确性=生成算法构造保证**：生成即合法。图纸的可行性是生成器**算出来**的，
  不是核查/审计/DRC 查出来的。核查只作不变量断言，永不作正确性来源、永不出图结论。
- **L3 禁贪婪与顺序耦合**：图纸生成用**确定性合理算法**；同输入、任意确定性枚举序
  （正/倒/密度），图纸与失败集逐字节一致；不可行输出 = **守恒级证书**（最小不满足集：
  哪层/哪资源/被谁占死/为何任何分配都不可能），不是"本次试跑失败"。
- **L4 验证单向（上游→下游）**：正确性只由"对齐权威源 + 守恒 + 构造性生成"证明。
  任何两两互对（图纸↔板文件、板文件↔escape_spec、report↔板…）只产生线索，
  不产生正确性。禁止把引擎输出当"真板/地面真值"校核引擎。
- **L5 图纸做对=核心关键**：34 段全图（每段权威双端锚+完整节点+轨道）是主线；
  缺一张=欠债，错一张=停机整改。芯片端图纸缺页（33 段打回）即当前最大欠债。
- **L6 确定性答案**：对给定输入只输出确定答案（可行图纸 / 守恒证书），
  禁"可能/取决于/guess"；守恒墙只能由改输入（规则/器件/结构/减需求）消失。
- **L7 验收=机器谓词，逐阶段门禁**：每阶段有可执行验收标准；任一不过，**不得进入
  下一阶段**。口径 = **真图纸合格数**（图纸齐全→施工连连看通过）；含自搜的旧口径作废。

## 2. 权威端点到图纸的正确推导方向（只许这样走）
```
器件手册几何 + 网表连接性 + 放置 + 规则/守恒
      ↓ 派生（生成器，构造性保证，禁贪婪）
每段图纸（权威双端锚 + 全部节点 + 轨道）→ 施工连连看
      ↓ 机器谓词（不变量，不产出结论）
图纸合格数 / 守恒证书
```
禁止路径：板文件 → 猜锚点 → 出图；已解路径 → 反演 → 当登记簿；DRC 撞墙 → 改几何。

## 3. 违反即停机
发现与铁律冲突（含：用下游校核上游、核查出结论、贪心出图、顺序耦合、缺图自搜、
无验收跨阶段、"另卡/后推"出口、把派生物当标准）→ **立即停止当前动作** →
输出冲突报告（期望 vs 实际）→ 按违约整改清单处理 → 该步机器验收全过 → 才可继续。
