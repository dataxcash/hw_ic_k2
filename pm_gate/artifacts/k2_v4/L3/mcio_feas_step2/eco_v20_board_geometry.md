## 2. 层数 6 vs 8 重估判据（v20 新增）

8 层旧决策（stackup_8layer_decision，2026-08-19 用户裁定）的成立前提是：J2 侧 36 网 + 电容墙 + 低速
与 PCIe 抢 In2/B.Cu + REFCLK 需独立层。**新负载**：
- 高速 16 对仍 F.Cu 微带 + In2 带状线（F→In2→F 单内层换层模式保持）；
- 无电容墙 → In2 走廊净空释放；低速边带可回 B.Cu 或仍留独立层；
- **6 层（F/G/S/G/P/B）在旧负载即 36/36 通过**，仅因"更干净"（隔离/3 GND/REFCLK 独立）升 8 层。

判据 = 新板路由闭合 + 每网换层 via≤2 + 对间 0.875 + REFCLK 包地 + GND 伴行。**需跑一次真实路由验证才能裁**，
不拍脑袋。（下一步：BoardParser 摆新件 → 6 层与 8 层各解一次 → 数据说话。）

## 3. 板高候选包络（#6 坐标前置，v20）

旧 y∈[33,71]（38mm）。约束源：
- J3/J4 MCIO x4（卧式、上缘 y=33 出线、X 错开 ~1cm 用户已裁）需上部净空；
- DS320PR1601 22.8×9.0 横放 + 两侧 x 逃逸为主 → y 向仅需 9.0+去耦+上下逃逸窄带；
- J2 SlimSAS x8 右缘 74-pin y∈[42.9,64.5] 高度带 21.6mm 是 y 向最胖者；
- 底部 DCDC/U1 等低速件。

候选包络（进入下一 session 摆放测算）：
- **H1: y∈[33,79]（46mm）** — 保守首选：J2 21.6mm 带 + 顶部 MCIO 出线区 + 芯片 y 带，含余量；
- **H2: y∈[33,85]（52mm）** — 更松：MCIO 与 J2 同侧纠缠时备选；
- 取两候选路由均闭合的最小者，**倾向 H1（46mm）**，最终以 BoardParser 摆放+路由闭合数为准。
