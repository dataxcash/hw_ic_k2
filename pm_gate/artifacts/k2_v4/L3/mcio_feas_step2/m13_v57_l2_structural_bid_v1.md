## 1. 候选 CAND-A —— **6L 保层重分配**（in-envelope remedy）
- **叠层分配**：F/G/S/G/P/B 不变（不增层）。
- **走廊矩阵**：In2 = J2 穿越 16 对 + REFCLK 分带；F.Cu = 微带通道 + chip escape；**B.Cu 释放**给 fan-out + 低速/边带。
- **过孔策略**：per-pin ball-gap via；连接器外列 F.Cu 外逃 / 内列 via；via≤2。
- **等长窗口**：intra-pair ≤0.15 机检（新增）。
- **估价**：变更成本低（不动四源）；但…
- **淘汰理由（决定性）**：
  1. **[G-2/G-3] 冻结 6L 包络 + 3 信号层内所有合法构造族已族级穷尽**——域扩(4×)/序变体(3 序)/T-5/T-5′/
     共线行+相干字段/净距放宽 全部**不可行或退化**（构造域；W3-FCC.1 P2..P8；`m13_v57_w3_reopen_probe_v1.md` §5）；
  2. **[G-2] 单内部信号层资源不足**：P2 全墙不可穿 ⇒ 高速 pad 一律需 via 至 In2；In2 翼带容量 25.3 对
     vs 逃逸/穿越/REFCLK 需求已触顶；
  3. **[G-8] 参考平面缺陷**：6L 下 B.Cu 最近平面 = In4(P3V3)（电源），非 GND（L5 SI 记录实锤）；
  4. **[一致性] SPEC 层语义仍引用 In5（8L 层）**，6L 包络未闭合。
- **保留为回退候选**：仅当 L2 提出**非调参型全新技术方案**且闭式证明 G-1..G-8 全过时启用。

## 2. 候选 CAND-B —— **8L 恢复 In6（第二内部信号层）** ✅ 中选
- **叠层分配**：F/G/S/G/P/G/S/B（v20 ECO 语义）——**In1/In3/In5 = GND，In4 = P3V3(分区)，In2/In6 = signal**。
- **走廊矩阵**：
  - In2 = **恢复 2026-08-19 8L 定案的 J2 专用穿越走廊**（16 对）；
  - In6 = **REFCLK 专属带** + 西走廊(MCIO) 溢流；
  - B.Cu = 释放给低速/边带 + 连接器 fan-out（6L 的"不再走 B.Cu"= 8L 语义的降级错配，予以更正）；
  - F.Cu = chip escape + 微带。
- **过孔策略**：分层逃逸 (F→In2→F)/(F→In6→F)；via≤2；差分换层 GND 伴行 via。
- **等长窗口**：intra-pair ≤0.15 机检 + 对间 1.46。
- **PD/SI 评估（内嵌为门禁）**：
  | 维度 | 6L（现状） | 8L（候选 B） |
  |---|---|---|
  | 参考平面 | F↔In1(GND)、In2↔In3(GND)、**B↔In4(PWR)** | F↔In1、In2↔In3、**B↔In5(GND)**、In6↔In5 ✓ |
  | PDN | In1/In3/In4 三平面 | +In5 GND ⇒ 平面电容/回流改善 |
  | 阻抗 | w0.205/g0.175, SI9000 H1 5.0mil Er 4.3 | 介质堆叠变 ⇒ **SI9000 重推 + coupon**（SPEC `/impedance` 明载） |
  | 层用途红线 | In4=P3V3、In1/In3=GND | 保持（仅加 In5/In6，不改既有权属） |
- **中选理由**：
  1. **恢复被 cut 的原始冻结意图**（SPEC `j2_escape_topology`/`gnd_stitch_via` 均明载"**8 层定案**"）；
  2. 满足冻结 **L2 结构件 `L2_STRUCTURE_v2.0.md` L126-137 的「8L 重入 ECN 触发条款」1&2**（F1/F3）；
  3. **最小 restore 变更**（加回被移除层，非发明新结构）；
  4. 第二内部信号层 + GND ⇒ **解除 P3 资源不足**、**可内嵌 P4 强条**；
  5. 改善 G-8（B.Cu 参考 PWR→GND）。
- **前置**：层叠/SPEC 变更 → 依 R-03 重冻结（owner 授权）后实施；本件不实施。
