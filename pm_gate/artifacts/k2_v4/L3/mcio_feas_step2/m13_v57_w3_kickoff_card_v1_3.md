## R-8（③ 构造不可行证明 → 采纳 ① 第二层，确定性层分配）

**③（改 F-5 帧/lane 序使源序与靶序对齐）不可行 —— 闭式序矛盾证明：**
1. **chip 源行分组**：4 个源行组各 8 页 —— EAST up(55.13/55.823)、EAST dn(57.12/57.64)、
   WEST up(49.76/50.28)、WEST dn(51.673/52.366)。组内源行相同。
2. **chip 侧非交叉必要条件**：直线扇面下，两源行组的靶 y 区间必须**互不重叠**（否则扇面相交）
   ⇒ 同一走廊内 up 组的 8 条 lane 必须整体位于 dn 组之上（或之下）。
   对 WEST：`max lane_y(up 组) < min lane_y(dn 组)`（`lane_y(J4up) < lane_y(J4dn)`）。
3. **连接器侧非交叉必要条件**：R3 落点 y 序 = 帧序（J3up≈43 < J3dn≈45.5 < J4dn≈59 < J4up≈62.5，实测）
   ⇒ lane 序必须同序：`lane_y(J3up) < lane_y(J3dn) < lane_y(J4dn) < lane_y(J4up)`。
4. 2 与 3 对同一对页 `(J4dn, J4up)` 给出**相反**要求（`<` vs `>`）⇒ 不存在满足两端连接约束的 lane 序。
   ⇒ **③ 不可行（构造域证明）**。EAST 同型（up 组扇面下探 dn 组源行区）。

**① 采纳（生效）**：**确定性层分配规则**（非搜索）：
- 芯片锚 → 走廊入口的过渡段 + 走廊 lane 合并为**单层直行**，层由带决定：
  `up → In2.Cu`、`dn → B.Cu`（`LAYER_BY_BAND`）。
- 每线 via ≤ 2（via₁ F→L、via₂ L→F）✓；**层叠不变**（沿用既有 F/In1/In2/In3/In4/B）✓；
  电气约束不放松 ✓。
- 跨带交叉对由层隔离解决；**同层交叉仍须为 0**（A-CN.4 改为"同层交叉 = 0"）。

## R-9（R2 规则定案，消除 G-M4 漂移）
