## 1. 裁定（L2）
在**合法落列几何**下，O4（`intra_pair_skew_mm = 0.15`）**不能**由"落列选择 + 带内 y 调优"闭合：
穷举 5 类合法方案最好仅 **29/32**，失败对残差 **0.5~2.6mm**，远超 y 带可提供的补偿（0.6mm）。
⇒ 需 **CO-05b 成对对称逃逸/落列架构**（P/N 等几何，仅法向偏移）或 **L3 长度补偿**（须先证绕线空间）。
**禁止**以放宽 skew 预算取代结构修订。

## 2. 合法落列几何（F-8 域规则，`p3_v57_f8_r3_gap_candidates.py:94-104`）
- `between` 缝：仅**中点 ± (gap_width−0.7)/2**（J2 中缝 `133.825, gap_width=1.05` ⇒ **±0.175mm**；宽 0.35mm）。
- `left/right` 外侧：**半无穷**（本板受走廊 ~105/板边 ~143 限制）；与中缝相隔 **≥2.175mm**。
- 同缝内两点需 ≥0.525 的 via↔via ⇒ 可**对角分离**（Δx≈0.35 时需 Δy≥0.391，band 内可用 0.5 ⇒ 可行）。

## 4. 结论与依据
- 0.15mm 需 P/N 几何**等价**；合法落列自由度（±0.175mm 缝 + 相隔 ≥2.175mm 的外侧带）无法抵消
  `Δv1x`(0.4~2.2mm)、`POL_OFF`(0.38mm)、落列/landing-y 差。
- 故闭合路径 = **结构**（对称逃逸）或 **补偿**（serpentine），二者均属 L2/L3 我方可裁决范围，**不上抛 owner**。

## 5. CO-05b 设计要点（成对对称逃逸）
1. P/N 路径**等几何**：同一走线骨架，仅以**法向偏移**区分（芯片端与连接器端偏移差由**固定补偿段**吸收，长度可解析确定）。
2. 落列仍取合法 gap（中缝或外侧带），但两条**成对同向**（不再分居两侧）。
3. 构造须**闭式/零搜索**；RD 变更面：`r3_place` 成对骨架 + `REVISION`→`W3-CN.28`。
4. 验收：`W3-CN.28` `FEASIBLE_ALL` + A-CN.9 `0/0/0` + crossings 0 → `W4(G5)` → `L4(G6)` → `L5(G7)` skew ≤0.15 且 DFM new=0。
