# 拓扑样板库 v1（ROOT-7）— 架构层：样板 + 适用条件 + 平面性保证 + 确定性实例化

> 铁律边界（监理裁定）：禁**坐标空间搜索**；允许**样板库检索/匹配**（库常数级、确定性）与其**确定性实例化**。
> 本库每条样板四要素齐备：结构 / 适用条件（闭式可判）/ 平面性保证（定理或构造证明）/ 实例化规则（确定性）。

## T-1 BGA 出逃扇（area-array escape fan）
- 结构：球阵每球沿**同一侧**正交出逃 → 独立列 → 转入平行轨（lane）。
- 适用条件（闭式）：① 每带内各球沿**同一出逃方向**；② 源点列序与靶轨序**同序**（`sign(Δsrc)=sign(Δlane)`）；
  ③ 出逃列互斥（列距 ≥ via 直径 + 净空）。
- 平面性：**两有序轨引理**（源共线 + 靶共线 + 保序配对 ⇒ 扇面无交叉）。
- 实例化：`x_i = pad_x(i) + s·d`（d=相邻 pad 中点距），逐点吸附，单遍。
- 适用性（本案例）：**不满足条件 ②**（同带两帧共源行但靶序被连接器行序强制交错）⇒ **T-1 不可用**。

## T-2 双层通道路由（two-layer channel routing，含 dogleg）★候选
- 结构：区域两侧为**上下两条 terminal rail**；net 由"水平 track 段 + 垂直 column 段"构成；跨轨冲突用 **dogleg**（层切换）消解。
- 适用条件（闭式）：① 两 rail 的 terminal 排列给定（**允许任意扭序 twisted permutation**）；
  ② 垂直约束图（VCG）可含环 ⇒ 用 dogleg 打破；
  ③ 可用层 ≥ 2（本案例可用 **F.Cu/In2.Cu/B.Cu = 3**）。
- 平面性：**经典定理**——任意通道路由实例均可在 **2 层**用 dogleg 无交叉完成（dogleg 数 = 层切换数，
  与 VCG 环数同阶）；同层内由 track 分配保证不重叠、由 column 排序保证同列垂直段不交叉。
- 实例化（确定性、O(n log n)、无搜索）：
  1. 按 net 的**左 terminal x 升序**排序；
  2. **左边缘（left-edge）算法**分配水平 track；
  3. 垂直段按**固定列序**分配层（同列自下而上交替/按 VCG 拓扑序）；
  4. 冲突处插入 dogleg（= 2 via），记录层切换与 via 数。
- 适用性（本案例）：**满足**——芯片侧 via 列 = 上 rail，走廊 lane 入口 = 下 rail，扭序由 dogleg 消解；
  via 预算（≤5）须由 dogleg 数校验。

## T-3 河道布线（river routing）
- 结构：两 rail 的 terminal 顺序**相同**，bus 平行走。
- 平面性：顺序相同 ⇒ 直接平行、无交叉。
- 适用性：**不满足**（本案例两 rail 顺序不同）。

## T-4 总线扇出（bus fanout）
- 结构：单一源顺序沿同一方向扇出；层无关。
- 适用性：**部分**（仅适用于 T-1 条件②成立的那 6 个帧）。

## 结论：本案例 = **T-2 双层通道路由（含 dogleg）** 实例
- 归类依据：芯片侧 32 via 列（上 rail）+ 走廊 lane 入口（下 rail）构成**通道**；扭序（C12/C14 实测）
  正是 dogleg 要消解的 VCG 环。
- 需要的样板即 T-2（**已知族**，无需新样板）；其**平面性由定理保证**，与"坐标搜索"无关。
