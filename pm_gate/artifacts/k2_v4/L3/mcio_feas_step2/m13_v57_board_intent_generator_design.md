## 0. 一句话

**板级意图生成器 = 从（板框+放置+网表+层栈+规则+端点锚）确定性算出（走廊帧+
lane 帧+层分配+REFCLK 带），算出来的那一刻即满足全部守恒——lane 间距是摆出来的、
层是从层栈选的、REFCLK 是分配器给的；放不下当场输出量化证书（缺多少/缺什么）。**

## 2. 需求与自由度形式化

- **需求集 D**：34 对（页清单）。每对 = {side: east|west|直通, 数据/REFCLK}。
  数据对 32：east 16（DN in + UP_OUT out_J2）、west 16（DN_OUT out_MCIO + UP in）。
  REFCLK 2：穿东西双廊。
- **走廊实例 C**（由放置+板框+禁入区派生，非手写）：
  - EAST：x 从 chip 出逃区东界 → J2 内列西缘；x_range 内不得有其它器件。
  - WEST：x 从 AC 墙/连接器区东缘 → chip 出逃区西界。
  - 推导规则 = 部件/场边缘+安全距；实施时对下列常数做几何核验并留证据：
    chip 出逃区 = U6 ball 场全局 x 界 ± 出逃列域宽；连接器出逃隙同 S0 锚。
- **带/轨道需求**：每走廊 y 跨度可用区间 = 走廊 x_range 全程板内 y，减去禁入带
  （器件投影、M3、边距）。**该区间是 lane 帧唯一自由度源。**
- **层资源**：数据走廊层 ∈ {In2.Cu}（6L 唯一内层信号层，F.Cu 仅供端部 stub）；
  REFCLK 候选层 ∈ {F.Cu(带外直通), In2.Cu(隔离带)}——分配器裁决，禁 In6 等废层。

## 3. 构造算法（确定性四步；正确性=构造即合法）

1. **排序固定**：每带 lane 序 = 该带对集在两端锚定的 y 带升序（不可交叉约束）；
   对序 canonical（页清单键序）。
2. **数据带 lane 帧构造**：lane_y[k] = band_base_y + k × 1.46（对中心距，已含对宽
   0.585+铜边 0.875）。band_base_y = 带内最靠近参考锚的 lane 起点，由端锚 y 带
   投影 + 对齐规则定。**两两间距 ≥1.46 是摆出来的，不是查出来的。**
   - dn/up 两带在同一层 In2 必须整体互不侵入：带间净空 ≥ 隔离距（对间同口径
     1.46，或按层栈/平面裁决注入）；即 up 带末 lane 与 dn 带首 lane ≥1.46。
3. **层分配**：数据带 → In2；若两带 y 跨度叠加超走廊可用区间 → **证书**
   （量化：需求 n×1.46+带间隔 vs 可用跨度，缺 mm；出路=改输入：加走廊 y、减对、
   或分层裁决）。
4. **REFCLK 带分配**：在数据带排完后，找候选层×候选 y（F.Cu 带外：走廊 x 区间
   外板内路径；In2：数据带外的隔离空隙 ≥ 数据带最近 lane 1.46）。按确定性候选序
   取首个合法；全空 → **证书**（REFCLK 无合法隔离带，量化给出最近占用距离）。
   - F.Cu 带外候选还需过禁入区/器件/边距谓词（§1 禁入区），谓词全过才合法。

## 4. 证书格式（与图纸层同构）

```jsonc
{
  "kind": "BOARD_INTENT_CERTIFICATE",
  "blocked": "R2_lane_frame | R4_refclk_band",
  "demand": {"corridor":"EAST","pairs":16,"n_lanes":16,"pitch":1.46,
             "needed_mm":22.9,"avail_mm":21.1,"short_mm":1.8},
  "minimal_core": ["EAST/up lanes 1..16", "band_base 对齐"],
  "why": "可用 y 跨度 21.1mm < 16×1.46=23.36-0.46? 需要带间隔 → 缺 1.8mm",
  "escape_hatches": ["加走廊 y", "减 1 对", "REFCLK 移 F.Cu 带外"]
}
```
每证书字段直读对账，无 guess。

## 6. 验收谓词（B1.x，全过才进编码闭环；对应 A1.x 同纪律）

- **B1.1 守恒判定正确性**：判定核心 vs 独立穷举基准（合成实例：随机对集×带×层
  资源×隔离要求），决策一致；证书=最小不满足核且量化缺口与穷举一致。
- **B1.2 序无关**：同输入三枚举序（正/倒/密度）输出逐字节一致。
- **B1.3 构造即合法**：不变量套件（独立实现）：lane 两两 ≥1.46；层 ∈ 6L 栈；
  REFCLK 带与数据带隔离 ≥1.46 或不同层；带序无交叉；走廊 x 区间无器件侵入；
  证书字段直读。
- **B1.4 单向性**：输入白名单 grep（板框/放置/网表/层栈/规则/端点模型）；
  零读 SPEC corridors 现值、零读板文件铜、零读旧簿。
- **B1.5 回归**：当前 K2 输入跑出（可行图纸级 或 量化证书），与手写 SPEC 差异
  表落盘（authority-first：生成器输出优先）。

## 7. 不做 / 依赖裁决（编码前需清）

- 不做：芯片出逃列几何（S1 R1 职责）、连接器出逃、图纸发射、真板 DRC。
- 需布局层裁决/数据（进编码时核验并留证据）：
  a) 走廊 x_range 派生常数：U6 出逃区宽度/连接器出逃隙安全距的权威取值；
  b) up/dn 带间隔离口径：同层对间距 1.46 是否直接适用于带间，或需 GND 平面
     隔离另裁决；
  c) REFCLK F.Cu 带外路径的禁入谓词数据完备性（板上器件全集/keepout 清单）。
- 若走廊可用 y 跨度不足 → 本生成器输出证书（合法出口），不硬凑。
