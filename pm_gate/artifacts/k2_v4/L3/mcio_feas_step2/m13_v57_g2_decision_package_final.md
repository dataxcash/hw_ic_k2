## 3. 最小超授权项（唯一推荐）

**允许 R1.5 过渡段使用第 3 个信号层（或局部换层），并相应允许受影响线 via ≤ 3。**
- **闭式依据**：① 页级交叉图非二分 ⇒ 需要 ≥3 色（C12 实测）；② 6/12 帧共线行交集为空（C14 实测）
  ⇒ 这些帧必须走非共线（⇒ 需层分离）。
- **量化收益**（可复核的预期）：非共线 + 3 色 ⇒ 残余 245 → **0**；配合 R1 域/相干（r2/r3 已发射）
  预期 **R1 32/32** ⇒ `FEASIBLE_ALL`。
- **物理/合法性评估**：信号层由 2 → 3（可用信号层集合需 owner 指定，例如把某内层由平面改信号**属系统设计变更**
  ⇒ 必须 owner 裁决）；或用**局部换层**（第 3 段 via）⇒ 需放宽 `vias.high_speed.max_per_line`（当前 ≤2）。
  两项均**超出预授权范围**（触碰系统设计/电气规则）。
- **推荐**：优先「局部换层 + via ≤3」——不动层叠/层用途（无平面改信号），仅放宽单线 via 数；
  若 owner 不接受 via 数放宽，则退化为「指定第 3 信号层」。
