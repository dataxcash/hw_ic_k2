| 短端朝向 | **西短端 → J3/J4（MCIO），东短端 → J2（SlimSAS）**；长轴沿 x | [推导] 与 J2/J3/J4 实测 x 区间唯一相容 |

**0/180 选项与 A/B 侧语义** `[DS 已确认，勿重推]`：

- ball map 列带（lane n 的 4 个差分对沿长轴交错）：**A_PER@col1-2、B_PET@col7-10、
  A_PET@col26-29、B_PER@col34-35**。即**每个短端同时含 A 组与 B 组球**——
  "A 侧全左/B 侧全右"不存在，表面逃逸必穿层 [DS][推导]。
- 芯片 lane n = 一条 PCIe lane 的双向通道：下行 A_PER→B_PET、上行 B_PER→A_PET。
  A-port（host=J2 方向）球 A_PER/A_PET **分居两端**（col1-2 与 col26-29）。
- **orient-0（col1-10 朝 MCIO/西）**：西端 = A_PER(DN 输入球)+B_PET(DN_OUT 输出球)；
  东端 = A_PET(UP_OUT 输出球)+B_PER(UP 输入球)。两个**输出对组就近其目标连接器**
  （B_PET→MCIO、A_PET→J2 均为短程）→ **推荐作缺省**。
- **orient-180**：输入对组（DN/UP）就近各自连接器、两个输出对组改穿层 → 结构上等价
  （穿越对数不变，见 §4），留给 L2 摆放求解随 decoupling/strap 镜像裁定。**两选项均闭合。**

**关键澄清（回应"主机侧 8 = DN0-7 的 TX+RX 折半?"）**：PCIe lane 双向（每 lane 一收一发），
故计数不得折半。每侧走廊承载对数为：

| 侧 | 实测差分对数 | 明细 | 源 |
|---|---|---|---|
| 芯片↔J2（东走廊） | **16 对 / 32 网** | DN0-7 进（8）+ UP_OUT0-7 出（8） | [L0] J2 pad 网表 census |
| 芯片↔MCIO（西走廊） | **16 对 / 32 网** | DN_OUT0-7 出（8）+ UP0-7 进（8） | [L0] |
| ↳ 其中 J3 | 8 对（DN_OUT0-3 + UP0-3） | | [L0] J3 y43.25/45.75 两行 |
| ↳ 其中 J4 | 8 对（DN_OUT4-7 + UP4-7） | | [L0] J4 y61.45/63.95 两行 |
| REFCLK0/1 | 2 对直通（不经芯片） | J2↔J3 / J2↔J4 | [L0] |

**参与芯片的有效 lane = 8（of 16）→ 有效信号球 = 64（of 128）** [推导：DS lane=8 球 × 8 lane；
16-lane 器件超配现 x8 为架构冗余，v19 §6 #4]。

## 2. 走廊宏观闭合（每侧真实对/网数）

**差分对横截口径（用户给定，JLC 极限，自我一致）** `[推导]`：

```
线宽 w=0.205；对内 P/N 铜隙 0.175 → P/N 中心距 0.38(=0.205+0.175)
对铜跨 = 0.38+0.205 = 0.585mm
对间铜边净空 0.875 → 对中心距 pitch = 0.585+0.875 = 1.46mm
N 对并排所需横截 Y = (N−1)×1.46 + 0.585
  N=8 → 10.80mm ; N=16 → 22.48mm
```
> 注：旧冻结口径 8 对 / 8.0mm 带高（8×0.205+7×0.875=7.765，L2 v1.0 冻结）较本口径宽，
> 本预检用更紧的 1.46mm pitch 作保守判定；两口径下结论一致。

**实测 x 净跨（走廊可用长度）** `[L0 实测]`：

| 走廊 | 可用 x 净跨 | 计算 |
|---|---|---|
| 西（MCIO pad 右缘 → 芯片西缘） | **17.30mm** | 65.05 → 82.35 |
| 东（芯片东缘 → J2 信号 pad 左缘 x132.65） | **27.40mm** | 105.25 → 132.65 |

**Y 向可用带高** `[L0 板框 + 推导]`：板 y∈[33,79]（46mm）。芯片占 y[49.20,58.20]，
南北净空：**N=16.2mm、S=20.8mm**（S 向净空是 46mm 加高的实质收益：旧 38mm 板 S 仅 12.8mm）。

**判定：走廊闭合 ✓**
- 每侧 16 对 / 32 网（东 16 + 西 16，J3/J4 各 8）——**不是**旧"单层 16 线走廊"建模。
- 走廊横截（Y）按 2 带 × 8 对分工：每带 10.80mm < N 净空 16.2 / S 净空 20.8；即便最坏
  16 对单平面 22.48mm < N+S 总净空 37.0。**横截闭合**（1.46 保守口径）。
- 逃逸过渡 x 深度 ≈ 球行→带位 45° 折返 + via 落点 + 边距 ≈ 10–12mm（各方向最大 |Δy|
  ≈6–8mm + 2×via 系 3–4mm）< 西 17.30 / 东 27.40。**x 净跨闭合**。
- 旧板对照 [L1 冻结]：J2↔U 33.9mm、U↔MCIO 23.9mm（各 8 对/带 ×2 带）已闭合；
  新板东 27.4 / 西 17.3 更短，但**电容墙 32 件移除 + 双芯片合一**释放 x∈[74.95,85.15] 整带，
  走廊两端不再有墙过渡区——净效果走廊负载相等、障碍更少。

## 3. 焊盘墙穿透

**声明：无任何"焊盘墙"障碍阻挡逃逸 ✓** `[L1/v19 冻结 + L0]`

- 旧 MCIO 侧墙 C17-C32（x∈[74.95,85.15]，y 行 57.8/68.0）与 J2 侧墙 C49-C64（x∈[99,119]，y 39.4）
  = **32×220nF 0402 全部随架构转向移除**（AC 集成于 DS320PR1601 TX 脚，64 颗）[v19 §3 #2]。
- 旧 U3/U7（WQFN-64）双芯片区 x∈[88.8,99.05] 释放 [L0]。
- 真板现西走廊 x∈[65.05,82.35] 实测无 pad 障碍（仅待移除件）[L0 census]。
- 旧问题"落点须在 AC 电容之后（cap 先于 via）"（m13_mcio_escape_landing_gap_problem）——**随墙消失关闭**。
- 剩余"墙"仅为连接器本体焊盘列（J2/J3/J4 各自 pin field），属正常 pin 逃逸，非跨区障碍。

## 4. pin 逃逸可达性（交错逃逸 vs In2 容量）

**球级事实** `[DS 已确认 + 推导]`：0.6mm pitch、NSMD Ø0.3 pad → pad 间隙 0.3mm
< 0.205 线 + 2×0.09 净空 → **行内 pad 间不可穿线**。仅**最外列 ring**（col1 / col35）可
F.Cu 直出；col2/34 二环需 0.09 细颈 dogbone 才有机会、col7-10 / col26-29（4–10 列进深）
**必 via 下内层**。

| 量 | 值 | 计算/源 |
|---|---|---|
| 有效信号球 | 64（8 lane × 8 球） | [推导] |
| 可 F.Cu 直出球（col1=8 + col35=8） | ~16/64 = **25%**（且仅当该网在本地端） | [推导] lane0: A_PERn0@col1, B_PERp0@col35 泛化 |
| 需 ≥1 via 逃逸球 | ~48/64 = **75%** | [推导] |
| **穿越芯片 In2 的对/网** | **16 对 = 32 网 = 50% 球** | [推导] orient-0: DN0-7(东→西端 A_PER) + UP0-7(西→东端 B_PER)；orient-180 同数互换 |
| 每穿越网 via 数 | **2（F→In2→F）** ≤ 2 硬约束 ✓ | [L2 v1.2b 冻结 受控过孔 ≤2/线] |

**6 层叠层下的 In2 通道定量闭合**：

- 叠层 `[推导，eco_v20 §2]`：**6L F/G/S/G/P/B → 内部信号层仅 In2（带状线，上下 In1/In3 GND 参考）**；
  **8L F/G/S/G/P/G/S/B → 内部信号层 In2 + In6（+ 额外 GND 平面 + B.Cu 可用）**。
- 穿越 16 对按 N/S 翼分工：8 对/翼 × 1.46 pitch → 每翼横截 **10.80mm**。
  N 翼可用 ~16.2mm、S 翼 ~20.8mm（减 2mm via/去耦 keepout 后仍 14/19mm）→ **闭合，余量
  N≈3–5mm / S≈8–9mm** [推导]。
- 穿越走 In2 而非 F.Cu：芯片体内 cols11-25 为电源/地球区，F.Cu 不可横穿体下；In2 翼带
  （芯片 N/S 净空带）承载。与旧板"F→In2→F 单内层换层模式"同构 [eco_v20 §2 / kb corridor_pair_dual_band]。
- 局部（非穿越）对：输出对组（DN_OUT 西出、UP_OUT 东出）球在 col7-10/26-29 进深 → 仍需
  via 至 In2 短潜到芯片边缘外再回 F.Cu 走廊；同一 In2 上，短潜 stub 集中在**端区**，
  与中段翼带穿越不交叠（端区 x<6mm）→ 不争中段带宽 [推导]。

**6 层 vs 8 层定量判定（§6 汇总）**：见下，先给结论——**结构层 6L 闭合**；8L 增加的 In6
**非结构必需**，仅在（a）REFCLK 抖动隔离需专属层（§5）或（b）逃逸 stub 与穿越翼带在
求解器里打架时启用。

## 5. REFCLK0/1（2 对直通共网，不经芯片）

`[L0 实测 pad]`：REFCLK0 = J2 y45.9 ↔ J3 y45.75（x 58-59）；REFCLK1 = J2 y51.3 ↔ J4 y61.45。
两对横贯全长（~70mm）但**不接 DS320PR1601**（redriver 协议透明零 REFCLK [v19 §3]）。

| 方案 | 6L 可用性 | 争抢判定 |
|---|---|---|
| **In2 独立 guard 带**（推荐） | S 翼 8 对穿越 + REFCLK 2 对（横截 +2.0mm + ≥2mm guard ≈ 14.8mm < 19mm 可用） | 与穿越同层但分带、包地 ≥2mm [L2 冻结 REFCLK 包地]；**不争 PCIe 走廊 F.Cu** ✓ |
| F.Cu 板边微带 | N 缘 y≈33-41 与 S 缘 y≈66-77 空带可用；REFCLK0 终点 J3 y45.75 与 DN_OUT 同行区，需末段绕行 | 与 F.Cu 数据带在连接器 fanout 区有短段相邻 → 次选 |

**6L 判定：REFCLK 可闭合，不构成回 8L 的强制项**（8L 下可给 In6 专属层更干净，属 SI 裕量选项非必需）。

## 6. 结论

# 判定：46mm 单芯片 DS320PR1601 × 6 层 = 结构预检「闭合 ✓」

（走廊横截 + x 净跨 + In2 翼带 + via≤2 + REFCLK 均闭合，见 §2/§4/§5 各余量。）

**关键数字汇总**：

| # | 量 | 值 |
|---|---|---|
| 1 | 每侧走廊真实对 | 东(J2) 16 对/32 网；西(MCIO) 16 对/32 网（J3=8、J4=8） |
| 2 | 芯片有效球 | 64（8/16 lane）；信号球 128 总量 [DS] |
| 3 | 横截需求 | 8 对带 = 10.80mm（pitch 1.46 口径）；16 对 = 22.48mm |
| 4 | x 净跨 | 西 17.30mm / 东 27.40mm（过渡需求 ~10-12mm） |
| 5 | 穿越对数（In2） | **16 对 / 32 网 = 50% 球**，每网 2 via ≤2 硬限 |
| 6 | In2 翼带 | N 16.2 / S 20.8mm 可用 vs 8 对 10.80mm（REFCLK 加入后 S ~14.8mm） |
| 7 | 需 ≥1 via 球 | ~75%（25% 外环可直出） |

**6 层 vs 8 层结论**：

- **6 层（F/G/S/G/P/B）先试：闭合**——In2 是唯一内部信号层，但结构账：16 对穿越分 N/S 翼
  各 8 对 + REFCLK 均放得下（余量见上），F.Cu 走廊带每侧 8 对微带与旧板 8 对/带先例等价
  [L1 冻结走廊预算同构]。
- **回 8 层的确切触发（差在哪）**：非走廊闭合失败，而是 ① REFCLK 需专属无扰层（In6 承担，
  6L 需与其 8 对穿越同层分带）；② 逃逸 stub 密度（75% 球需 via、球下 0.6 pitch via 落点）在
  求解器中与翼带 keepout 冲突时，In6 作第二内部信号层承接逃逸/REFCLK 溢出。**缺 In6 = 少一个
  内部信号层 + 少一 GND 隔离**（8L 相对 6L 净增）。若 6L 路由验证出现上述任一项不可解 → 回 8L，
  不重跑 6L（禁暴力迭代，放不下 = 缺口报告，走包络/层数变更）。

**关键假设清单**：

1. [L1/用户裁决] 电容墙 C17-C32/C49-C64、U3/U7 及其原去耦全部移除/随新器件重布——§2/§3 的空区
   判据依赖此；摆放矩形内不再保留任何旧件。
2. [DS 已确认] ball map 列带 A_PER@col1-2、B_PET@col7-10、A_PET@col26-29、B_PER@col34-35，
   **全 16 lane 同型、仅行位平移**；本文球级计数以 lane0 位型泛化。**行级（row A..FJ）逐 ball
   坐标未逐球复核**——25%/75% via 比例、50% 穿越比例在"任一 lane 同型"下稳健，但精确逃逸求解
   需 L2 读一次 TI 完整 ball 表。
3. 差分口径 = 用户给定 JLC 极限（w0.205/g0.175/对内 0.38/对间 0.875）；较旧冻结 8 对/8.0mm
   更紧，结论在两种口径下一致。
4. 6L 叠层 F/G/S/G/P/B、8L F/G/S/G/P/G/S/B 语义来自 v20 ECO；In2 在 6L 上下皆 GND（带状线）。
5. B.Cu 保持空置（单面贴，用户已批）——若 B.Cu 允许走线，6L 实际可用信号面 +1，进一步放裕
   （本预检未依赖它）。
6. 芯片 x 中心取释空带中心 (93.8, 53.7)；±（向西/向东滑移 ≤ ±5mm）均不改变 §2 净跨闭合结论
   （西/东走廊合计 44.7mm，滑移只是互换两走廊长度）。
7. 低速/边带 24 网不在本预检走廊账内（走 In2 端区 / B.Cu / F.Cu 外围，另案），不争 PCIe 走廊。

**产出供竞标**：本预检为 L1 结构可行性证据（非最终裁决），下游 L2 摆放求解在 orient-0/180、
中心 (93.8,53.7)±滑移、8-of-16 lane 行位选择约束下产出候选 ≥2 → 竞标 → 裁决后按
freeze_ctl.sh unlock→回写 L1/L2→lock 流程正式化。
