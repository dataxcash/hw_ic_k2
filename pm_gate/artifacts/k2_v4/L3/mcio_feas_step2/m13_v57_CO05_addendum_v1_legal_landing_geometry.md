# CO-05 追加 v1 — 自纠：**落列 legality 未成立**，O4 的 0.15mm 不能据此认证

> 2026-09-11｜发起：ARCHER｜性质：**自纠 + 阻塞定因**（CO-05 的 "32/32" 用未受 legality 约束的 ±2mm 窗口）
> ｜结论：O4 需 **O2 类信息（真实连接器落盘几何）**或**长度补偿机制**，现有模型无法认证 0.15mm。

## 1. 更正
CO-05 报告的"x 窗口 ±2.0mm ⇒ 32/32 ≤0.15"**不成立**：该窗口的 x 位置未受 F-8 域合法性约束，
其中多数落在连接器焊盘列之间**非 gap**的位置（可能压在焊盘上）。按 F-8 生成器实际规则修正如下。

## 2. F-8 落列合法性（域定义，可复核）
`tools/p3_v57_f8_r3_gap_candidates.py:94-104`：合法落列 x 仅为
- **`between` 缝**：相邻焊盘列**中点** `x=(a+b)/2`；自由裕度 = `gap_width − need`，`need = via_od + 2·clr = 0.7`（域 `params.gap_fit_mm=0.7`）。
  实测 J2 中缝 `x=133.825, gap_width=1.05` ⇒ 允许区间仅 **±0.175mm**（宽 0.35mm）。
- **`left`/`right` 外侧**：`x = 最外焊盘列 ∓ (w/2+clr+via_od/2)`，向**外侧半无穷**（本板受走廊/板边限制）。

## 3. 约束化可行性（独立长度核；canonical 几何）
| 落列方案（均含 y 带内调优、无交叉、via↔via ≥0.525） | ≤0.15mm | worst |
|---|---|---|
| 现行 R3X2（内列向左/外列向右，成对分居两侧） | **0/32** | 24.5mm |
| 成对同列 | **0/32**（band 0.6 ⇒ 可用 0.5 < 0.525） | — |
| **双双落在走廊侧逃逸区**（同向） | **14/32** | 3.18mm |
| 域声明 gap 集合（±小缝裕度） | ≤21/32（其中部分解为非法同列族，需剔除 → 更低） | ≥1.78mm |
| 未受约束 ±2.0mm 窗口（CO-05 原报告） | 32/32 | 0.00mm —— **非法，作废** |

## 4. 定因（阻塞）
- 0.15mm 需要 P/N **几何等价**；而合法落列自由度（缝内 ±0.175mm、外侧半无穷但受走廊限制）与 0.6mm 的 y 带
  不足以同时抵消：`Δv1x`（0.4~2.2mm）、`POL_OFF` 0.38mm、落列差、landing y 差。
- 关键缺失信息：**落列 x 究竟在哪些位置合法**，取决于**真实连接器落盘几何（board read）**——即既有未决项 **O2**
  （W3 零板读）。当前模型（零板读）只能给出离散 gap 候选，无法证明连续性。

## 5. 处置建议（待裁）
1. **O2 类授权**：允许以真实连接器 footprint 建立落列 legality（读板）⇒ 重算合法 x 域，再判 0.15mm 可达性；或
2. **长度补偿设计（L3）**：在成对局部落列基础上，对短极注入**确定性 serpentine**（需先证在 lane 间距 1.46mm 下有绕线空间）；或
3. **成对对称逃逸架构（L2 结构修订）**：P/N 等几何、仅法向偏移（改动最大，但唯一与 0.15mm 语义一致的解）。
- **禁止**：以放宽 `intra_pair_skew_mm` 取代上述任一路径（"参数特权/放水"红线）。
