## 2. Q2 缺口性质：**方案级修输入**（非「再试一次」）
### 2.1 「两遍式全局构造」假设已被证否
上一会话 handoff §5.2 结论为「单遍贪心不可解 ⇒ 需两遍式全局构造」。本会话证明：
**不需要**两遍全局构造，**也不需要**改 lane framing；只缺**谓词的完整性与顺序语义的正确性**。

### 2.2 先定因、后改码（仪器化拒绝归因）
1. 对目标页逐候选打印「拒绝谓词 + owner」：>96% 候选被 `_va`(va_full) 拒；展开显示候选 corner via 与"已放置 via"冲突，而 owner 指向**phase-1 投机解坐标** ⇒ 缺口 = **顺序语义**（stale seed），而非几何无解。
2. 删 stale seed 后东侧全清、残余转移 ⇒ 证明"通道层不够"不是真因（同一 L2 分配下东侧已可放置）。
3. 补 vt 谓词后残余 1 条（vt 0.3066），owner 分析显示冲突对象是**尚未放置页的 pad**（固定几何、与顺序无关）⇒ 缺口 = **障碍场不完整**。
4. 另立缺口：发射层硬编码与内部规则不符 ⇒ 缺口 = **工件自洽性**（独立重算器对旧工件命中 36 tt / 82 vt，对新工件 0）。

### 2.3 为何是「方案级修输入」
- 改动对象 = **模型能力**：谓词集合（补 vt/tt）、顺序语义（去投机播种）、障碍场（固定 pad 入索引）、发射规则（按带取层）。**非参数、非模板**。
- 阈值不新造：`VT_TRACK/VT_ESC/TT_ESC` 由冻结 SPEC 派生（`:74-76`），`main()` 断言与 SPEC 一致，drift ⇒ `exit 3`（`:1047`）。
- **一次实现**：终态配置直接得 0；其后的复跑全部是**验证性**（枚举序 3×、scale 2×、validator 3×），不是在解空间里继续试。
