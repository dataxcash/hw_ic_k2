每条取 **2 处** hop ⇒ `planned_hops = 90`、**每线 via = 2 + 2×2 = 6 > 5**，**违反 R-08 的 `via ≤5`**。
⇒ 该计划**非合规**，不得据以实施（不计入任何"已实现/已收口"结论）。

2. **每条覆盖路径 1 处 hop**（不是 2 处）⇒ `via = 2 + 2×1 = 4 ≤ 5` ✓ 符合 R-08。
3. 容量核对：需 hop 路径 37 ≤ 可 hop 路径 45 ✓（1 hop/线口径下仍可行）。
4. hop 位置取该路径**最小 x 的未消解交叉**（固定键、单遍、无搜索）。
5. 实施后必须验：① 无新增同层交叉；② via-via/via-pad DRC；③ pad 区无碰撞；④ 每线 via ≤5。
