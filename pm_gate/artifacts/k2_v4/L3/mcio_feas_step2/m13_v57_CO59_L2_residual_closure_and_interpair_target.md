## 1. 残余②（handoff §4-②）机器闭合：**PASS**
判据：L4 板 `k2_v4_8L.l4.kicad_pcb` 上 B.Cu 与 In6 阻抗关键段的**并行耦合**
（夹角 ≤10°、重叠 >0.30mm、中心线横向净距 <0.50mm）。
- 并行耦合对 = **0**；全板 B.Cu×In6 并行对的最小中心线横向距离 = **20.3mm**。
- B.Cu 实体：**70 段 / 32 网 / 0 zone**（无铺铜）；与 In6 的几何关系为**垂交**（B.Cu 段为纵向、In6 长平行带为横向）。
⇒ CO-55 判"B.Cu 非阻抗控制层 ⇒ In6 关键段下方不得**并行**铺铜/走线"**已满足**；该残余项**闭合**（板零改动）。

## 2. 更正 CO-58：基线错用（把 fallback 当成了要求量）
CO-58 用 L1 v2.0 文本里的"**冻结轨距仍 1.08**"作为"冻结口径"，并据此判"交付走廊 = 冻结口径"。
机判 `route_model_config.json`（L2 冻结注入点，sha16 `71c001125959b24b`）证明该判断不成立：
```
capacity_audit.inter_pair_spacing = 1.46
capacity_audit.note = "v22 用户裁决(2026-09-05): inter_pair_spacing 语义 = 0.875 对间铜边净空
  → 对中心距 1.46mm. 引擎 capacity_audit 按对中心距(pitch)计, 故注入 1.46
  (勿用 drc_rules.json diff_pair.inter_pair_spacing=0.875, 其为铜边净空口径)"
channel_alloc.pitch_fallback = 1.08     # ← 这才是 1.08 的出处：**回退值**，非要求
```
⇒ **要求量的语义是"对间铜边净空 0.875mm"**（R3-2）；1.46 是它在**冻结对铜跨 0.585** 下的中心距换算值；
**1.08 是 `channel_alloc.pitch_fallback`（回退/缺省），不是冻结要求**。CO-58 以 1.08 为基线 ⇒ 结论过宽。
