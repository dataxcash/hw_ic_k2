# CO-05 — O4 闭合的成对落地方案（设计已验证；待实现）

> 2026-09-11｜发起：ARCHER｜依据：CO-04 裁定（L2，禁放宽 skew 预算）+ CO-04 追加 v1（证明落列调优不足）
> ｜状态：**设计已验证（32/32 可达 ≤0.15mm）**；域件与引擎实现 + 全链重跑待执行。

## 1. 目标
使 SPEC `intra_pair_skew_mm = 0.15` 成立（现况 32/32 超差，15.6~24.5mm）。

## 2. 设计（本单采纳）
1. **落列自由度 = 逐 pad 的 x 窗口**（取代 R3X2 的单元素槽）：每个 pad 的落列 `lx` ∈ `[pad列x − 2.0mm, pad列x + 2.0mm]`（0.1mm 网格）。
2. **落列 y** ∈ 该 pad `y_band`（±0.3mm，SPEC/连接器行几何给定）。
3. **成对求解**：对每个差分对，在窗口内选 `(lx_P, lx_N, ly_l_P, ly_l_N)` 使 `|L_P − L_N| ≤ 0.15mm`
   （`L` 为 CO-04 的独立长度核，对 canonical 64 网误差 0.0）。
4. **构造规则（确定性、零搜索）**：以一个极性为锚（取其 pad 列 x、band 低端 y），另一极性的 `lx` 由
   `|lx−v1x| + sqrt((connx−lx)²+dy²) = 常数` **闭式（二次）求解**；再以带内 y 消残差；越窗即钳位并出证书（不得称 PASS）。

## 3. 验证（独立长度核，canonical v1 几何；可复算）
| 方案 | ≤0.15mm 达成 | worst |
|---|---|---|
| 现行 R3X2（单元素槽） | **0/32** | 24.5mm |
| BASE F-8 候选（Δx∈{2.175,4.35}） | 21/32 | 1.784mm |
| 成对同列（lx 相同） | **0/32**（几何不可能：band 0.6 ⇒ 可用 0.5 < via-via 0.525） | — |
| 关于列中点对称（`mid±δ`） | 16/32 | 2.663mm |
| **逐 pad x 窗口 ±1.0mm** | 23/32 | 1.217mm |
| **逐 pad x 窗口 ±2.0mm** | **32/32** | **0.0000mm** |

## 4. 净距与全局可行性论证
- 每对占据**唯一连接器行**（P/N 同行的两个 pad）⇒ 不同对的 `y_band` 至少相差行距（≥1.2mm）⇒ **不同对的落列可共享 x 而不冲突**（y 分离 ≥0.6mm > via-via 0.525）。
- 对内强制 `|lx_P − lx_N| ≥ 0.5mm`（x 分离满足 via-via）。
- 走廊 run 仍在各自 `lane_y`（In2，平行）⇒ 同层交叉结构不变（预期 crossings 仍 0，需重跑确认）。

## 5. 实施要求（两遍式）
- **_placed 顺序**：R1 把落列当障碍，故落列须在 R1 前确定；而闭式求解需 `v1`（R1 输出）⇒ **两遍**：
  ① 以窗口中心落列跑一遍取 `v1`；② 按 §2.4 求解最终落列；③ 以最终落列重跑 R1（障碍索引即为终态）。
- 变更面：新版本化域 `m13_v57_f8_r3_gap_candidates_r3x3.json`（**x 窗口**替代单元素槽）；
  引擎 `r3_place` 成对求解 + `REVISION` bump（W3-CN.28）。
- **不得**改冻结四源原件；不得放宽 `intra_pair_skew_mm`；不得 partial pass。
