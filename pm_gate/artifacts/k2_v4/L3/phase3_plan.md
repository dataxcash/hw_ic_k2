## WP1 方案要点（U3/U7↔MCIO 45 网，最大块）

- 物理拓扑：U3(下行 DN, @62.7) / U7(上行 UP, @44.7) → AC 电容墙 → J3/J4(MCIO, @44.5/62.7)
- 方法与 j2-escape 完全同构：每网冻结折线（F.Cu 为主 + 受控换层白名单 In2）+ 
  确定性逃逸桩（芯片侧/电容侧固定深度 0.8/2.5 + 固定方向）+ 联合障碍场预校验
- 测量前置：MCIO 焊盘盒/电容墙走廊/芯片脚距（L2 measurements.md 已有，待补 MCIO 段走廊实测）
- 逃逸桩必须走 `escape_stub_replanner`（G3.4 门禁已强制）

### WP1 实测几何约束（2026-08-20 三轮迭代固化，v1→v2→v3）

| 约束 | 实测值 | 方案影响 |
|---|---|---|
| J3/J4 焊盘阵 x 间隙 | 0.268mm | < 线 0.205+净距 0.175=0.38 → **禁穿焊盘阵**，走线从右缘 x=65.3 接入焊盘右端 |
| 电容墙同行 x 间隙 | 0.3mm | < 0.38 → **禁水平穿行**，出线必须竖直走向行间空隙 |
| 电容墙行 y | 60.05/61.65/63.0/66.0（DN 区） | 行间空隙 y≈60.85/62.3/64.5 为水平走廊 |
| 中带禁区（U3/U4 热焊盘） | y 49.3~58.1 | 跨带网（DN_OUT1-3→J3、UP4-7→J4 共 12 网）**必须 In2 受控换层** |
| 同带网 | 14 网（DN_OUT4-7→J4、UP0-3→J3） | F.Cu 通道直连 + 焊盘右缘接入 |
| 跨带网 | 12 网 | In2 换层（宪法受控换层白名单，需 SPEC layer_plan 声明） |

**v3 出线规则（方案定死）**：
1. 电容出线：起点竖直 → 最近行间空隙 y（60.85/62.3/64.5）→ 水平沿行间走廊
2. 走廊段：行间水平 → x=65.3（焊盘右缘）→ 竖直 → 目标焊盘行 → 水平接入焊盘右端
3. 跨带网：行间水平 → stub via 换 In2 → In2 走廊竖段（避 v10 In2 冻结段）→ via 换回 F.Cu → 接入焊盘
4. 芯片↔电容短段（22 网）：U3/U7 引脚 stub → 行间走廊 → 电容焊盘

**生成器迭代轨迹**：v1 直线 4/48 → v2 通道+右缘 0/26 → v3 行间隙穿行（本轮方案定稿，施工下一阶段）
