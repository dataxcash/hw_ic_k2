# L3 执行器约束（G3.2 产物）

> 宪法第八章禁令 2：脚本禁止在运行时做任何设计决策。执行器零运行时自由度。

## 执行器判定

- **旧管线 run_pipeline.py 违宪，禁止作为 L3 执行器**（61 处违宪候选在册：stagger/force_sink/兜底/换层自适应）
- routing_engine 模块静态扫描：7 处违宪候选（stagger_fanout、Dog-bone 下沉、In2 兜底）——全部为运行时设计决策，违宪
- **L3 施工执行器选择**：KiCad GUI 人工布线（差分对模式），Python 仅做 SPEC 校验与 DRC 解析，**禁止任何自动布线器接触 k2_v4**

## 执行规则（施工工程师/AI 施工时强制）

1. 只读 SPEC_k2_v4.json，逐条执行，禁止修改
2. 高速 18 对：F.Cu 微带 w=0.205/g=0.175，0 过孔，上下带对称
3. 任何"放不下"→ **不得自行调整**，走 ECN 回 L2 裁决
4. 低速/电源：按 LOW_SPEED/POWER net class，B.Cu/In2/In4
5. 施工产物：布好的 k2_v4.kicad_pcb + 施工日志

## 验证方式（G3.2 PASS 判据）

- scan(routing_engine/) 违宪候选已登记（不可清零——它们是旧管线的存档证据）
- 施工执行器无运行时自由度（人工布线 + 只读 SPEC 校验脚本）
- 施工日志逐条对应 SPEC 项
