## V4 · 阻抗券（板厂出件）
- **索取**：向板厂索取**阻抗券报告**（含逐层 TDR/时域测量曲线与数值）。
- **覆盖要求（强制）**：须覆盖 **①最宽对内间距 0.6mm 中心几何**；**②最紧段 = F.Cu 边到边净距 0.2825mm**（位点 `PCIE_UP3` 逃逸域，见 `DISCLOSURE.md §5b-2`）。
- **测点**：F.Cu / In2.Cu / In5.Cu / B.Cu 各不少于 1 处差分对；记录 Zdiff。
- **判据**：**85.0Ω ±10%**（76.5–93.5Ω）。**注**：SPEC `[0.295,0.395]` 系**名义几何窗**（设计指导带），**非合格判据**（#K2-37 §6-2）。
- **证据**：券报告 PDF/扫描件 + 逐层数值表 + 抽样位置图。

## V5 · PDN 直流压降
- **轨**：`12V_IN` / `P3V3` / `P3V3_AUX` / `MCU_VDD`（电源面 = **In4.Cu**；GND 面 = In1/In3/In6）。
- **测点**：每轨**源端**（入板/稳压输出点）与**负载点**（最近去耦/器件供电 pad 或等效可及点）各 1 点；注明所用测点 refdes。
- **方法**：四线法优先（或经校准的数字表，记录表内阻）；**稳态**下读数；**负载条件与该轨电流须显式声明**（来源：datasheet 或保守值）。
- **判据**：压降 ≤ **预算 3%**（=`(V_source−V_load)/V_nom ≤ 3%`）。
- **证据**：测点照/接线图 + 读数记录 + 电流来源说明。

## V6-1 · 各电源轨电压
- **测点/条件**：同 V5（稳态、已声明负载）。
- **判据**：每轨电压 **±5% 标称**。

## V6-2 · MCU SWD 识别
- **接口（**已由 `INSTRUMENT_SELFCHECK.json` 机核**）**：`J13` pad1 = `SWDIO` · pad2 = `SWCLK_BOOT0` · GND；**`NRST` 不在 `J13`** —— 其测点为 `U1` pad10 / `R29` pad1 / `C73` pad1（复位观察另接）。
- **步骤**：连接调试器 ⇒ 读 **device ID**（读不到则记录复位/debug 口状态）。
- **判据**：device ID **与器件手册一致**（记录实测值与标称值）。**二值**。

## V6-3 · FRU（I2C EEPROM）
- **总线**：`I2C1`、`I2C2`（见 SPEC `pd.decoupling` 与原理图）。
- **步骤**：总线扫描 + 读 EEPROM 前 16 字节。
- **判据**：**地址应答正确**（与原理图/BOM 标称地址一致）且内容可读。**二值**。

## V6-4 · 链路（**双路 x4 Gen4 训练**）
- **端口**：`J2` / `J3` / `J4`（PCIe 通道；中继 = `U6` DS320PR1601）。
- **步骤**：按 `ORDER_NOTES.md` 的工艺通道 A 匹配的调试环境插入主机 ⇒ 读取链路训练结果：**速度、宽度、LTSSM 终态**；两条方向/端口均须记录。
- **判据**：**x4 Gen4（16 GT/s）训练成功**（二值）。
- **证据**：`lspci -vvv` 摘录或厂商工具截图（含 Speed/Width/AER 段）+ 训练日志。

## V6-5 · 稳定性
- **条件**：V6-4 训练成功后，连续运行 **30 分钟**。
- **判据**：**AER 计数 = 0**（PCIe 高级错误报告）；同时记录链路是否降速/掉链。
- **证据**：kernel/`lspci` AER 段前后对照 + 时长证明。

## V7 · 热验收（O2 定案 · L2 v2.0 / CO-204）
- **装配前置（强制）**：`U6` = **30×30mm 铝散热片** + **界面垫 1.0 ℃/W** + **~2 m/s 风冷**；未按此实施 ⇒ 直接记 **T1 触发**。
- **工况（四）**：`U6_EQ0-2_typ` 4.7W / `U6_EQ0-2_max` 6.0W / `U6_EQ5-19_typ` 5.8W / `U6_EQ5-19_max` 7.0W（定义见 L2 裁定）。
- **测点/方法**：`Tj(U6)` = 贴附 case-top 热电偶（记录固定方式/导热膏）或红外（**须声明发射率**），按 `Tj = Tcase + P·θJC_top(6.5)` 或仪器直读换算；**Ta 须实测记录**（判据设计基准 40.0℃）。
- **判据**：四工况 **Tj ≤ 120.0℃**（设计预测 91.7/106.0/103.8/**117.0**）。
- **触发条款**：
  - **T1**：实测 `Tj(U6) > 117.0℃` **或** 未按 O2 实施 ⇒ **立即开新 rev**，量化目标 `θJA_eff ≤ 9.5 ℃/W`（回 P3/P4）。
  - **T2**：`U6` 域几何因他因修订 ⇒ **同 rev** 一并补 GND via 阵列。
- **证据**：四工况原始曲线/读数 + 装配照 + Ta/风速记录。
