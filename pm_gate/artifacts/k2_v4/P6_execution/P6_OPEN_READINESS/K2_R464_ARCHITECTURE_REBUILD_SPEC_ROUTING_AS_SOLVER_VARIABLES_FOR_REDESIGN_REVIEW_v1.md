## 2. 规则 R1–R6（每条：规则 / 分离义务 / 可复现断言 / 对应负控）
### R1 首段 · 只准竖向
- **规则**：(A_x,A_y) 垂直至 (A_x, SY(s_i))。**禁**锚点 y 横移；**无**调整量。
- **分离义务**：|ΔA_x| ≥0.500
- **断言**：入口区逐对最小距 ≥0.435
- **负控**：强令两线首段同列 ⇒ 不合格

### R2 南带长走行 = 求解器变量
- **规则**：水平段位于 y=SY(s_i)（**s_i 由求解器拍板**，非模板常量）。**禁**吸附/对齐。
- **分离义务**：s_i 互异 ⇒ 行距 ≥0.435
- **断言**：南行集合两两 ≥0.435
- **负控**：① 同 s 必不合格；④ 注入吸附 ⇒ 单射/几何断言必抓

### R3 端口穿越列 = 求解器变量
- **规则**：在 x=PX(p_i) 竖向贯穿南北两行。
- **分离义务**：p_i 互异 ⇒ 列距 ≥0.435
- **断言**：端口列两两 ≥0.435
- **负控**：② 同 p ⇒ 不合格

### R4 横向段端点固定 · 单调嵌套
- **规则**：南行横段 x∈[A_x, PX(p_i)]；北行横段 x∈[PX(p_i), B_x]；**端点固定、无调整量**；三坐标随 A 锚 x 序**单调**（方向由求解器选）。
- **分离义务**：单调嵌套 ⇒ 折线两两 ≥0.435（含横×竖）
- **断言**：**在册闸** n_lane_pitch_viol==0
- **负控**：注入非单调 ⇒ 不合格

### R5 北带长走行 = 求解器变量
- **规则**：水平段位于 y=NY(n_i)；至 (B_x, NY(n_i)) 后垂直入 B。
- **分离义务**：n_i 互异 ⇒ 行距 ≥0.435
- **断言**：北行集合两两 ≥0.435；出口区逐对 ≥0.435
- **负控**：③ 同 n ⇒ 不合格

### R6 障碍净距（域表达 · 渲染器零调整）
- **规则**：把投影后不满足净距的 (p,s,n) **从域中剔除**。
- **分离义务**：净距 ≥ max(0.175, req)（孔到铜 0.25）
- **断言**：**在册闸** n_clearance_viol==0 ∧ clearance_min_mm ≥0
- **负控**：⑤ 可构造形态违约实例（产出前判不合格）

## 3. **评审新格**：形状族摆得下吗？（表达力/可解性）
