## 2. **新发现：宽变 303 段 0.10mm**（归修复清单）
| 网 | l8 | l9 |
|---|---|---|
| `PERSTA#` | 88×0.20 | 75×0.20 + **278×0.10** |
| `DS320_STRAP_B_ADDR0_15-8` | 31×0.20 | 31×0.20 + **18×0.10** |
| `DS320_STRAP_B_ADDR1_7-0` | 35×0.20 | 24×0.20 + **4×0.10** |
| `I2C1_SDA` | 160×0.20 | 157×0.20 + **3×0.10** |

- **根因**：施加器 `K2_R373_CW_RELOCATION_APPLIER_v1.py` 之 `seg(..., w=**0.1**)` **默认宽**（R413 同源）⇒ 搬迁生成之铜一律 0.10mm，未按网类/原网宽回填。
- **相对在册**：0.10 ≥ 0.09（冻结/JLC 下限）⇒ **过下限**；但冻结 SPEC `net_classes.LOW_SPEED.width = 0.15`（该 4 网属默认类）⇒ **低于类别宽**（而 l8 之 0.20 高于之 ⇒ 板在 l8 即非网类共形）。
- **判**：**网类宽度无在册应然项（19 维亦无）⇒ ENG 不自判 PASS/FAIL、不自立判据**；仅登记为 **宽变读数（现网铜 −50%）** 并**并入修复清单**（与回填/45°/冲突同批）。
