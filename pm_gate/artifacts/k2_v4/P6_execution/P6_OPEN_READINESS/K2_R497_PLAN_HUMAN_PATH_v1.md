## 一、①信号怎么走
16 条上行差分线（`PCIE_UP_OUT0..7_{P,N}_J2`），每条两端各只有一个孔：
- **西端 A**（SoC 侧 · F–B 贯通孔）：x≈84.35–93.70 · y≈54.88–55.82（**A 的 x 序整齐**：0_N,0_P,1_N,1_P,…,7_P）
- **东端 B**（J2 侧 · F–In2 盲埋孔）：x≈127.01–141.42 · y≈42.65–52.85（**B 的 x 序是乱的**：0_N 127.01 · 0_P 141.22 · 1_N 139.48 …）

信号**只能走 In5 一层**，且**每线最多 2 个过孔**（A、B 各一，中途不加孔）。所以每条线的走法是：
**A 出来 → 往南钻到墙下面 → 在墙南边那条宽走廊里往东 → 从唯一的门（x≈135.45–143.05）钻回北边 → 在北区迷宫里绕到自己的 B → 落到 B。**

## 二、②挡路的是什么（逐段）
1. **墙**：缝合孔场＋`PERSTA#` In5 铜带（y 55.15–56.10 · x 105.6–133.7）＋J2 孔列（x 133.2–136.3）横在中间 ⇒ **南北唯一通道只有 x≈135.45–143.05 的 7.6 mm**（0.435 中心距下**正好 18 个门位子**）。16 条线全挤这一个门。
2. **西端下落被堵**：y≥56.5 时 x≲84.7 是障碍块；实测（R486/R490）**下落竖列只在 x≳84.87 以后可用**。所以线必须先往东挪一点再往下钻。
3. **南走廊本身是好的**：y≥57.9 整行从 x 84.87 到 142.72 **全空**（宽 26 行）⇒ 这是唯一的"分道走廊"。
4. **北区是迷宫**：B 锚彼此只差 0.58 mm，而锚的禁近圆半径 0.43 mm（0.25 孔到铜＋线半宽 0.08＋孔半径）⇒ 相邻两个 B 锚的禁近圆几乎贴死；能把"门东区"通到"x≈127–133 中区"的横向通路**只剩第 7 行（y=44.045）与第 25 行（y=51.875）**两条（外加零散短段）。
5. **门柱本身**：x≥136.2 的门柱从 y≈46 到南走廊是通的；x 在 [136.2,137.9) 的行 8–11、x<138.81 的行 20–23 有局部堵点 ⇒ 门柱要挑着用。
6. **北区顺序不能"洋葱"**：南走廊里两个端点集合（A 门位子 ↔ 门）落在同一条边上 ⇒ 门位子顺序**必须**与 A 的 x 序一致（否则南边就交叉）；但 B 的 x 序是乱的 ⇒ 北区**必须"把顺序解回来"**，靠第 7/25 行这两条"单行街"分层错车，**不能**靠简单嵌套弧线。

## 三、③人类方案（大白话）
**一句话：16 根线过一个窄门 · 谁坐哪个位子 → 谁走哪条皮带 → 谁用哪条北街。**
1. **定门口座次**：门位子按 A 的 x 序自西向东发（**发牌顺序不能由序号预先钉死，要交给求解器**）。
2. **定南走廊"皮带分层"**：南走廊 26 行当皮带；往东走得越远的线、皮带层要越深（最外/最深），这样南边天然不打叉 = **洋葱嵌套**。
3. **定下落列**：每条线从 A 出来先往东挪到自己的下落列再往下钻（西端不能直落）；下落列要与皮带层配好（深的先落、浅的后落）。
4. **北区走"单行街"**：钻过门后，各线按自己的 B 位置挑第 7 行或第 25 行错车，绕开别人 B 锚的禁近圆，最后落到自己的 B。
**机器化**：变量 = 每线的 {门口位子 · 皮带层 · 下落列偏移}；约束 = 位子互斥 + 座次随 A 序单调 + **真实折线两两中心距 ≥0.435** + 障碍/锚禁近；**一次求出**。
