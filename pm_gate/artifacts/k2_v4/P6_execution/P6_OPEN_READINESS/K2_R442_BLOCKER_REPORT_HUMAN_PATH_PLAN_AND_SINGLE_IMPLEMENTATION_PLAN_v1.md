## 一、人类工程师路径（大白话）

### ① 信号怎么走
**信号怎么走**：16 条高速差分线上行（`PCIE_UP_OUT0..7_{P,N}_J2`）从 SoC/U6 侧的 **A 锚**（F–B 通孔 · x≈84–94 · y≈55）出发，要到 J2 连接器侧的 **B 锚**（F–In2 盲孔 · x≈127–141 · y≈43–53）。冻结要求（②-UP=16/16）规定：**只在 In5 一层上长走、全程最多 2 个过孔** ⇒ 路径就是一句话：**A 孔 → 下到 In5 → 沿 In5 一路走 → 到 B 孔 → 上到 F/In2**。中间不许再换层、不许加孔。

### ② 挡路的是什么
**挡路的是什么**：A 锚与 B 锚之间横着一道**墙**——① 缝合孔场（x≈82–118 · y≈48–55.5）② `PERSTA#` 的 In5 铜带（y≈55.15–56.10 · x≈105.6–133.7）③ J2 连接器通孔列（x≈133.2–136.3）。它把南侧（A 区）与北侧（B 区）隔开，**唯一的南北通道口只有 x≈135.45–143.05 那 7.6mm**（按 0.435mm 中心距刚好排得下 **18** 条线位）。所以每条线都必须：出 A → **往南绕到墙下**（南通道 y≈57–68）→ **往东跑到东口** → **从东口往北穿**过 y≈54.9 → 进北区 → 再拐到自己的 B 孔。**16 条线全挤这一个 7.6mm 的口**。另外：线对线留 ≥0.435mm（中心距），线对他网铜留 ≥0.175mm、对过孔留 0.25mm。

### ③ 人类方案
**人类方案（大白话）**：这是**「16 根线过一道窄门，谁坐哪个位子」的排座次问题**，不是「找不到路」——实测**每条线单独都走得通**（R438：16/16 可达）。做法三步：**(a) 先定门口的座次**（18 个位子，按各线 A 锚从西到东依次占位——先到先得、不许插队）；**(b) 再定绕墙的层级**（最西那条线走**最外圈/最深**，往东依次往里收 = **洋葱式嵌套**，这样线之间天然不打叉）；**(c) 每一段都按空地直着连**（沿可通行带画阶梯：走不通就换到隔壁一条空带，段数固定、不试探）。⇒ 对应到机器：**决策变量只有「每条线的门口位子 + 南通道层 + 北区层」**（百级）；**约束 = 座次单调（防叉）+ 位子互斥（一位一线）+ 间距 ≥0.435**；**一次求出**。

## 二、《卡点报告》

**试过什么**
- **① 自由格点流**（0.435 格点 · 8 连通 · 16 商品路径 · 113,280 布尔）⇒ 受证一次跑 **900s 返回 UNKNOWN**
- **② 严格『单程直行』三层位**（南通道层 × 端口槽 × 北区层）⇒ 域近乎空（S=7/T=1 · 4 网 S=∅ · 3 网 T=∅）
- **③ 结构化『逐槽 BFS 最短路』候选 + 节点互斥 + 单调槽序**⇒ **候选互相重叠** ⇒ 平凡 **INFEASIBLE @0.0s**

**为何不通**
- ① 错在**编码形态**：把「排座次」写成了「在几万个格点上让 16 条线各自找路」——搜索空间爆炸，等于用搜索撞答案（违第八章精神）
- ② 的『整段直行』是我自己加的过严判据（要求一条线在同一 y 上一口气横穿 40mm）——**同批 R438 已实测证伪**（逐网可达 16/16，真实通路是多段阶梯）⇒ 该结论是**伪结论**，已作废
- ③ 错在**候选如何生成**：我用「最短路」生成候选，得到的是**同一批重叠路线**；而这个问题需要的是**一族互相错位的嵌套路线**（洋葱层）⇒ 候选族里根本没有「互不侵占」的组合 ⇒ 模型一写就无解（且是**编码性无解**，与几何无关）

**缺口在哪层**
**缺口在实现层（候选族生成算法）**，不在需求层（②-UP 冻结要求清楚）、不在几何层（路是通的：R438 16/16）、不在判据层（R401 预登记口径未动）。

**结论**
**问题可解、形态已具名**；缺的是把「第 k 条线的第 s 个门口位子」映射成「沿第 (s+k) 层带的一条阶梯」这一步**生成算法**。前两轮花在了错误形态上，第三轮花在了错误生成法上——**皆属我的实现问题，非需求/几何问题**。
