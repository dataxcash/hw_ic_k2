## 一、本版与上一版的**唯一**差别（针对具名死锁）
上一版具名死锁：**南走廊嵌套**要求「A 越西 ⇒ 行越深 ⇒ 门位子越东」，**北区终止**要求「B 越西 ⇒ 出口越西」；
`0_N`(B x=127.01，最深) 与 `0_P`(B x=141.22，最浅) 两端要求相反 ⇒ 该线对必真穿越（实测最接近的一对只差 1 处，位于出闸节点之后）。
本版**只打开被判死的那个自由度**，其余（搜索栅/校验栅分离、在册尺逐段复核、真穿越判据、模型骨架）**原样沿用本窗已绿资产**：

| 自由度 | 上一版 | **本版（新）** |
|---|---|---|
| 皮带行 R × 门位子 e | **绑死**（e = e(ℓ)，ℓ 即行） | **解耦**：e 独立取值，允许「行深 + 位子西」与「行浅 + 位子东」任意配对 |
| 北区解序 | p2 = 单条最短路径（⇒ 只能"出闸即横切"） | p2 = **三段式显式 waypoint**：①出闸 → ②上街 m ∈ {7,25} 横向走到**解序列 x_r** → ③折返落 B |

## 二、候选族（元组 → 折线一一对应 · 确定性生成）
```
候选 = ( R ∈ 39..61 )                      # 皮带行（23 行，容纳 16 线各占一行）
     × ( e ∈ E(18) )                       # 门位子，与 R 解耦
     × ( m ∈ (7, 25) )                     # 北区单行街（仅有的两条可长距离错车的街）
     × ( x_r ∈ 解序列候选：由 B 的 x 序排出的一列，取 ±2 邻域 )   # 回折列
     × ( k ∈ {0,1,2} )                    # 锚区下落列微调
```
- **p1**（A → 门节点 (E[e], 36)）：8 邻格 Dijkstra，横向步按 `|j − R|` 加权（皮带偏置），下落带软代价（k）；**允许**在锚区东侧带内选择下落列。
- **p2**（门节点 → B）：**三段式**——(i) 北上腿；(ii) 沿街 m 横走至 x_r；(iii) 折返落 B。
  **硬要求**：北上腿必须落在**所有更浅皮带的东端以东**（本版由冲突表精确保证，不靠掩膜；仍加一个**代价项**引导到合规解）。
- **折线 = [A] + p1 + p2 + [B]**；**子链分别 taut**（保 waypoint），逐段过**在册尺**。
