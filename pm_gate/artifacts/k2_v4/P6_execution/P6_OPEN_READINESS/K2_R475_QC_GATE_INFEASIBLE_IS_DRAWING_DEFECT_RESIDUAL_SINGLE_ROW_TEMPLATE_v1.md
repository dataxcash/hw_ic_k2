## 二、定性（本件核心 · 可机核的核）

### 2.1 闸 INFEASIBLE 的直接核 = **强制公共跨段的行位容量 <16**

任一 lane 的南带走行横段 = `[CIN[ci], PX(p)]`，而 **`CIN[ci] ≤ 95.745`、`PX(p) ≥ 135.45`**
⇒ **每一 lane 的该横段必含公共跨段 `[95.745, 135.450]`（宽 39.705mm）**
⇒ 其**行高 y 必落在『公共跨段全清』之自由 y 集内**；且 16 lane 的两两互距须 ≥ 0.435
⇒ 该模板之容量上界 = 该自由集在 0.435 节距下的**一维打包容量**。

实测（在册 margin 口径 `PAD_EXTRA = 0.1212`）：

| 量 | 值 |
|---|---|
| 公共跨段全清 y 集 | `(57.90,58.55) (59.67,59.75) (60.87,61.49) (62.67,62.75) (63.87,67.13)` = **5 段 / 共 4.69 mm** |
| 0.435 打包容量 | **14** |
| 车道数 | **16** |
| **⇒** | **14 < 16 ⇒ Hall 失败（同 #K2-165/166 之 9<16 型）** |

**独立路径复核**：逐 lane 由逐腿表（L1 竖出 + L2 南横）合成的 `s` 域 —— **16 网之 `s` 域完全相同**（`n_distinct_lane_row_sets = 1`），即**无任一 lane 享有额外行位** ⇒ 上界 14 为**全板共有**之上界。**故闸之 INFEASIBLE 系「残余单走行模板」之容量缺陷，非 lane 间冲突所致。**

### 2.2 稳健性 / 反向核（**排除**「板上无解」⇒ **不得**出不可行证书）

| 口径 | 公共跨段全清 y 集总长 | 0.435 打包容量 |
|---|---|---|
| **在册 margin**（PAD_EXTRA = 0.1212） | 4.69 mm | **14 < 16** |
| **无 margin**（纯物理间隙口径） | 6.09 mm | **18 ≥ 16** |

⇒ 该模板之不可行**由在册 margin 口径所致**，**不是物理不可行** ⇒ 依 #K2-166 §四.4③ / #K2-169 §四.3.e，**不得**据此出「含核不可行证书」（假证书）。

**夹缝截面反向核**（H3）：夹缝处 `x = 133.5`、南走廊带 `y ∈ [56.2, 68.0]`，自由 y 集 `(57.78,58.70)(59.52,59.81)(60.78,61.61)(62.58,62.84)(63.75,67.97)` = 6.52 mm ⇒ 0.435 打包上界 = **17 ≥ 16**（弱口径 0.335 下 = 21）⇒ **板上不被排除**，与在册 **R393（切面容量 28）/ R395（一般曲线 min-cut = 16）** 一致。

> 合起来：**板有解（min-cut ≥16）**，而**「单条水平南走行」之模板容量只有 14** ⇒ 历轮同族失败之根因在**图纸的残余形状模板**，不在算法、不在题、不在板。

### 2.3 与在册记录对齐

- **R325**（在册）：『单条水平长走』模型不成立 ⇒ **任何解必须含 ≥ 1 次层内折返（jog）**。本件**定量坐实**之：单走行模板容量 14 < 16。

- **R393 / R395**（在册）：切面 28 / 一般曲线 min-cut 16 ⇒ **不可行证书不可能建立**（本件复核一致）。

## 三、结论（§四.3.a 之定性）

1. **闸判 INFEASIBLE 之性质 = 图纸缺陷（残余『单走行模板』自由度不足）**，依 §四.3.a ⇒ **回建图补足缺失自由度**（**不耗求解额度**）。**禁**以之报「不可行」。
2. **不得出不可行证书**：§2.2 已证模板之不可行由 margin 口径所致，且夹缝容量 ≥16。**通向 owner 之路（#K2-169 §四.3.e）本轮不触发。**
3. **图纸修补之最小充分面（本件给出）**：南带走行**不得钉为单条水平行**；须把 **层内折返（jog）** 一并入模（承 R325）——即走行自由面为
   `锚侧竖列 ci → 西段行 s → 折返列 xj → 东段行 e（夹缝行位）→ 缝口列 p → 北段行 n → 北侧竖列 co`，
   **七类对象全为求解器变量 · 生成器仍为纯投影 · 零残余模板**（承 R450 / R466 架构不变量，不倒退）。
4. **本轮状态**：**本轮未出二值终局**（属 §四.3.a 授权之**图纸缺陷修补步**，尚未进入开跑）。据实呈报、不自修补、不动参数。
