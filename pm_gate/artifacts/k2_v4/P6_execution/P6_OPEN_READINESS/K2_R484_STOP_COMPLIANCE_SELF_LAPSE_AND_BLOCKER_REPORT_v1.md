## 二、①信号 / ②挡路 / ③人类方案（大白话 · 一分钟版）

- **① 信号**：16 条 **J2 PCIe 上行**差分线。起点 **A 锚 = 贯通孔**（In5 可 0 孔起步）；终点 **B 锚 = 埋孔**（只到 In2 ⇒ 下潜 **1 孔**，≤2 孔 ✓）；长走**全在 In5 单层**。路当中一道墙（缝合孔场 + `PERSTA#` 带 + J2 孔列）⇒ In5 上**只剩一扇门**（`x≈136.0–143.1`）⇒ 16 条只能：**南下进南走廊 → 东行 → 挤过那扇门 → 北上 → 接 B**。
- **② 挡路**：**板有解，是我们的图纸把路画死了**。实测：夹缝**可穿层位恰 16**（`57.90…67.83`）；其中 `67.39/67.83` **只能「东跨」**（`x≤126.24` 在 `y≥67.13` 被南墙封死）⇒ 必须靠**夹缝以西的竖直折返**接上；该竖段的 y 跨度**会被其余每条线的横段穿过** ⇒ 其余层位被迫 ≤66.26 ⇒ 长跨层位只剩 **12** ⇒ **12+2 = 14 < 16** ⇒ **「曼哈顿(H/V)折线」这个图纸形状不可能**（可机核；与在册 **R446 构造式上界 14/16** 同数）。
- **③ 人类方案**：**别用直角折线，改用斜段「扇入」**——每条线锚侧下落一小段后，**一条斜段**直接斜插到夹缝入口的 16 个层位（16 条像折扇一样嵌套、互不相交），再水平进那扇门。这样**走廊里不再有竖折返**，14<16 卡点**整条消失**。冻结要求只限「单层 / ≤2 孔 / 端点不动 / 两两 ≥0.435 / DRC 干净」，**未禁斜线**。
