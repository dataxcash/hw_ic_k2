## 一、为什么换形状（承 R481）

R481 已证：**曼哈顿（H/V）架构下容量上界 = 14 < 16**（可机核）——卡点是**折返竖段占道**：2 个"仅东跨"层位（`67.39/67.83`）必须靠夹缝以西的**竖折返**接上，而该竖段的 y 跨度（下沿 ≤66.695）会被**其余每条线**的横段穿过 ⇒ 其余层位被迫 ≤66.26 ⇒ 只剩 12 个长跨层位 ⇒ 12+2=14。

## 二、新形状：**一条斜段代替"竖折返 + 横段"**

每条线：
```
A ─(竖列 ci 下落, 至 s)─┐
                        └─(一条直线斜段)─► (x_entry, e) ─(水平横段 e)─► 门列 PX(p) ─► 北上 ─► B
```
要点：**斜段独占"从走廊到夹缝入口"的整段行程**，于是**走廊内不再有竖折返** ⇒ R481 的"竖段占道"整条卡点**消失**；16 条斜段彼此**单调嵌套（不相交）**，水平段只在 `x ≥ x_entry` 处出现（彼此层位两两 ≥0.435）。

## 三、构造规则（本件给出 · 供单发实现）

1. `ci_u = A_x(u)`（**无初始横段** ⇒ 与 A 锚零距离 ✓ 端点不动 ✓）；按 A_x 升序索引 `u=1..16`。
2. 下落终点 `s_u` **随 u 递减**（⇒ 与 `ci` 反序，避免斜段撞他网竖列——即 R481/K2 规则）；取 0.435 阶梯。
3. 入口层位 `e_u` **随 u 递减**，取**夹缝 16 层位** `F = {57.90 … 67.83}`（R481 实测）。
4. 斜段 = `(ci_u, s_u) → (x_entry, e_u)`；因 `s`、`e` 同向递减 ⇒ 16 条斜段**嵌套不相交**（两条不相交直线段的最小距离在端点取得 ⇒ 只需端点距 ≥0.435 即可核）。
5. 入口横坐标 `x_entry` 受**走廊天花板**控制（实测）：`x=98→67.13 · 110→67.13 · 120→67.46 · 126→67.40 · 129→67.96`。⇒ 除 `e_u ∈ {67.39, 67.83}` 两条外，`x_entry = 126.5` 即可；该两条需 `x_entry ≥ 128.5` ⇒ 其斜段带**一个膝点**（先缓升到 ~67.0 @x≈127，再升至 `e_u`）——**仍是任意角折线**，不违冻结要求。
6. 水平段 `(x_entry, e_u) → (PX(p_u), e_u)`：`p` 两两互异（16 门列 `x=136.2…142.7`）；`e` 与 `p` **反序**（承 R259F 次序反转，防门列穿他网横段）。
7. 北侧沿用 R466/R480 结构：`门列 PX(p) → 北上至 NY(n) → 西行至 co → 至 B`；`n` 与 `p` **反序**。
