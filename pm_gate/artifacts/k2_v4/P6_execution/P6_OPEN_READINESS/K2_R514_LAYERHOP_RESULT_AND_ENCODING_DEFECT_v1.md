## 三、机器坐实的**编码缺陷**（承 R512 · 与本轮 INFEASIBLE 的归因）

R512 §"(b) EXACT per-lane clearance encoding" 的线性实现：
```
E(r) = 以 r 为【端点】的弧 ; S2(r) = 以 r 为【严格影子】的弧
每车道 l:   sum_{l'!=l} S2(r) + M * y(l,r) <= M ,   M = |others| + 1
            y(l,r) = sum(E(r) 中属于 l 的弧) + [src_l == r]      ← 注释自称 0/1 指示
```
**缺陷**：`sum(vs)` 是**计数**。一条**穿过** r 的车道有 **2** 条弧以 r 为端点 ⇒ `y = 2` ⇒
`sum(others) + 2M <= M` **恒假**（`others ≥ 0`）⇒ **连 `others = 0`（他线并未靠近 r）的合法配置也判不可行**。

**证据 ①（最小实例 · `K2_R514_ENCODING_DEFECT_PROOF_v1.py`）**：
| 配置 | v1 形（`y = sum(端点弧)`） | 指示式（`y ∈ {0,1}`） |
|---|---|---|
| **合法**：A 穿过节点1 · B 未靠近（`yB = 0`） | **INFEASIBLE（假否定）** | **OPTIMAL（正确）** |
| 非法：A 穿过节点1 · B 影子扫到（`yB = 1`） | INFEASIBLE（正确） | INFEASIBLE（正确） |

**证据 ②（实模型结构性计数）**：R514 `full` 实模型 **191,053** 条净距约束中，**187,309 条（98.04%）** 所在的 (格点, 车道) 上该车道有 ≥2 条候选端点弧 ⇒ 只要它走到该格点，约束即恒假 ⇒ 该格点对该车道**「禁止穿过」**。

**证据 ③（为何 R513 的 T3 漏过）**：T3 验的是**判据**（"shares a node ∨ endpoint of one is a strict shadow of the other"，`K2_R513_DECISIVE_TRIAGE_v1.py:72-75`）——**判据本身确实与在册尺逐对等价**（该结论**不受影响**）；缺陷在**线性实现**（把 0/1 指示写成了求和），T3 **未覆盖**。

## 四、缺陷修复（v2 · **一次实现缺陷修复** · R494 先例）
