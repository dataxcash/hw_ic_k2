## §1 红线（禁，违即停并出冲突报告）

R-1 **暴力 / 随机坐标试错**：以未声明的随机数、未声明的连续参数扫描、或以「碰运气+取读数」替代构造，来寻找坐标/形状/拓扑。
R-2 **非确定性**：同一输入不保证同一输出（含依赖运行顺序、未声明种子、时间、并发调度者）。
R-3 **伪造 / 编造几何**：写出未经计算或未经声明源推导的坐标、尺寸、连通性。
R-4 **绕过冻结输入**：修改 `k2/_shared`、冻结四源、历史工件，或以其未声明的副本替代权威输入。
R-5 **partial pass**：在判据未全部满足时以「部分通过」结案；或以家族受限/工具不足的负结果冒充「物理不可行」。
R-6 **伪造 sign-off**：代填输入、代签评审、自称通过。

**机判化判据（可被第三方复算）**：凡产出须附 (i) 输入集（文件 + sha16）、(ii) 确定性构造规则说明、(iii) 复现命令；(iv) 同输入两次运行**逐字节一致**。缺任一项即视为触碰 R-1/R-2。

## §2 基本功（必须允许且必须具备）

B-1 **确定性算法**是**允许且必须掌握**的能力，包括但不限于：
   - 图搜索 / 迷宫法（BFS、Dijkstra、A*，边权由声明净距/障碍闭式给出）
   - 计算几何（可视图法、扫掠线、多边形布尔、闭式偏移/内缩、可见性绕障）
   - 闭式推导、约束传播、动态规划、线性/整数规划（声明目标与约束后由求解器给出唯一最优解）
B-2 上述算法产出**唯一、可复现**结果，**含绕障（obstacle avoidance）**，即为合规。
B-3 工具能力缺口（只会凸形 / 只会从预声明菜单挑形状，遇障即拒解）是**工具缺陷**，不是「物理不可行」，不得据此升级 owner。
B-4 每次 L2 自裁动作须留证据：命令 + 原始输出 + commit hash。

## §3 划界：禁「暴力试坐标」≠ 禁「确定性算法」

| 情形 | 判定 | 理由 |
|---|---|---|
| 8 向 × 半径梯穷举、逐点取读数、择优「挑一个能过的」 | **红线（R-1）** | 未声明参数的连续扫描 + 择优 = 试错 |
| 随机扰动 + 蒙特卡洛取可行解 | **红线（R-1/R-2）** | 非确定性 |
| BFS/Dijkstra/A* 在**声明网格**上求**声明代价**下的最短可行路径 | **基本功（B-1）** | 输入定则输出定，可复现 |
| 可视图法 / 扫掠线 / 多边形布尔构造绕障区域 | **基本功（B-1）** | 闭式几何，唯一解 |
| 由声明坐标 + 声明净距**闭式偏移**出边界（如 antipad + 0.2 moat） | **基本功（B-1）** | 闭式推导 |
| 声明 palette（有限、由障碍派生、含取用序）+ 取首个合法位 | **基本功（B-1）** | 有限且由输入派生 ⇒ 确定性；但**palette 之外不得延伸扫描** |
| 家族受限 ⇒ 直接判「不可行」并升级 | **红线（R-5）** | 以工具不足冒充物理不可行 |

**边界判据**：算法须能写出「同一输入 ⇒ 同一输出」的构造规则；规则中的任何自由度（阈值、序、跳数）**必须由输入数据闭式派生或显式声明**，不得由「试到能过为止」决定。
