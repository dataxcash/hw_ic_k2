## 1. 走廊容量闭合（F.Cu 微带，w=0.205/g=0.175，对间 ≥0.875mm — 工艺常识 R3-2 3W 原则）

每对差分占宽 = 2×w + g + 对间 = 2×0.205 + 0.175 + 0.875 = **1.460mm**（工艺常识强条 PCB_DESIGN_RULES v1.0）

### J2↔U 走廊（净宽 33.82mm，容纳 8 对）

- 需求：8 × 1.460 = **11.68mm**
- 容量：33.82mm
- **闭合：11.68 ≤ 33.82，余量 22.14mm（65.5%）** ✓

### U↔MCIO 走廊（净宽 23.93mm，容纳 8 对）

- 需求：8 × 1.460 = **11.68mm**
- 容量：23.93mm
- **闭合：11.68 ≤ 23.93，余量 12.25mm（51.2%）** ✓

### 结论

- 对间间距按工艺常识提升至 0.875mm（3W）后，每对占宽 1.104→1.460mm（+32%）
- **两条走廊仍大幅闭合**（余量 65.5%/51.2%），容量充足
- 蛇形窗口（每对 ≥10mm×2mm）另占走廊长度方向，已在 §2 等长预算中核算

## 2. 等长预算闭合（对内等长 <0.15mm，总链路预算）

### 段长（实测）

- J2↔U：x∈[98.83,132.65] → ~33.8mm 直段
- U↔MCIO：x∈[64.90,88.83] → ~23.9mm 直段
- AC 电容逃逸：芯片焊盘→电容→走廊 每段 <3mm

### 蛇形补偿

- 对内差 <0.15mm：蛇形区最小节距 3×w=0.68mm，振幅 0.3mm → 每节补偿 ~1.2mm 差
- 单走廊可用蛇形长度（预留 50% 走廊）：16mm（J2↔U）/ 12mm（U↔MCIO）
- 可补偿对内差上限：16mm/1.2mm×0.15mm ≈ 2.0mm >> 0.15mm 需求
- **闭合：等长可实现** ✓

## 3. PDN 闭合（电源走线/铺铜）

- 电源网（P3V3/P3V3_AUX/MCU_VDD）走 In4.Cu 整层分区，不拉细线（checklist C.3）
- 去耦电容（MLCC_0603 C67/C68/C72）位于 U3/U4 之间 8.8mm 空隙，经 Via-to-Plane 直连（checklist C.4）
- **闭合：PDN 无细线依赖** ✓

## 4. 过孔预算闭合（高速 0 过孔，低速有预算）

- 18 对差分：0 过孔（ECO #12 冻结）
- 低速/边带/电源：过孔数 = 引脚逃逸数（I2C×2 + GPIO×8 + PERST# + 电源脚），估算 <60 个
- JLC 工艺：0.20/0.35mm 孔环 ≥0.075（0.35-0.20)/2 = 0.075 **恰好达标** ✓
- **闭合：过孔策略可行** ✓
