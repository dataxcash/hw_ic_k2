## §2 IPC-2141 计算（公式 + 输入 + 迭代 + 结果）

### 公式

```
Zo_single = (87 / √(Er + 1.41)) × ln(5.98 × H / (0.8 × W + T))     [单端微带, IPC-2141 近似]
Zo_diff   = 2 × Zo_single × (1 - C)                                  [边缘耦合差分]
C         = 0.48 × exp(-0.96 × g / H)                                [耦合系数, IPC-2141]
```

单位：全部转 mil（mm ÷ 0.0254）。W = 线宽, g = 线对边沿间距, H = 介质高, T = 铜厚。

### 输入（mil）

```
Er = 4.3
H  = 0.127 / 0.0254 = 5.000 mil
T  = 0.035 / 0.0254 = 1.378 mil
目标 Zo_diff = 85.0 Ω
```

### 迭代：g 扫描求 w（二分法，目标 85.0Ω）

| g (mm) | w 解 (mm) | Zo_single (Ω) | C | Zo_diff (Ω) |
|---|---|---|---|---|
| 0.100 | 0.167 | 54.87 | 0.220 | 85.0 |
| 0.125 | 0.182 | 52.25 | 0.187 | 85.0 |
| 0.150 | 0.195 | 50.26 | 0.159 | 85.0 |
| **0.175** | **0.205** | **48.73** | **0.128** | **85.0** |
| 0.200 | 0.214 | 47.53 | 0.102 | 85.0 |
| 0.225 | 0.220 | 46.58 | 0.081 | 85.0 |
| 0.250 | 0.226 | 45.82 | 0.064 | 85.0 |

### 反向验证（固定 w 求 g；及当前规格代入）

| 场景 | w (mm) | g (mm) | Zo_diff 计算值 (Ω) | 偏差 |
|---|---|---|---|---|
| math_closure v1.1 规格 | 0.205 | 0.175 | **85.05** | +0.06% |
| 固定 w=0.205，求 g | 0.205 | 0.1744 | 85.00 | g 偏差 0.34% |
| 固定 g=0.175，求 w | 0.2052 | 0.175 | 85.00 | w 偏差 0.10% |
| 旧口径 constraints.md | 0.227 | 0.15 | **77.24** | -9.1%（不达标） |

### 结果

- **推荐值：w = 0.205mm / g = 0.175mm**（保留 3 位小数：w=0.205, g=0.175）
- 该组参数代入公式得 **Zo_diff = 85.05Ω**，距目标 85Ω 偏差 +0.06%，在 ±10% 容差内完全达标
- 旧口径 w=0.227/g=0.15 在 JLC 参数（H=5.0mil）下仅 77.24Ω，**超差** → 印证 math_closure v1.1 已修正为 0.205/0.175 的正确性

4. **走廊余量**：J2↔U 65.5% / U↔MCIO 51.2%，容量充足。
