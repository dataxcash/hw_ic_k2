# K2 卡 6 层 → 8 层方案数据对比报告（投板决策）

> 日期: 2026-08-19 | 状态: 用户裁决定案 8 层 (F/G/S/G/P/G/S/B)
> 求解器: v24 (6 层) vs v25 (8 层)，均在真实板障碍场 36/36 全通过
> 权威口径: F.Cu 段 `rf._seg_clear` / In2 段 `rb._path_ok_in2` / In6 段 `_in6_seg_ok`

## 1. 叠层对比

| | 6 层 (v24) | 8 层 (v25, 定案) |
|---|---|---|
| 叠层 | F/G/S/G/P/B | **F/G/S/G/P/G/S/B** |
| 路由面 | F.Cu + In2 + B.Cu | F.Cu + In2 (完美带状线) + In6 + B.Cu |
| GND 参考面 | In1, In3 (2 个) | **In1, In3, In5 (3 个)** |
| 电源层 | In4 单层分区 | In4 双区拆分 (P3V3 / P3V3_AUX+MCU_VDD) |

## 3. 四大优化方向达成情况

### 3.1 降解换层复杂度 ✅
- UP_OUT 16 网全部 `F→In2→F` 单内层换层（v24 中 7 网需 B.Cu 兜底、1 条 F-I-B-F 三层跳跃）
- 7_P 特殊处理（C63.2 被三角包围）：三层解耦简化为 In2 单层内完成
- 每网换层 via ≤2 硬约束保持（宪法）

### 3.2 彻底隔离边带 ✅
- In6.Cu (L7) 独占：I2C / PERST# / GPIO / USB2 / REFCLK
- PCIe 走廊 (In2) 与低速物理隔离，互不争抢
- B.Cu 仅剩低速 + 电源铺铜，零 PCIe 载荷

### 3.3 GND 伴行孔硬性落实 ✅
- 56 个换层 via 全部有 GND 伴行候选（`j2_via_gnd_stitch_v8.json` 机器可读）
- 3 个 GND 平面 (In1/In3/In5) 提供连续回流参考
- REFCLK In6 层两侧包地 + GND via 间距 ≤2mm
- 异网 via 最小边距 0.250mm > 0.175 主净距 ✓

### 3.4 PDN 平面拆分 ✅
- In4.Cu 双区：P3V3 (东) / P3V3_AUX+MCU_VDD (西)
- 电源脚 Via-to-Plane 直连，目标 S3 gate Unconnected==0

## 5. 结论

- **8 层方案在 J2 侧 36 网求解上 36/36 全通过**，且相较 6 层：
  1. B.Cu PCIe 载荷清零（23 段 → 0）
  2. UP_OUT 全部统一为 F→In2→F 单内层换层（三层跳跃归零）
  3. 低速/REFCLK 彻底隔离（In6 独占层）
  4. GND 参考面 2→3，SI 裕量显著提升
  5. 电源层双区拆分，PDN 更从容
- 换层 via 总量 57→56，未增加过孔成本
- 成本溢价 +50~100% 换取 SI/PDN/可制造性全面收益
