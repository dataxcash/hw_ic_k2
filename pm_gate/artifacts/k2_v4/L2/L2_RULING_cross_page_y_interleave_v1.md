# L2 裁定 — **跨页 y 交错**（rev-19 **不动** + 触发）｜ CO-220
> 权源：`LAYOUT_CONSTITUTION` 第二章（L2 自裁）｜层 = **L2**（走廊分配 / 层分配 / 几何）｜2026-09-14｜as-found `a46b7a1`

## 1. 待决项（**唯一剩余 L2 自由度**）
**跨页 y 交错** = 允许各 lane 之 y 序**跨页交错**（现行分配模型按页内 y 单调）。§77/§82 记为「**须改几何、非旋钮可达**」。

## 2. 自裁（**决定**，非延后等 owner）
**rev-19 不启动该几何变更**，附触发（§4）。理由：
1. **驱动缺席**：现行定案 A（HDI 盲埋孔）**无需改设计**；rev-19 交付件（板 `d4e81f647be7f980` / 打样包 37 payload / L5 三记录 / 全 pin 链）**完备且逐字节稳定**，唯一阻断为**外部报价/DFM**。几何变更将**取代**该可下单交付态并使打样包与全部 pin 失效（CO-144 改板之教训）。
2. **受益面窄且已行使**：该自由度**只影响 B 路**（加信号层全通孔）。B 之族上限 **≤24/32** 已由 **CO-209 直接行使**证（§82；R-CO209-1），且 B 须整层重派生 + 阻抗重签；A 不依赖 B。
3. **无驱动之「为证而证」不合宪**：铁律（问题回模型；DRC/探针是核对不是驱动器）。

## 3. 备择项评估（皆 **rev 级**，故同此裁）
| 备择 | 为何不采（现刻） |
|---|---|
| 以该自由度救 B 至 32/32（**若成立可免除外部阻断**，改走标准通道） | 须先改几何 + 10L 重派生；现行封顶 ≤24/32（§82 直接行使） |

## 4. 触发（满足其一即**立即开新 rev**，并以该几何变更为首动作）
- **T1**：A 之 JLC advanced/HDI **DFM 答复否决**（或明示现行 3 阶/孔径不可制）⇒ 转救 B（若仍不足则改拓扑 = **L1**，升级 owner）。
- **T2**：外部报价显示 A 代价不可接受 **且** B 被救至 32/32 之概率非零 ⇒ 先对该几何族做**直接行使**（承 R-CO209-1）。

## 5. 边界（诚实）
本裁定**不**声称「跨页 y 交错无益」；仅裁「**rev-19 无驱动、不以此代价开新 rev**」。该自由度**保留**，触发即用。**R-CO220-1**。
