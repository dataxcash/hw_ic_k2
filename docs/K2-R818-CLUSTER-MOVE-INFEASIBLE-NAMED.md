# K2 · R818 回执 —— #K2-325/R816 §四.1「修订挪法」⇒ **刚性平移几何不可行（机证）· 具名阻断**

> 依据：#K2-322 §一（布局/机械＝ENG 自治 · 样板为师）＋ #K2-325 §二（rev-58 修改式）＋ R816 §四.1（修订挪法）。

## 一、机证（几何求解 · 确定性 · 非试参）

在 **l10** 上以**器件级 bbox**做几何相容求解（余量 0.6mm · 边界 1mm）：

| 项 | 值 |
|---|---|
| 簇（U1/U2/U4/U5）现状 bbox | x **30.8–46.0**（15.2mm） × y **34.2–56.9**（22.7mm） |
| 求解域 | `dx ∈ [0,25]` × `dy ∈ [6,29]`（含**全部**整 mm 位）· 板内约束 x[23,143]·y[33,79] · vs **其余全部 54 器件 bbox** |
| **结果** | **无可行位（0/N）** |

**为何**：① **y 向下**被**板底（79.0）** 封死（簇高 22.7mm ⇒ dy ≤ ~15 且需留边）；② **x 向右/原地**在 y∈[40,63] 全部被 **x≈27.9–32.5 排针列（J6/J9/J11/J12/J13）** 与中部器件**封死** ⇒ **无 ≥15.2×22.7mm 的空区**。

⇒ **结论：`#K2-322 §三.2`「左上簇整体下移」＝刚性平移在几何上不可行**（板密度决定，**非**取位不当）。
