## 一、为什么 v1（P1 断面南移/belt 内、P2 深南巴士）仍不够（机核）

- `P1` 把断面行移进 belt(38–57) ⇒ **梯子墙（上升梯）的跨度被拉到 rows 38–64** ⇒ 转移的"深南绕行"（需 rows ≥65）**越出板高（NY=65 ⇒ 最大 row 64）** ✗；
- 反过来把 highway 加深到 54–64 ⇒ 墙底到 64 ⇒ **南面无免费带宽** ✗。
⇒ 结论：**南绕/北绕都必须在"墙外"**，而墙的自由带只有 **rows ≤39（其上方）** 或 **rows ≥54（其下方）**；
后者要求墙底 ≤53 ⇒ **wall = rows [slot, highway] 必须整体落在 41–53 之内**（即 slot 与 highway 同处 belt 一带）——
但这样墙就把 col33 与 col60 之间在 rows 41–53 全部封死 ✗。**唯一出路：让"北上"的通道列落在墙的东侧之外**。

## 二、v2 前提（几何自洽 · 逐条可机核）

- **P1'｜断面改"阶梯断面"**：col33 断面不再是单列，而是**每条线自己的过点 `(c_i, s_i)`**：
  `s_i ∈ [41,53]`（落在 belt ⇒ **过点格可打过孔** ✓）；`c_i ∈ [42,52]` 且**逐线不重复、按 π 递增**（=断面序=π，与 col60/exit 同序）。
- **P2'｜入口扇出不变形**（已验证规则照用）：口袋下钻列 `d_i` **递增** → 东行于腰带行 `R_i ∈ [54,64]` **递减** →
  上升梯 `c_i`（↑ 到断面行 `s_i`）。此三序满足既有 `<1><2><3>` 三族不冲（与已验证入口表同构）。
- **P3'｜断面间转移改"北巴士 + 东列"**：自 `(c_i,s_i)` **沿自己列 `c_i` 北上到专属巴士行 `b_i ∈ [24,39]`**（逐线不重复）
  → 沿 `b_i` **东行**（cols ≥42 ⇒ 全在梳齿之外，全程无墙 ✓）→ 到**专属东列 `E_i ∈ [60,75]`** 南下到 col60 行 `t_i` → 拐入 col60。
- **P4'｜过孔策略**：每线 ≤3 对孔（#K2-220 §三.2 辅助放开）；孔位限在册宽区（belt/field/comb）。
- **序一致**：断面过点序（按 `c_i`）、col60 行序、exit 序**三者同序**（`(c_i,s_i)` 与 col60/exit 值同步重发）。

## 三、为什么 v2 不自锁（要点）

1. 墙（上升梯 cols 42–52）只在 **rows ≥41** 存在 ⇒ **rows ≤39 的"北巴士带"完全无墙** ⇒ 转移自 `(c_i,s_i)` 北上（走自己列，`<s_i` 段无他人占用）后即可**自由东行**；
2. 巴士行 `b_i` 逐线不同 ⇒ 巴士段互不相交；
3. 东列 `E_i` 逐线不同、皆 ≥60 ⇒ 互不相交，且 col60 断面行 `t_i` 在其西侧一步处；
3b. **转移 = 第二个扇出**：北上腿列 `c_i` **递增** · 巴士行 `b_i ∈ [24,37]` **递减** · 东列 `E_i` **递减** · col60 行 `t_i` **递增** ⇒ 与已验证入口表**同构**（d↑/H↓/W↓），三族逐对不冲（巴士腿×他线北上腿、东列×他线巴士腿、收尾×他线东列）。
4. 扇出三序（`d` 递增 / `R` 递减 / `c` 递减）与已验证入口表同构 ⇒ 扇出自身不冲。
