## 四、为何任何分配都不可能（why no allocation exists — 在本卡点口径下）
1. 需求 3 的**分离手段只有两种**：**异层**（对孔）或**异格点**（并行走廊）；
2. **异层**：≤2 对孔/线为在册上限 ⇒ 三线最多各 1 段行程 ⇒ **入口带的层分离能力不足以分开 3 条重叠管道**（R536：放宽到 3/4 对亦无效 ⇒ 说明卡点更在**格点并行度**）；
3. **异格点**：入口带内同层可并行走廊 **≤10**，而三线的**可行域在喉部**交集过大、彼此**没有足够的互不重叠走廊**（域=各线独立最短路时尤甚）；
4. ⇒ **在「逐层节点不交 ＋ ≤2 对孔」下，三线无解（机证 3 条核）**；而**该无解不消耗任何守恒级资源**（容量余 +37）⇒ **"能量不够"型不可行证书不存在**，本卡点属**编码/域级**。
