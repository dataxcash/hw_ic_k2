## 2. 两项非零残差（请监理裁 1 项 + 确认 1 项）

### 2-A（**P2 侧，唯一未闭项**）：`U1` 引脚口径 = LQFP48 → QFN32（**属 R2**）

## 4. 2-A 复核（本轮新增证据）—— **该修正不能"机械闭合"，须裁定权威资产**

沙箱对 `U1` 口径对齐做**前置试做**（只读真源 + 仓内资产，未改仓），结果如下：

### 4.1 仓内引脚资产只能覆盖 25/27 脚

- 资产：`_shared/eda_core/sch_gate/datasheets/STM32G0B1KBU6.yaml`（`device=STM32G0B1KBU6`，`package=UFQFPN32`，`pins` 1..32 + `'33'=EP`，附 `aliases`）。
- 以该资产把 U1 27 个已建模脚名映射到 QFN32 脚位：**25 个可映射**（含 `PWR_BTN_OUT→pad10`、`SWDIO→pad24`、`SWCLK_BOOT0→pad32`、`SWDIO`… `EP→pad33`）。
- **2 个不可映射**：`I2C2_SCL`、`I2C2_SDA` —— 资产 `pins`/`aliases` **均无对应条目**。
  ⇒ 按 §五 停机条款「真源不足（缺引脚资产）**不得硬编绕过**」：**这两脚不得由我臆造脚号**。

### 4.2 更关键：**板与资产的 U1 引脚口径互不一致**

实测交付板 U1 逐 pad 网（`k2_v4_8L.l4.kicad_pcb d4e81f647be7f980`，只读）：

| 信号 | 板上 pad | 资产 `STM32G0B1KBU6.yaml` 对应脚 | 一致？ |
|---|---|---|---|
| `NRST` | pad **10** | pad **6** | ❌ |
| `PWR_BTN_OUT` | pad **13** | pad **10**（PA3） | ❌ |
| `GPIO_LED` | pad **14** | pad **15**（PB0） | ❌ |
| `UART_TX` | pad **29** | pad **19**（PA9） | ❌ |
| `UART_RX` | pad **32** | pad **21**（PA10） | ❌ |
| `I2C2_SCL / SDA` | pad **22 / 23** | **无条目** | — |
| `EP` | pad 33（网 = `NO_CONNECT`） | pad 33 | ✅ 位置一致 |

⇒ 板的 U1 pad→网映射**不遵循**该资产的数据手册脚序（pad 1..33 逐net顺排的形态）。

### 4.3 因此 2-A 须监理裁「哪个资产权威」，两条路径后果不同

1. **以数据手册资产为权威** ⇒ **板的 U1 引脚映射是缺陷**（交付板 `d4e81f64…` 的 U1 物理脚序与数据手册不符）：
   - 后果 = **板侧 P4 重建项**（且属**较严重**类：MCU 引脚序），须新增登记；且 `I2C2_SCL/SDA` 仍缺资产条目（需补资产）。
2. **以板的 footprint 映射为权威**（视 `ForgeOS:MCU_STM32G0_*` 封装资产为项目自有脚序） ⇒ **yaml 侧对齐到该 footprint 脚序**：
   - 属**源侧（R2）**，但等于**以板反推真源**（与 Z1「真源为先前、板为派生」相悖，须监理确认这是否可接受）；
   - 且 `I2C2_SCL/SDA` 的脚号只能取自板（22/23）⇒ 该 2 项为**板导出值**，须在留痕中标明来源。
3. 附带（已登记 P4）：板上 `U1` 实例**封装名 = `MCU_STM32G0_LQFP48`，内容 = 33 pad（QFN32 同构）** ⇒ 名/内容不一致。

### 4.6 **结论修订（决定性证据，取代 §4.3 的两选项框架）**

**补充取证（只读）**：
1. **真源自洽于 LQFP48**：`k2_sch.yaml` 的 K2 U1 用符号 `MCU_STM32G0_C2`，其 `value = STM32G0B1CBT6`、`footprint = ForgeOS:MCU_STM32G0_LQFP48`（另有符号 `MCU_STM32G0`，`value = STM32G0B1KBU6` / `QFN32`，未被 K2 使用）。
2. **板的 U1 引脚序 = LQFP48 资产**：以 `STM32G0B1CBT6.yaml`（LQFP48）比对交付板 U1 的 pad→网：**7 命中 / 0 不符**；以 `STM32G0B1KBU6.yaml`（QFN32）比对：**0 命中 / 5 不符**。
3. **K1 板交叉验证**：`k1/k1_v1.kicad_pcb` 的 U1 = `{NRST:6, UART_TX:19, UART_RX:21, SWDIO:24, SWCLK_BOOT0:32}`，与 **KBU6/QFN32 资产逐项一致** ⇒ 两个资产均为**真实可用的项目资产**，各自对应各自器件。
4. **板的 U1 被截断**：交付板 U1 实例**仅有 pad `1..33`**（LQFP48 应为 1..48）⇒ `35/36/42/43/44/47/48/49` 八脚**不存在** —— 这正是 E2「缺脚 8」与 E3「缺焊盘 8」的**同一根因**。
