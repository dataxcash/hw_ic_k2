# K2 · 工序资产 ③《整版分配（Whole-Version Bundle Assignment）》SOP（v1 · 针对能力账 C7）

> 依据：#K2-296 §二.2（C7「完备分配／整版规划」仍开，须以资产＋回归件关账）＋ 本项目已付出的返工代价（R720→v5b 共六支构型）。

## 1. 目的
把「16 条线一次排完」做成**可复用工序**，杜绝「逐线/逐行零敲」的补丁螺旋（本项目 v2→v5b 六支皆死于同族）。

## 2. 工序（七步 · 一次执行 · 零回溯）
| 步 | 动作 | 要点 |
|---|---|---|
| W1 | **分组** | 按**出口侧**分组（K2：W＝col-114 墙缺口组 / E＝row-36 出线带组）；**一组＝一束** |
| W2 | **组内定序** | 序 = **器件侧物理入口序**（在册入口通道列 `d`）；**不得**用「行号/寄存器通道号」替代物理序 |
| W3 | **分配** | 组内**单调指派**（第 k 条线 → 第 k 个出口/逃逸位）；**禁**对**物理走线序**做反向（反向只属于**寄存器编号**语义 — 见资产②在册案例） |
| W4 | **预算守门** | 每一步都守**在册预算**：孔对数（13 线 ≤2 / 3 条放宽线 ≤3）、包络（≤21 列/≤29 行）、门位集（不改物理开口） |
| W5 | **一次性构造** | **域=1**：按 W1–W4 直接产出**每线一条确定走法**；**禁**搜索/试参/现场兜底 |
| W6 | **机核** | 四硬键 ＋ 层对键（孔对格两层皆空）＋ 与基准对账（差异=0 或逐格具名）＋ 守恒（容量≥需求） |
| W7 | **报验** | 全绿 ⇒ 可行见证；任何阻断 ⇒ **具名到格**（哪条/卡在哪对同组通道/被哪条已画通道占死） |

## 3. 失败类型学（在册 · 用于自检）
| 型 | 表征 | 处置 |
|---|---|---|
| T1 逐线补丁螺旋 | 同一目标连续多窗 7–8/16 | **强制换手段**（§17§4），不再批同型窗 |
| T2 贪心基座＋尾段 | 「先钉一排再塞余线」⇒ 余线存活 0 | 改**整版**分配（本 SOP） |
| T3 参考板型不匹配 | 平面内对称扇出 ≠ 跨区下钻 | 走**资产②预检**（MISMATCH ⇒ 停） |
| T4 参考范式机制越预算 | 如「拐角多段换层」超在册孔对预算 | 走资产②**S4/S5**（PARTIAL ⇒ 停，禁跑退化等价构型） |
| T5 物理序被反向 | 同组四线自相切断 | 依 W2/W3（反向只属寄存器编号语义） |
