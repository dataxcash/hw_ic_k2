# K2 · 工序资产 ②《参考件适用性预检》SOP（v1 · 固化 R760 做法）

> 依据：#K2-295 §五（绑带）＋ #K2-293 §三.1（先预检再推导）＋ R760（直通式线卡＝板型不匹配；分叉 riser＝机制被在册预算封死）。**目的：一次性阻断「照抄不适用成品」的返工。**

## 1. 目的与时机
**在按参考件做任何推导之前**执行。**预检不过 ⇒ 具名报告即停，禁推导。**

## 2. 步骤（六步 · 只读）
| 步 | 动作 | 产出 |
|---|---|---|
| S1 | **识别参考件板型** | 直通式线卡 / 分叉 riser / 扇出式底板 / 其它 |
| S2 | **映射到在册约束集** | 至少四条：① 出口是否多组且几何不同 ② 是否需**跨区下钻** ③ 是否需**有序不交叉** ④ **在册孔对预算**（13 线 ≤2 对孔 / 3 条放宽线 ≤3）与**在册包络**（≤21 列/≤29 行） |
| S3 | **判类别匹配** | 逐条给 ✅/❌（须挂**图/页**证据） |
| S4 | **判区分性机制是否被在册预算封死** | 明确：该参考件的**特征机制**（如「拐角多段换层」）是否**超出在册预算** |
| S5 | **退化检验** | 扣掉被封死的机制后，其剩余几何是否**等价于已跑过的构型**（若是 ⇒ **无新可判定范式**，不得再跑） |
| S6 | **裁定＋落件** | `FULL_MATCH`（⇒ 可推导）／ `PARTIAL_MATCH_MECHANISM_BLOCKED`（⇒ 具名停手）／ `MISMATCH`（⇒ 具名停手）；件内记录**视觉调用次数／用到的图号／不可辨项** |

## 3. 硬规矩
- **必须挂图/页证据**；**不可辨项如实登记，禁猜**；
- **不得**为「凑一次运行」而跑**退化后等价**的构型（R760 已示警）；
- 视觉调用**仅限证据观察**，不得挪用；
- 预检**通过也不代表**16/16 可达（须由 S4→推导→认证表验证）。

## 4. 在册案例（回归基准）
| 参考件 | 板型 | 裁定 |
|---|---|---|
| DS320PR1601 EVM（SNLU300A） | 直通式线卡 | **MISMATCH**（平面内对称扇出 vs 本板跨区下钻） |
| DS320PR412-421 EVM（SNLU301） | 分叉 riser | **PARTIAL_MATCH_MECHANISM_BLOCKED**（拐角多段换层 vs 在册孔对预算） |

## 5. 关闭判据（§22§3 · 硬）
**资产（本件）＋ 同类回归件 PASS**：回归件 = **下一份带参考件的登记/推导件，须附本 SOP 的 S1–S6 完整记录**（缺记录 ⇒ fail-closed 不受理）。
