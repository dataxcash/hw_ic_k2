### 2. 为何不通（按族）

- **施工层撕铜族**：两根跑线是**整段**（B.Cu 49.4 mm 横 ＋ In5 14.8 mm 竖）；沿禁区撕开 ⇒ 残段成**远端孤立长桩**，缝合器只能对整桩作业 ⇒ 越接越乱。
- **局部挪孔族**：挪孔**必然带动挂接段**；该角列**满铺异网铜皮** ⇒ 任一姿态都落铜皮 ⇒ **精确穷尽**。
- **确定式平移族**：平移后**竖线那一列已被占**（异网铜）⇒ 必撞。
- **出图构造器族**：三次失败**不是几何不通**，而是我把**工具集成问题**（层 id 体系 / 孔位选择 / SWIG 进程态）当成了迭代对象 —— **这正是触发第 8 条的动作**。

## 二、Plan（人类工程师路径 · 大白话）

### ① 信号怎么走
`U6 出球 → 沿板下缘在 B.Cu 走 ~49mm 横线向右 → 到右下角用一个「拐点孔」换到下内层 In5 → 沿右缘**竖直上升 ~15mm** → 到 y≈59.5 再换层上表层 → 接 J2 焊盘`。
**即：角上那个孔是「横线→竖线」的拐点。**

### ② 挡路的是什么
右下角要放**安装孔＋6×6 禁区**，而**拐点孔正好住在角上**：
- 把孔往左挪 ⇒ **竖线也得跟着挪** ⇒ **竖线那一列已经挤满别的网走线/铜皮** ⇒ 必撞；
- 把线剪掉重接 ⇒ **横线太長（49mm）**，残段离目标太远 ⇒ 接不回。

### ③ 人类方案是什么
**不要在角上拐 —— 把「拐点」整体搬到禁区外（x=137.555），然后在竖线那一列里另找一条上去的路。** 两条候选（出图时定一条）：

- **(a) 换层再上（推荐先试）**：在 x=137.555 把 B.Cu **先换到更空的内层**（如 In2），在那一层竖直上升到 y≈59.5 附近，**再换回 In5** 接原顶孔。（多一个孔，但绕开整列拥挤）
- **(b) 借道绕行**：仍在 In5 上竖升，遇拥挤段用一段 **45° 斜线**向左右让开 1–2 mm 再回正（45° 是规范允许的，不需新孔）。

**判据不变**：精确闸（0.20 净距地板）＋ **铜皮精确多边形入模** ＋ **DRC ≤168 且无类增加** ＋ **未连接 0**。
