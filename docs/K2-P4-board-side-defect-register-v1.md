# P4 板侧缺陷登记（R1/R2 落盘后归口）v1

- **依据**：监理 **#K2-13 §三**（`PWR_5V_KEY` 改判为板侧缺陷 + 7 单节点网系统性发现）、**§一 O2**（终局 55）、#K2-12 §二.3（C 类防掩）。
- **性质**：**板侧（P4）修复项清单**。R1/R2 只改**图侧**；此处各项**不得**用改真源/删网的方式抹平。

## 1. 补件 13 件（= O2 终局差额 55−42）

`D2` · `L1` · `R35` · `R36` · `R37` · `R38` · `R39` · `R40` · `R41` · `R42` · `R43` · `R44` · `R45`

- 其中 `D2`/`L1`/`R40`/`R41` = R1 **B 类**（buck 缺电感/续流二极管，6L 保留项）；`R35–R39`/`R42–R45` = 单体 strap 电阻（对应 `DS320_STRAP_*` 9 网）。
- E1 现状：**图-板 = 13**，即"图上已有、板上未落"，**非图侧缺陷**。

## 2. 板上单节点网 7 个（**已独立复算，与监理 §三 逐项一致**）

| 网 | 板上唯一节点 | 归因 |
|---|---|---|
| `PWR_5V_KEY` | `C89`（4.7µF） | 5V 键控轨缺源 ⇒ **浮空去耦**（与 buck 缺件同源） |
| `SW_U2` | `U2` | buck 开关节点，**缺 `L1`** |
| `FB_U2` | `U2` | 反馈分压，**缺 `R40`/`R41`**（及 `D2`） |
| `PWR_CTRL_OUT` | `U5` | 光耦输出未接下一级 |
| `UART_RX` | `U1` | 串口未引出/未接 |
| `UART_TX` | `U1` | 同上 |
| `SWCLK_BOOT0` | `R28` | strap 未接（缺 `R35–R39` 类补件） |

**对照（正常网）**：`12V_IN → ['C88','U2']`（3 pads）· `P3V3_AUX → ['C90','J3','J4','R1','U1']`（5 pads）。
**复算方法**：解析交付板 `k2_v4_8L.l4.kicad_pcb`（`d4e81f647be7f980`）逐 footprint pad `(net "…")`，按 ref 去重计数。

**裁定要求**：① `PWR_5V_KEY` **禁从真源删除**（删 = 抹平缺陷）；② 不得判为"有意占位"；③ 7 网全部 ⇒ **P4 板侧修复**。

## 3. C 类防掩（#K2-12 §二.3）—— 独立保留

- **`U6` 15 球未连**：不得因图侧 strap 网删除而被读作"已消解"，**在 P4 板侧清单独立保留**（本件 §3 即其载体）。
- 另见 E3 板侧 57 项归因：`U6` 15 球 + 5 排针 16 pad + 13 件补件 26 pad（`k2/docs/K2-P2-E3-rootcause-breakdown-v1.md 23172f7548d3b29f`）。
