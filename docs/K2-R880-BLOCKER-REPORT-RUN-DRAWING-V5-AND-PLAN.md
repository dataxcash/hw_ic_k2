## 三、Plan（大白话 · 依**更正后的层别事实**）

> 更正（R876 文本为准）：横线在 **In5.Cu**；拐点孔是 **In2↔In5 盲孔**；**竖升在 In2.Cu**；顶端还有**顶孔**（合法 · 禁删）。

### ① 信号怎么走
`U6 出球 → 内层 In5 沿板下缘走 ~49mm 到右下角 → **拐点孔**换到 In2 → 沿右缘在 In2 **竖直上升 ~15mm** → **顶部孔**换回 In5/F → 接 J2 焊盘`。

### ② 挡路的是什么
右下角要放**安装孔＋6×6 禁区**，而**拐点孔就住在角上**：
- 往左挪 ⇒ 竖线也要挪 ⇒ **竖线那一列被别的网铜占满** ⇒ 平移必撞；
- 剪线重接 ⇒ 布线器**今天接得上**，但它**在自己脚下连打 5 个孔**，接出来的线**不干净**；现有清理器**清不掉**，而且**还想删掉两个合法顶孔**。

### ③ 人类方案（**一次做成两件事**）
1. **少打洞**：竖升**保持在同一层（In2）**，遇到拥挤段用 **45° 借道**绕开再回正 —— 目标是 **0~1 个孔**（而不是 5 个）；即**候选 (b)**。**禁止**在脚下叠孔来「绕」。
2. **给清理器补一条正确动作**：**「把悬空端缝到最近同网铜」**（用**精确闸 + 0.20 净距**），并**明确保护非被困孔**（顶孔等**禁删**）。
