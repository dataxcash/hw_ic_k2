## 0. 结论（三句）

1. **0.25 / 0.41mm 不是「对间距」差，而是走廊端点的「参照物」差**：L2 冻结表用**器件体宽**、SPEC/板侧用**焊盘外接框**。
2. **对阻抗 `ΔZ = 0`**；**对可制造性无影响**（JLC HDI 门槛 0.09/0.10mm 与本差无关；走廊容量账在**两套口径下均过**）⇒ **不触发 §2.6 的停机条件**。
3. **但发现一处具名对账缺口**：SPEC `corridors_clearance_basis_v24` 在册的 `board_measured_mm`（`U6` 82.76 / 105.00，`delta_mm` 0.16）在 **l4 / 设计源板 / l5 / l6 四块板上、四种「焊盘外接框」口径下均不可复现**（恒为 82.60 / 104.84 ⇒ δ = 0.00）⇒ **须 owner/监理裁定口径具名**，ENG 不改 SPEC（判据/冻结面）。

## 3. 影响量化

| 面 | 判定 | 依据 |
|---|---|---|
| **阻抗** | **`ΔZ = 0`** | 走廊端点口径只决定**走廊容量账/排轨端点**；差分阻抗由 `impedance.width_mm_by_layer`（F/B 0.205 · In2/In5 0.16）+ **对内** gap（`p_gap` 0.175 / 交付几何 `p_gap_geometry_mm_delivered` 0.295）决定 ⇒ 与走廊端点**无函数关系** |
| **可制造性（DFM）** | **无影响** | JLC HDI 在库门槛 = **最小线宽 0.09mm / 最小线距 0.10mm**（`k2/docs/02-manufacturing.md:18`）。0.25/0.41 是**走廊端点**差，本身不产生任何亚门槛特征；且**两套口径均无 DRC 下限变化** |
| **走廊容量（能否布下）** | **两口径均过** | 每带 8 对 × **1.46mm 对中心距** = **11.68mm** ≤ 西 N16.2 / 东 S20.8（L2 冻结表同列）；焊盘口径下走廊**更大**（17.55/27.81）⇒ 结论 a fortiori |
| **布线资源/余量** | 落在既有余量内 | 审计实测走廊利用率 **51%–65%** ⇒ 0.25/0.41mm 的端点差不足以改变「布得下/布不下」 |
| **交付面** | 不阻塞 | 属**容量账/文档口径**项，非 Gerber/DFM 项（owner #14 ③） |

⇒ **`#K2-30 §2.6` 的停机条件（影响制造）不成立**：不停机。
