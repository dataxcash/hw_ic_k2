# K2 · 工序资产 ⑤《方案布局渲染评审清单 v1》（#K2-335 制度化）

> 法定形式：**方案评审 = 布局渲染图 ＋ 标准清单逐条评审**（非数据审阅）。每轮方案迭代：**出渲染图 → 按清单逐条评审 → 具名问题 → 改布局 → 再渲染**，**清单全过 = 方案可冻结的唯一条件**。
> 执行者：**视觉模型逐轮自动跑**（能力已装，`-p vision`）→ 具名发现；**owner 终审 = 冻结前最后一次渲染评审**。
> 追溯：owner 2026-09-28 直令「方案投标评审的重点就是器件布局渲染图的分析」。承接资产 ①②③④。

| # | 评审项 | 判据 |
|---|---|---|
| **R1** | 主器件位置合理性（主芯片 ↔ 信号流向对应） | 主通路直达性 **P1 量化** ＋ 渲染目视 |
| **R2** | 功能分区合理（高速区 / 低速功能区划分与位置） | 分区边界清晰 · **高低速不混布** |
| **R3** | 密度均衡（无过度紧密簇；空间利用均衡） | 簇间距 ≥ 标准件位 · **无「挤在一角」** |
| **R4** | 机械框架（孔位四角 · 边缘间距 · 连接器对齐） | **P3 量化** ＋ 渲染目视 |
| **R5** | 信号流向一致性（入出方向 · 无逆流长绕） | 流向图对照 |
| **R6** | 可制造性初判（装配/焊接可达 · 无重叠） | **C16** ＋ DFM 最小间距 |

**与闸的关系**：R1↔P1 · R4↔P3 · R6↔C16/DFM；R2/R3/R5 为**渲染目视项**（量化辅助）。
**关闭判据**：某轮 **R1–R6 全过 ＋ owner 看图过** ⇒ **方案冻结**（rev-60 ＋ 框架证书）。
