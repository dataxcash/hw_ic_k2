## 0. 结论（四句）

1. **残余 5 件 `electrical_diff`（`U6`/`U1`/`L1`/`J3`/`C85`）的亚微米差 = 单一机制**：生成器 `k2/tools/k2_gen_v5.py` 以 **`{:.3f}`（µm 取整）**发射 **footprint 原点**（`:319`）与 **pad 局部坐标**（pad 行 `(at {px:.3f} {py:.3f})`）。
2. **库快照坐标含半微米值**（QFP/BGA/0603 类常见）：**216/1232 = 17.5%** 的 pad 坐标分量**非 µm 对齐**（余数 200/400/500/600/800 nm）⇒ 经 `:.3f` **必产生 ±0.2…0.5 µm 误差**。
3. **逐分量预测 vs 实测完全吻合**：`U1` **10/10** · `L1` **4/4** · `C85` **4/4** · `J3` **12/12**；`U6`（`fp_rot=90`）轴置换后量级一一对应（±200/±400 nm）。
4. **⇒ `lib_electrical_level` 的现行「精确等值」口径对任何非 µm 对齐的库 pad 结构性不可达**（应然过严，非实现缺陷；与 `refplane` 面积口径同构）。**电学/制造影响 = 0**（≤0.5 µm，远低于 DRC 与工艺分辨率）。修复候选须**授权改生成器**（ENG 不自行改）。

## 3. 影响量化

| 面 | 判定 | 依据 |
|---|---|---|
| **电气/拓扑** | **0** | 差 ≤0.5 µm；不改 net、不改铜连接、不改 pad 尺寸/形状（`sx/sy` 差 0） |
| **DRC** | **0** | 误差 ≤0.5 µm 远低于 DRC 分辨率；`l6` 实测 `error 0` / `unconnected 0` |
| **可制造/阻抗** | **0** | µm 级不触及任何工艺/阻抗几何 |
| **判据** | **结构性 FAIL** | `lib_electrical_level` expect = 精确 0（逐字节 vs 库）⇒ 17.5% 的库 pad 坐标分量注定被量化 ⇒ **口径应然过严** |
| **真值语义** | 无信息损失 | 板侧值 = 库侧值的 **µm 量化**（确定性、可预测、可逆推） |
