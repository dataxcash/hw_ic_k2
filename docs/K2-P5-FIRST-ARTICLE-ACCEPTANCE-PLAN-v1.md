## 2. 验收项

### V4 · 阻抗券（板厂出）
- **阈值**：**85.0Ω ±10%**（76.5–93.5Ω）— SPEC `impedance.tolerance_pct`。
- **覆盖要求**：请板厂阻抗券**覆盖最宽对内间距 0.6mm 中心几何**（承 CO-146 备注；设计名义最宽间距下 M2 模型观察值偏 +11.7%）。
- **对照（交付包 as-built 几何）**：In2/In5 净距 0.3400mm（= 窗下界）· F.Cu/B.Cu 主 run 净距中位 0.395mm（窗内），最紧真平行段 **0.2825mm**（`PCIE_UP3`，−4.24%，具名）。券报告须逐层给出 Zdiff 实测。

### V5 · PDN 直流压降（实测）
- **阈值**：各电源网「源端 → 负载点」直流压降 **≤ 预算 3%**（监理定值，指令 #10）。轨：`12V_IN` / `P3V3` / `P3V3_AUX` / `MCU_VDD`。
- **方法**：负载条件与**各轨电流须显式声明**（无器件数据时按保守值并声明）；四线法在负载点测；同时记录源端。
- **已知布局事实（供解读）**：电源平面 = **In4.Cu**（P3V3 东区 / P3V3_AUX+MCU_VDD 西区 / 12V_IN 载流）；GND 平面 = In1/In3/In6；去耦经 via_to_plane 落地。

| V6-5 稳定性 | 训练成功后连续运行 **30 分钟** | **AER 计数 = 0** |

### V7 · 热验收（O2 定案；L2 裁定 `L2_RULING_u6_thermal_mitigation_v2.md`）
- **装配前置（强制）**：`U6`（DS320PR1601）= **30×30mm 铝散热片 + 界面垫 1.0℃/W + ~2m/s 风冷** ⇒ θJA_eff **11.0℃/W**。
- **判据**：四工况 Tj = 91.7 / 106.0 / 103.8 / **117.0** ≤ **120.0℃**（设计预测值）。
- **T1 触发（必做）**：首件实测 **Tj(U6) > 117.0℃** **或** 未按 O2 实施 ⇒ **立即开新 rev**，量化目标 `θJA_eff ≤ 9.5℃/W`。
- **T2 触发**：`U6` 域几何因他因修订 ⇒ **同 rev 一并补 GND via 阵列**。

## 3. 实板观察点（P5 具名项的直接验证，不构成新增审判齿）
1. **阻焊坝 9 处 <0.09mm**（U1 pad23/24 · U6 FG1 · J13 pad1/2 等）⇒ 实板检查该处**无阻焊坝**、焊接后**桥连检查**。
2. **正面丝印 4 处越框**（`H4`/`R41`/`D2`/`C87`，max +1.848mm）⇒ 实板确认该 4 个位号是否被板厂裁剪（缺字属预期）。
3. **F.Cu 最紧耦合段 0.2825mm** ⇒ 由 **V4 阻抗券**覆盖判定。
4. **B.Cu 无 as-built 耦合 run**（SPEC 对称声明行）⇒ 无实板动作。
