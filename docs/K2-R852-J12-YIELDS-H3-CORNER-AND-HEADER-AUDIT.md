## 五、本窗新登记缺陷（两条 · 均为机证）

1. **M-ENG-HOLE-KEEPOUT-STALE**：**移动孔而禁区留守**。机证：l12 上 `K2_HOLE_KEEPOUT_H4` bbox `[111.6,33.1,117.6,39.1]`（＝**移动前** H4 位置），而 H4 实测在 `(140.8,76.8)`；`H2` 同族（低 1.5 mm）。**静默**（无 DRC 条目）。补法 = 孔动则禁区随动（本件已对 H3 执行）；回归件 = 四孔 `keepout bbox 中心 == 孔 at`。**本 rev 不改 H2/H4**（一次一改 · 其改动会重铺该区铜 ⇒ 需独立 DRC 验证的 rev）。
2. **M-ENG-CLEARANCE-MODEL-DIVERGENCE**：**验收权威 vs 冻结规则口径差**。冻结 `drc_rules.json` 说 `LOW_SPEED/GND clearance = 0.10 mm`，而 kicad-cli 的工程网类默认 **0.20 mm** ⇒ 用冻结模型的路由器会产出 kicad-cli 判违规的铜（本件实测 2 处 0.12 mm）。处置：C17 v1 的**避障闸地板抬到 0.20**（`--clearance-floor` · 包装器 `k2_reroute_router_floor_v1.py`，**不改在册资产**）⇒ 归零。补法 = 冻结规则与工程网类对齐（**涉冻结件 ⇒ 提案，待批**）。
