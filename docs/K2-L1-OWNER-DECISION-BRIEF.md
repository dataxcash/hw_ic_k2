1. **地方够**：156 断面全量计数，最紧断面**容 40 vs 需 3（余 +37）**；`hard_wall_certificate_found = false`（R537）。
2. **单线都画得通**：16/16 单线级标定在册（R545／R533）。
3. **变体试尽**：六族构造最高 **13/16**（R652）；13 固定 + 3 自由 = **相对该基座 UNSAT**（R708）。
4. **整版重排也不行**：按成品全序做整版束道、**出口门列严格不动** ⇒ **7/16**（R732）。
