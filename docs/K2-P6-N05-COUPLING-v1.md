## 2. 关键读法（避免把「正常」当「问题」）
1. **「导入后未变更」≠ 陈旧**：K2 工程目录由 `1a883b8` 自 `strix-halo-ioconvert` 复制而来 ⇒ L1/L2 的**人写证据**（`measurements.md`/`criteria.md`/`constraints.md`/`ruling.md`…）天然就是「导入 + 未修改」，**这是正常的**，不是 N-05 卫生项。
2. **`on_gate_path` 命中多为「契约文件名」而非「被消费的该件」**：如 `report.json`(41)、`summary.json`(7)、`PCIE_REFCLK1.json`(8) —— 代码里出现的是**命名约定**，不代表依赖该具体文件。
3. ⇒ **可裁决的问题不是「64/656 件」，而是**：**哪些「机器生成物」位于本轮交付/复现链上，且无法由现行 SPEC 重生成？**
