## 三、前提勘误（W2′ 授权件 E5）

## 四、修复规格（量化）

**约束**：凡车道 pol-y ≥ 73.9287（须穿越禁区带）的立柱，须满足

```
column_x + via_radius + margin <= 137.9287      # 0.175 + 0.10
=> column_x <= 137.6537
```

| 网 | 现 column_x | 判 |
|---|---|---|
| DN4_N | 139.48 | ✗ 超 1.83mm |
| DN5_P | 138.32 | ✗ 超 0.67mm |
| DN6_N | 137.16 | ✓ |
| DN7_P | 136.00 | ✓ |

**可行带** `[135.4, 137.6537]`（宽 2.25mm）＞ 4 柱 × 0.58 步距所需 1.74mm ⇒ **再排列存在**（例：135.40 / 136.15 / 136.90 / 137.65，步距 0.75，DN4_N 边距 0.104mm）。

**长度耦合（关键）**：立柱西移会**同时**缩短 In5 横线与 F.Cu 着陆段（landing→pad 在 x=135.0），约 2×Δx；并且**吃掉等长蛇形唯一可用的空间**（column_x 与 pad 之间）。
⇒ 这正是 #K2-341/#K2-346 **四法族穷尽**的机械原因：角能清，但同一动作把长度预算也清掉了。
⇒ 修复 = **{车道迂回 + 立柱 + 等长补偿} 联合重解**，且重出的图必须**重过它自己的 18 条闭式谓词**——不是坐标微调。
