## 3. 归因结论

1. **焊盘口径可排除**：全部 ≤ 10.1%（y 最高 9.25%），与登记「19–27%」差 **2–4 倍**；且 `x`/`y` 换轴、
   AABB/真多边形换定义都拉不开量级。
2. **唯一落在登记量级的是「courtyard（本体）占用」**：`l5` 中带 **18.97%（真多边形）/19.44%（AABB）** ≈ 19%；
   复合候选（courtyard 补齐后）中带 **27.84% / 28.14%** ≈ 28%。`l4` 中带 12.42%（courtyard 仅 1 件 ⇒ 偏小）。
3. ⇒ M-12 的「19–27%」**最可能是 courtyard/本体占用的三横带中带值**，其跨度来自 **courtyard 普及率/revision 差**
   （补 courtyard 前 19% → 补齐后 28%）；登记册**未写口径与「件面/本体」**，故 ENG 数轮复算（5.3/17.8/0.7 与
   4.78/7.59/2.19）都在**焊盘口径**上，注定复现不出。**口径仍须监理择一后才可谈阈值。**
4. **⚠️ 与判据的牵制（决策后果）**：若监理采用「courtyard 占用」口径、且上限取登记上界 **27%**，则
   ⑥+⑦ 复合板中带 **27.84% ⇒ FAIL**。即 **⑥「40 件 courtyard 补齐」会抬高该指标**（19% → 28%），
   而 ⑥ 是「P5 出 Gerber 前须闭」项（#K2-21 §二⑥）⇒ 口径与阈值须**先定**，再据此重算 ⑥ 的可行性/边际。
