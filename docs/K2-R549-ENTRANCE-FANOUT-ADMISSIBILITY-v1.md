## 二、机核证据

### 证 1 · 端点三连 {31,32,33} 同层不可共存（穷举 · 机核）

| 端点 | 门（合法入口格） |
|---|---|
| (col33,row31) | `(33,32)`、`(34,32)` ← 只有两扇门 |
| (col33,row32) | `(34,32)`、`(34,33)`、`(32,33)`（`(33,31)`/`(33,33)` 是别人的端点） |
| (col33,row33) | `(34,33)`、`(34,34)`、`(32,33)`、`(33,34)`、`(32,34)` |

- row32 的两扇「斜门」`(32,33)→(33,32)` / `(34,33)→(33,32)`：其 45° 走线中心线到 `(33,33)` 的**最近距离 = 0.3075 mm < 车道中心距下限 0.435 mm** ⇒ **非法**（在册判据 `pitch = P = 0.435`）。
- 于是 row32 的门只剩 `(34,32)`；而 row31 的两扇门是 `(33,32)`（＝row32 那一线自己的端点格）与 `(34,32)`（＝row32 线的过路格）⇒ **两线必争同一格 ⇒ 无解**。

> 机核：`lemma1_terminal_trio`（当前命中：L1 的 `OUT0_P(31) / OUT2_P(32) / OUT4_P(33)`；判定 `INFEASIBLE (machine-checked)`）。

### 证 2 · 端点 31 的入口割集 = 单格 `(col34,row32)`（机核）

- 在其余 col33 端点（row 33..42）**全部被占**的前提下，对 `(33,31)` 做局部可达 + 割集计算（窗口 cols 28..41 / rows 28..45，图＝在册节点+弧）：
  **`must_pass_cells_cut = ['c34r32']`** ——即**每一条**通往端点 31 的合法通路都必经 `(col34,row32)`。
- 含义（施工口径）：**端点 31 那根线必须独占列 34 在 rows 32..约34 的那段「专梯」**；同层任何别的线的收尾走法都不得从列 34 穿过（否则撞梯）。
- 这正是 R548b/R548d「±2 格直线带内无通路」的真正原因：不是带宽不够，是**门只有一扇**。

### 证 3 · 规则化构造（候选修复 + 未闭合项登记）

本件另给出**入口可通行**的候选端点集合与逐线走法规则（`lemma3_repaired_scheme`）：

- 候选端点：**L0 = {31, 34,35,…,43}**（11 行）· **L1 = {31, 34,35,36,37}**（5 行）——即**把 row 32/33 从端点集里让出来**（让 31 那根线能走 row33→`(33,33)`→`(33,32)`→`(33,31)`）。
- 走法规则（零搜索）：按 A 焊盘自西向东定序；**下钻列 d 严格递增**、**腰带行 H 严格递减（随 d）**、**上升列 W 严格递减且 ≥34**；收尾行 = 端点行；端点 31 线专走 row33 收尾。
- **未闭合项（诚实登记）**：解析上四族两两约束（下钻×东行、东行×上升、上升×收尾、收尾×收尾）在上述单调律下**全部满足**；但**严格递增的下钻列在 col25 之后对最东两根线无合法「口袋通道」**（其自有空闲列只到 col21/col25），改走腰带列（col26+）则需一条东行，而那条东行会压到西侧各线的下钻段。⇒ **下钻列与 H/W 必须和 L2 一起重推（见 §三）**，不能只在入口层局部拍表。
