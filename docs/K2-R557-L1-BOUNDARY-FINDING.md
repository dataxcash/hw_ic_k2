## 一、机证链条（承 R549→R556）

1. **入口扇出（已机核、两线已画通）** 的东行段必须从梳齿（cols 2–25）延伸到**各自上升梯列（cols 34–44）**
   ⇒ 全组东行段的列覆盖 = **cols 2–44**（行 = 各自腰带行 H，43–53）。
2. **断面间转移**要把"后画线"送到 **col60**，它必须**下潜穿越 row 43–53**（梯子墙底部之上无路）。
   下潜必然经过 **cols 2–44 中某一列** ⇒ 与第 1 条的东行段**必交**（R554 机核：三种分配律下冲突恒落在同一行 row 53）。
3. **不存在自由下潜列**：`∪_j [d_j, W_j] = [2,44]`（因 d_j ≤ 25 且 W_j ≥ 34）⇒ 若要"下潜不穿他线东行"，
   下潜列必须 **≤1 或 ≥45** —— 而 ≤1 无南向通道（梳齿），≥45 被梯子墙封住（同层不可达）。
4. **换层也救不了**：把转移挪到另一层后，那一层有**本组自己的**东行段（行 43–53、列 2–44）⇒ 同样封死（对称）。
5. **北面（rows ≤30）** 是唯一"梯子墙外"的通道，但 cols 34–40 在 rows 25–32 被梳齿占死 ⇒ 只有 cols 41–44 的
   少数线能北出，**不可能承载 11 线**。

⇒ **判定**：在当前 **R540 断面语义**（A→col33→col60→exit→B 的次序与断面位置）+ **≤2 对孔**（R512/R515 设计约束）
+ **不越层组** 三条同时成立时，**该两扇架构无解**（与格子合法性、守恒、层数无关；余 +37 为正）。
