## 二、人类路径 Plan（大白话）

### ① 信号怎么走
西侧 16 个焊盘 A 出一根线 → 按在册**入口动作**在自己那一列下钻（或就地打孔下到 In4）→ 向东穿**梳齿/腰带** →
在 **col33 → col60 → 出口** 三个断面上**各占自己那一格**（同一层相邻线不许同格、不许交叉）→
穿**墙缝（西 8 线）/门柱（东 8 线）**进**焊盘场** → 落到自己焊盘 B。全程最多 2 对孔（一次下去再上来）。

### ② 挡路的是什么
1. **断面槽位重复**：5 根线被塞进同一格点，2 层放不下（**已机证**，是**输入**坏了，不是画法）。
2. **入口扇出要绕行**：从"自己的下钻列"到"col33 的槽位行"之间，梳齿 + 别的焊盘禁近圈**把直线带封死**，
   每根线都得绕；**16 条绕行没有分配表**，于是互相压。
3. **不是**：线宽/间距不够 · **不是**层数不够（2 层够） · **不是**板面不够（断面余 +37）。

### ③ 人类方案是什么（大白话）
> **"先摆一张通道表，再照着描线。"**
1. **把断面槽位改成一格一线**（逐层不重复）并让**同一层的线序**在相邻断面间**不翻转**——这张表我已经画好（R548 `l2_slot_repair.assignment`，45 处改动，0 冲突、0 翻转、预路由 PASS）。
2. **入口那张表要人画**：拿梳齿的**空闲竖直通道**（列）与**空闲行**，按 A 焊盘自西向东的次序，
   **一格一线**地分配"下钻列 → 目标行 → 东行通道"，并给需要绕行的线**指定专用的绕行通道**（相邻线不许共用通道）。
3. **然后每根线照表描**：在自己的通道里走直线/台阶，不搜索、不协商。
4. **最后过在册闸**：`exact_gate`（逐层 pitch/clearance）+ `gate_vias` + 端点偏差 + ≤2 对孔。
