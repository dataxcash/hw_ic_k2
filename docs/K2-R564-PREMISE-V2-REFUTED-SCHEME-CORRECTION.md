## 二、根因（一句话 · 机核）

**前提 v2 的 P3′「自 (c_i,s_i) 沿自己列北上到巴士行 b_i ∈[24,37]」在该层不可实现**：

1. `riser_cols = ∅`（R564 本体核：无任何 `c ∈[42,52]` 能在 COMB 层上从 `b` 一直通到 `H`）；
2. In5 层 **rows 24–34 在 cols 42–80 全被封**（机核：每条 In5 线 **225** 个被封格）；
   ⇒ 巴士行只剩 **rows 35/36/37**（3 行）⇒ **11 条 In5 线挤 3 行 = 鸽笼无解**（首 3 条线取走后，第 4 条起必然耗尽）。
3. 附带更正 R559.1：**上升梯列 c 必须递减**（c 递增 ⇒ 他线腰带行 `R_j` 会与他线上升梯列 `c_i` 相撞）；
   `c` 递减后"入口叠套律 `R_i > s_{i+1}`"**根本不存在** ⇒ R561 的"11 线/层不可行"与 R561/R562 的 8/8 层重发**均无必要**。
