## 一、Plan（人类工程师路径 · 大白话）

### ① 信号怎么走
K2 主芯片是 **16-lane 中继（TI DS320PR1601 ×2）**。16 条差分通道从芯片出来 → **穿板中央的墙缺口** → 到两个下接插座。每条线必须**从哪个墙缺口过墙**，就是「出口注册」；而**成组怎么排（哪四条一组、谁和谁左右对照、在哪一层换层、逃逸带怎么分）**，就是**分叉段的物理布局**。

### ② 挡路的是什么
- **不是地方不够**：R537 全量计数，最紧断面**容 40 vs 需 3（余 +37）**；
- **不是单条线画不了**：16/16 单线级均可独立画通；
- **不是手法不够**：我已试四支规则（已注册开口内 8/16 · 包络内挪门位 8/16 · 厂商 A 单调/B 反向 7/16 · flow-through 8/16）；
- **真挡路的是**：**我拿不到「这张板子到底该怎么排」的那张图**——
  厂商文档（SNLA425A / SNLU300A）**只给寄存器与通道分组语义**；**EVM 的板布局是「图」（Fig 4-1/4-2），无可抽文本**；**EVM 设计归档公开直取是空壳页（要登录）** ⇒ **「怎么排」这一步在可得资料里没有可机核的形态**。
