## 一、机读到的布局事实（不是"已读"，是逐条观察）
1. 交换芯片在板中央；扇出 = **一束束平行直走线**从 BGA 射向各连接器。
2. **每个连接器独占一束**、等间距；束间是大片空白。**没有任何"共享单列走廊"、没有任何断面槽位排班**。
3. 一束线只在**最后几毫米**做浅 s 弯进连接器焊盘场；长段是直的。
4. **换层在扇出处一次完成**（过孔簇紧贴 BGA 外圈），**不推迟到远处的共享行**。
5. 分叉（5×16/10×8/20×4/40×2/80×1）在成品里是**芯片配置（SBR/STRAP）属性**，不是布线形状。

## 二、抄什么 / 怎么套（落到具体做法）
| 成品观察 | 套到 K2（尤其 OUT0_P / OUT6_N） |
|---|---|
| 一连接器一束、等距、长段直、只在焊盘场 s 弯 | 尾段 = **一线一通道**，从腰带直走至**本线自己的焊盘场**；线距 = 束距，**不是共享网格行** |
| 束与束只需**不重叠** | 出口槽规则 = **互异（同层不共用格）**。成品**没有**"出口之间留 2 格"这种东西 |
| 换层在扇出处**一次**、在**本线自己的列**上 | 入口换层要**显式声明**（K2 自己的在册 SPEC 已声明：`OUT3_N/OUT5_N/OUT6_N` = `In5_entrance`；COMB 起线者 = `DIVE_via`） |
| 进焊盘场走**连接器自己的扇出列** | `OUT0_P`（东组，B 焊盘 ≈ col 131 / row 4）应沿**本线自己的列**进焊盘场；K2 的"gate row 36"是**K2 内部构造**，成品无对应物（成品不会先挤到共享行再纵走 33 行） |

## 三、具名结论
成品对这 2 条线只给出**一条**尾段规矩：**一线一通道 + 扇出处一次换层 + 不重叠**。
成品**不支持**"出口槽 ≥2 格"，也**不支持**"把换层点推离本线所在列"。
⇒ 这是对 R634《出口间距规则出处鉴定》的**成品侧独立佐证**（两条证据链同向）。
