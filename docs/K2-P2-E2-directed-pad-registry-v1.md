## 0. 口径瑕疵订正（对已交 E2 基线的更正）

已交 E2 基线表（`J2`43/74/74、`J3`25/38/38、`J4`25/38/38、`U1`27/33/33、`U2`6/8/8）中的**符号侧数字是「唯一 pin 名数」**，

**本件改用 pin number 集**比对，逐件实测如下。

## 3. `J3`/`J4` 对应关系证明（38/38，非默认假设）

约定 `pin i → A((i+1)//2)`（i 奇）／`B(i//2)`（i 偶），对 `J3` 逐脚比对「符号侧该网名」与「板该 pad 网名」：
**命中 38 / 不符 0**。样例：`pin3 RX0_P → A2 = PCIE_DN_OUT0_P_MCIO`；`pin4 TX0_P → B2 = PCIE_UP0_P`；
`pin9 RX1_P → A5 = PCIE_DN_OUT1_P_MCIO`；`pin10 TX1_P → B5 = PCIE_UP1_P`。
⇒ `J3`/`J4` **无余量焊盘**；登记项 = **「符号顺序号 ↔ 封装 A/B 位号」对应关系本身**（源侧应显式化，防静默）。

> 注：`J3`/`J4` 各有 4 个 NC pad（`A8`,`B8`,`B9`,`B12`）板上网为 `NO_CONNECT` 而源侧无网条目 ⇒ 对应关系判定按「未连接等价」处理（M-17「NO_CONNECT 建成真实网」同族，已登记）。
