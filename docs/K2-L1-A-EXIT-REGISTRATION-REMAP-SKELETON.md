## 1. 本支动的与不动的

| 项 | 是否变动 |
|---|---|
| **16/16 需求** | **不变** |
| **pad-to-pad 接口 / 连接器 / BGA 球映射 / 信号流向** | **不变** |
| **墙缺口物理开口（开口几何本体）** | **不变**（承 #K2-278 附加硬护栏：不搬/不增/不删） |
| **冻源本体** | 不动原件；**仅以版本 bump 落「出口注册修订版」新件**（SPEC 派生件） |
| **变动项 = 唯一** | **「每条线从哪个注册门过墙」的语义**：东组按成品范式**成组镜像重定**（注册网格上，量级 ≤ 21 列 / 29 行，承 R710 实测） |

## 2. 映射表结构（批准后逐行填值 · 一次确定性成表）

| 列 | 含义 | 取值来源 |
|---|---|---|
| `lane` | 线名（16 行） | R613 在册表 |
| `group` | 组（东组/西组 · 按注册分组） | 在册 `grp` |
| `pn_pair` | P/N 对 | 在册 |
| `exit_gate_registered_old` | **现**注册出口门（层, 格） | R613 |
| `exit_gate_mirrored_new` | **拟**成组镜像出口门（层, 格） | 成品范式（REF-CASE-LIBRARY §A.1） |

| `invariant_check` | 16/16 · pad-to-pad · 连接器 · 球映射 四项「不变」核对 | 机器核 |

## 3. 批准后的交付链（预计 2~3 窗）

1. **「出口注册修订版」新件**（SPEC 派生 · 版本 bump · 附上表 ＋ 冻结四源逐条距离核算）；
