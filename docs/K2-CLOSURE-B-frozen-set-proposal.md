## 3. 改冻结集提案骨架（**先证后动**）

**提案**：**墙缺口开口集修订**——按分叉范式**成组有序重排**（对称门对：W `7↔28 · 11↔24`；E `115↔135 · 117↔133 · 119↔131 · 125↔125`），**新增 5 处**缺位开口（W rows **23/22/20/16**、E col **123**）以补全镜像对；**物理开口本体变更 = 待 owner 批**。
**守恒核算（复用 R537 方法）**：对修订后开口集重跑 156 断面全量计数，出具 `capacity_upper_bound ≥ demand` 对照表（证明不改出容量墙）。
**预检验证计划（PRECONDITION · 证不过就不动）**：
1. **P-a** 以「修订后注册」为输入，跑 **一次**认证表（域=1 · 零搜索）；
2. **P-b** 全通（附可行见证）⇒ 方**申请落开口修订**；仍阻断 ⇒ **修订不成立、本提案撤回**；
3. **P-c** 全程**不动物理开口**（P-a/P-b 在模型内完成），落开口仅发生在 P-b 通过**并经 owner 批准**之后。
