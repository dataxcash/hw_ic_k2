## 2. 方法（工具 `k2_p4_pdn_stitch_v1.py`）

1. 判定过孔**已连接层**（几何口径：同网线段与之相接 / 孔位落在同网**已填**平面内 / 同网焊盘）。
2. **只在未连接的层**找同网接点，三类候选：
   - **平面**：自孔心沿 8 个 0/45/90° 方向**射线行进**（整数轴向偏移、0.01 mm 步长；对角真实距离 = a·√2），
     取**首个落入同网已填平面**之点 ⇒ 天然单一合法腿；
   - **同网线段**：点到线段的最近点（可 T 接）；
   - **同网过孔 / 焊盘**：几何最近点。
3. 孔心→接点用 **≤2 段 0/45/90°** 路径（任一段 ≥0.05 mm，红线）；按长度升序（同长优先内层平面）。
4. 逐案「改板 → `ZONE_FILLER` 重填 → `kicad-cli` DRC 复算 → 不合格即回退」；复算闸**复用 W-7 `delta_ok`**
   （①无新类型 ②无类型条数增量 ③error=0 ④`unconnected`=0 ⑤总量严格下降）。**只写 work-dir。**
