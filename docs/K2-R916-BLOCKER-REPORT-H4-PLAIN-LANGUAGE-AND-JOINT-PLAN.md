## 一、① 信号怎么走（大白话）

> 板子右下角那两条 PCIe 下行线（`PCIE_DN4_N`、`PCIE_DN5_P`）是**从中间的转接芯片出发**的：
> **先在中层（In2）竖直往下钻** → **到底部通道带后换到 In5 层、沿板底横着往东跑**（约 48mm）→ **在板右缘附近掉头** →
> **再换回 In2 层竖直往上爬** → **落到 J2 连接器那一排焊盘上**（y≈59.5 / 60.3）。
> 两条线天生不等长，靠**同伴那条线上的蛇形**补长度，使一对两根等长。

## 二、② 挡路的是什么（大白话）

> **右下角那颗安装孔（H4）周围 3mm 不得有铜**（6×6 禁区）。这两条线**掉头+上爬的那根立柱就站在禁区里**（x=139.48 / 138.32，必须 ≤137.6537）。
>
> 想把它挪出去？**它西边那条带子已经被「上行线」占满了**——J2 那一排是**上下行交替**的，
> **上行的着陆立柱/过孔就插在下行立柱之间的每一格**（全板共用同一张 0.58mm 的 x 栅格：135.0 / 136.0 / 136.58 / 137.16 / 137.74 / 138.32 / 138.90 / 139.48）。
> 所以**不是「角上做不出来」，而是「只挪下行、不动上行」做不出来**。

## 三、③ 人类方案是什么（大白话）

> **老工程师不会一根一根推线，而是把右缘这条「柱栅格」整体重排一次**：
> **下行四根一起让位、同时把上行那几根算进去**，允许下行**跨到上行之间/以西的空格**里（已量出空格确实存在——见下），
> 然后**把两根蛇形重新调好**保持等长。
> **一句话**：这是**「重排柱栅格」**，不是「推线」。

## 四、卡点三问：试过什么 / 为何不通 / 缺口在哪层
