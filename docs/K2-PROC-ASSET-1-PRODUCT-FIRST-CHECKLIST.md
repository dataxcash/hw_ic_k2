# K2 · 工序资产 ①《立项即成品对照》前置工序（v1 · 关闭能力账 C6/C9「前置待装」）

> 依据：#K2-295 §五（停等期造活绑带）＋ #K2-282 §一（设计权威=成功案例）＋ #K2-283 §二.2（主锚=本板主器件厂商件）＋ #K2-295 §七（C6：登记阶段缺「业界成品对照」前置）。

## 1. 适用对象
**任何「出口/穿行/开口 登记件」在冻结（入库为在册输入）之前。**

## 2. 前置工序（缺一 fail-closed ⇒ 不受理）
| # | 必附项 | 要求 |
|---|---|---|
| P1 | **本板主器件**具名 | K2 = **TI DS320PR1601**（×2 中继）；**异型芯片（如 PEX88096）只能作「行业范式佐证」**，不得作主锚 |
| P2 | **厂商件出处** | 文档号 + **页码/图号** + **公开 URL** + **sha256[:16]**（本地留档）；机核可复跑 |
| P3 | **逐行厂商对照列** | 每一行登记项须写「本行依据厂商件的哪一条/哪一页」；禁占位、禁空 |
| P4 | **参考件适用性预检结论** | 见工序资产 ②；须写明「类别匹配／区分性机制是否被在册预算封死」 |
| P5 | **不变量声明** | 需求数（16/16）· pad-to-pad · 连接器 · 球映射 · 物理开口（0 改动，除非另获批） |

## 3. 逐行厂商对照列（模板）
```
lane / 登记项 | 本行规则依据（厂商文档号 §页/图） | 主器件锚（必填） | 参考件类别 | 适用性结论 | 备注（不可辨项）
```

## 4. 关闭判据（§22§3 · 硬）
**资产（本件）＋ 同类回归件 PASS**。回归件 = **下一份新登记件必须带「本板主器件厂商对照列」（P2+P3）**；**无列 ⇒ fail-closed 不受理**。**口头「已改进」不算关账。**

## 5. 反面教训（在册）
- 本 K2 的登记冻结**早于**任何成品对照 ⇒ 现注册与业界范式**系统性相悖**（#K2-280 §一 #6/#7）；**发现太晚**即为 C6 的代价。
