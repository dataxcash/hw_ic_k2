## 一、§20 成品三问（①同类成品 ②可抄件 ③差异清单）

**① 同类成品**：**TI DS320PR1601 EVM**（`REF-SNLU300-DS320PR1601RSCEVM-UG.pdf` · 层图 `REF-DS320PR1601EVM-Fig4-1-TopLayer.png` / `Fig4-2-BottomLayer.png` · 在册）＋ 厂商 datasheet `SNLS683`／编程指南 `SNLA425 §1.1`（`REF-CASE-LIBRARY §A1`）。

**② 可抄件（EVM 框架事实 · 视觉观察 · 只描述所见）**：

| 框架要素 | EVM 事实 |
|---|---|
| **主芯片位** | **居中**（`U1` 长方形 BGA 位于板中央区域） |
| **高速连接器位/朝向** | **单边**（**下缘**）· 水平长条 · 多引脚并行 |
| **安装孔** | **四角**（左上/右上/左下/右下） |
| **外围分区** | 左：电源/接口（HSDC111 区）＋ 跳线 JMP1–4；右：EEPROM/控制（I2C 控制器）；**芯片周圈**：阻容外围 |
| **信号流向** | **自 U1 扇出（放射状）→ 下缘高速连接器**，整齐并行（**扇出范式**） |
| 不可辨 | 无（图面清晰） |

**③ 差异清单（EVM 框架 vs K2 现框架）**：

| 要素 | EVM（成品） | K2 当前（l10/l12） | 差异 |
|---|---|---|---|
| 主芯片位 | **居中** | `U6 (93.8,53.7)`＝**偏右** | 需**居中化** |
| 高速连接器 | **单边下缘** | `J2` 在**右缘** | 边位／朝向**重立** |
| 安装孔 | **四角** | `H1 4.67 / H2 7.49 / H3 22.50 / H4 28.62`（**均非角位**） | 需**四角化** |
| 外围分区 | 电源/接口 vs 控制/存储**左右分置** | 左簇（`U1/U2/U4/U5`）**偏上过密**（R3 FAIL） | 需**分区重排** |
| 流向 | 扇出→下缘 | 右侧汇入 `J2` | 随连接器边位**重立** |

## 三、框架重导出（提案 · **不触 L1**）

以 EVM 框架为蓝本映射到 K2 板框：**① 主芯片居中** ② **高速连接器改单边（下缘）并与芯片扇出对齐** ③ **孔四角** ④ **外围左右分区**（电源/接口 vs 控制/存储）⑤ **扇出流向**。
**L1 红线（禁触）**：需求／接口／信号流向语义／球重映射 **不动**；**仅动"框架几何（器件位／朝向／孔位／分区）"** ⇒ 属 **L2**（布局/机械 = ENG 自治），但**连接器边位变更须复核是否触及接口定义**（若触及 ⇒ 停手具名升监理）。
