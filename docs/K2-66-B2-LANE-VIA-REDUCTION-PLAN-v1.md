# K2 · B2 高速线过孔 ≤2/线 —— 执行计划（#K2-66 §六④）

## 一、实测（l8 = 受审板）
- 高速网 = **32 条 PCIE 车道**（`PCIE_UP_OUT0..4_P/N_J2` · `PCIE_DN_OUT0..7_P/N_MCIO`）+ 2 REFCLK。
- **每车道 = 4 via**（via 层 span 实测：`F.Cu-In2.Cu` ×1 · `In2-In5` ×1 · `In5-B.Cu` ×1 + 1 冗余/入口）。
- 车道走线层 = F.Cu(945 段) · In2.Cu(32) · In5.Cu(870) · B.Cu(43) ⇒ **层序 F→In2→In5→B**。
- 阈值 = **≤2 via/线**（强条 R1-5/R5-1）⇒ 当前**每条超 2**。

## 二、可达性
- 车道须自 `U6`（354-ball BGA）扇出至 `J2`（金手指）/`J3`/`J4`（MCIO）。
- ≤2 via ⇒ **至多 2 次换层**：可选层对 **(F,In2)**、**(F,B)**、**(In2,In5)**、**(In5,B)**。
  例：扇出 F → 1 via → In2 走全程 → 1 via → 落 J2/J3/J4 焊盘；或 F → B（2 via）。
- **约束**：85Ω 差分（宽/间距按 SPEC `impedance.width_mm_by_layer`）· 参考面完整性 · 既有盲/埋孔 span 类不得新增
  · DRC 全绿 · canonical 19 维不回归。

## 三、执行（唯一串行）
1. **输入** = l9 板（含 A1–A8/B1/C1 已修）。
2. **布线器** = 项目多层迷宫布线器 `k2/tools/k2_p4_mroute_v1.py`（span 感知 · 逐段 `seg_exact` + 逐孔 `via_exact` 放行闸）；
   新增 **via 计数约束**（每网 ≤2）或对 32 车道逐一 `--only-net` 重布。
3. **验收**：`k2_layout_quality_check_v1.py` B2 行（32 车道 hist 全 ≤2）· kicad-cli DRC 全绿（含差分阻抗/长度）· 19 维不回归。
4. **不作弊**：不得放松 3W/阻抗/DRC 下限；不得以删网/断线换 via 数（19 维 `unconnected_zero` 兜底）。

## 四、状态
- 本件 = **计划 + 实测依据**；实际重布线**未执行**（须先定 l9 之内层策略，且属大规模布线改动）。
- 依 #14③：**非「可能/待定」** —— 路径、工具、约束、验收均已具名；执行 = 下一步（R108 续）。

## 五、单车道拓扑实测（2026-09-21 · R108 续 · `PCIE_UP_OUT0_P_J2`）

| # | via 位置 | span（首三） | 角色 |
|---|---|---|---|
| 1 | (84.85, 54.88) | F.Cu… | **U6 侧扇出**（BGA escape，F→内层） |
| 2 | (141.22, 42.65) | F.Cu…In2.Cu | **J2 侧进入**（→J2 焊盘 F.Cu） |
| 3 | (141.22, 56.83) | In2.Cu… | **换层**（In2→In5） |
| 4 | (84.85, 56.83) | B.Cu… | **U6 侧换层**（In5→B） |

- 走线层分布：**F.Cu 18 段**（主走线）· In2/In5/B **各 1 段**（短跳）。
- 结论：车道 = **F.Cu 长走 + 3 处短跳换层** ⇒ 有 **2 个 via 属「短跳」冗余**（#3/#4），可用
  **同层绕行**消除；保留 #1（BGA escape，bump 不可同层扇出）+ 1 个进入 via ⇒ **目标 2 via/线可达**。

## 六、消除策略（拟）
1. 对 32 车道逐一：识别「短跳 via 对」（两端段长 < 2mm 且同层可续）⇒ 尝试**同层重连**（删 2 via）。
2. 若同层绕行不达净距/3W ⇒ 改用**相邻层对**（In2/In5）整体迁移该短跳。
3. 逐网 `--only-net` 用 `k2_p4_mroute_v1.py` 重布短跳段；**保留** BGA escape via。
4. 验收：B2 hist 全 ≤2 · kicad-cli DRC 全绿（含差分阻抗/长度/3W）· 19 维不回归 · `unconnected_zero`。
