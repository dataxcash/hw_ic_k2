# K2 · B2 高速线过孔 ≤2/线 —— 执行计划（#K2-66 §六④）

## 一、实测（l8 = 受审板）
- 高速网 = **32 条 PCIE 车道**（`PCIE_UP_OUT0..4_P/N_J2` · `PCIE_DN_OUT0..7_P/N_MCIO`）+ 2 REFCLK。
- **每车道 = 4 via**（via 层 span 实测：`F.Cu-In2.Cu` ×1 · `In2-In5` ×1 · `In5-B.Cu` ×1 + 1 冗余/入口）。
- 车道走线层 = F.Cu(945 段) · In2.Cu(32) · In5.Cu(870) · B.Cu(43) ⇒ **层序 F→In2→In5→B**。
- 阈值 = **≤2 via/线**（强条 R1-5/R5-1）⇒ 当前**每条超 2**。

## 二、可达性
- 车道须自 `U6`（354-ball BGA）扇出至 `J2`（金手指）/`J3`/`J4`（MCIO）。
- ≤2 via ⇒ **至多 2 次换层**：可选层对 **(F,In2)**、**(F,B)**、**(In2,In5)**、**(In5,B)**。
  例：扇出 F → 1 via → In2 走全程 → 1 via → 落 J2/J3/J4 焊盘；或 F → B（2 via）。
- **约束**：85Ω 差分（宽/间距按 SPEC `impedance.width_mm_by_layer`）· 参考面完整性 · 既有盲/埋孔 span 类不得新增
  · DRC 全绿 · canonical 19 维不回归。

## 三、执行（唯一串行）

2. **布线器** = 项目多层迷宫布线器 `k2/tools/k2_p4_mroute_v1.py`（span 感知 · 逐段 `seg_exact` + 逐孔 `via_exact` 放行闸）；

## 八、结构性结论（2026-09-21 · R108 续 · 决定性）

### 8.1 板与 SPEC 的层系实况
| 项 | 实况 |
|---|---|
| **板（l8/l9）** | **8 铜层**：F / In1 / In2 / In3 / In4 / In5 / In6 / B |
| 平面层 | In1=GND · In3=GND · In4=POWER(12V_IN/MCU_VDD/P3V3/P3V3_AUX) · In6=GND |
| **信号层** | **F · In2 · In5 · B** |
| SPEC `stackup` | 记 **6L**（JLC 6L · F/In1/In2/In3/In4/B）· `in2_crossing_nets`：『**In2** 双 GND 参考带状线 · crossing_pairs=16』⇒ **SPEC 原意 = 车道 crossing 走 In2** |
| SPEC `vias.high_speed` | `max_per_line: 2` · 口径原文『**每线 ≤2 过孔 = 单次换层 (F→In2→F)**，每对差分 4 过孔』 |

### 8.2 车道现状与 via 数之结构成因
- 车道层分布：**F.Cu 945 段 · In5.Cu 870 段（长走）· In2.Cu 32 段 · B.Cu 43 段**。
- 单车道路径（实测 `PCIE_UP_OUT0_P_J2`）：**F →(via) B →(via) In5 [长走 56.4mm] →(via) In2 →(via) F** = **4 via**。
- **成因（结构性）**：本板换层 span 类 = **{F–In2, In2–In5, In5–B}**（HDI 盲埋）⇒
  **F ↔ In5 无直接 span ⇒ 必 2 次换层**；车道长走若在 In5，则 F→In5→F 两次跨越 = **4 via（不可降）**。

### 8.3 达 ≤2 via 的唯一结构路径
- **长走改置 In2** ⇒ **F →(via) In2 [长走] →(via) F = 2 via**（**唯一**可行拓扑，且**正是 SPEC 原文口径**）。
- **合规性**：In2 夹于 **In1(GND)/In3(GND) 之间 ⇒ 双参考带状线**（SPEC 原文即如此描述）⇒ 85Ω 差分参考完整；
  线宽按 SPEC `layer_plan.in2_width_mm = 0.205`。
- **代价/风险**：In2 现载 298 段 / 1417mm（含 **MCU_VDD 61 段**、16 条 crossing stub、REFCLK）⇒
  32 条车道长走改置 In2 **需要 In2 容量与拥塞评估**（若不足 ⇒ 需腾挪/分层平衡）。
- **替代方案（不采纳）**：新开 **F–In5 直接 span** = 改工艺/孔策略（#K2-66 未授权；且触 JLC HDI 叠孔规则）⇒ **不采用**。

### 8.4 结论
- **B2 非不可行，且有 SPEC 依据的确定拓扑**：**F→In2→F（2 via）**。
- 执行 = 32 条数据车道**长走由 In5 重布至 In2**（`k2_p4_mroute_v1.py` 或等价 · 守 0.205mm/85Ω/3W/伴行 GND/背钻），
  验收 = B2 hist 全 ≤2 + DRC 全绿 + 19 维不回归。
- **下一步（ENG 续）**：先做 **In2 容量/拥塞评估**（能否容纳 32 车道长走），再决定重布批。

### 10.1 §8.3「长走改置 In2」= **不可行**（原判有误）

§8.3 断言『唯一拓扑 = 长走改置 In2 ⇒ F→In2→F（2 via）』，但**未核 In2 在原锚点处之可达性**。实测（必要条件探针：32 车道全部 A/B 锚孔计入障碍 · 精确净距栅格化）：

| 层 | 通过必要条件 | 失败 | 失败态 |
|---|---|---|---|
| **In2.Cu** | **10/32** | **22/32** | 车道 U6 侧 A 锚（F–B 孔位）落于 **≤743 cell（多数 3–93 cell）** 之孤立自由域 |
| **B.Cu** | **29/32** | 3/32 | `DN_OUT0_N/P` B 锚落 11456-cell 孤岛 · `UP_OUT0_P` A 锚仅 2 cell |

**根因（具名）**：U6 扇出区为 **BGA/缝合孔墙** —— `P3V3` F–B 缝合孔排（y≈54.0 · **0.5 mm 栅距 · 21 孔**）= 实心墙；`GND` F–B 缝合孔排（y=53.0 等 · 1.2 mm 栅距）与车道自身 A 孔排（y=51.423 / 52.366 · 行距 0.943 mm）叠加 ⇒ In2 上通行所需中心距 `VIA_R+hw+req = 0.43 mm` 使**行距 0.943 < 2×0.4525 = 0.905…1.30** 之相邻行**无缝可穿**。

⇒ **SPEC `corridors` 之 In2 走廊意图在本版板上不成立**（该走廊需 In2 自 U6 扇出可达）。

### 10.2 唯一有可能之路径 = **B.Cu**（F→B→F · 2 via）

- `B.Cu` 为 SPEC 已定义之 PCIe85 信号层（`impedance.per_layer.B.Cu` · 微带 · ref=In6 · w=0.205 · gap 0.295/0.395）。
- 必要条件 29/32 通过 ⇒ **B.Cu 是本板唯一可能的 ≤2 via 落点**。
- 仍缺：① 3 条线之锚点须移（⇒ 触其 F 扇出/蛇形等长重调）；② 32 车道 B.Cu 重迁须**拥塞感知布线器**（v1 朴素 A* 仅通 8/32，且系**顺序级联**失败 —— 非结构性，见下）。
- 阻塞他网（须 ECO 方可清走廊）：`I2C1_SDA`(B.Cu y=50.438/x 62.8–68.6 + y=51.138/x 69.3–82.0) · `PERSTA#`(45° 斜线) · `P3V3_AUX`(45° 斜线) · `DS320_STRAP_*` · `PWR_BTN_ISO`。

### 10.3 本会话 v1 布线器实测（B.Cu · 32 车道）

- 结果：**8/32 通**（`DN_OUT1/2/3` 各 P/N + `DN_OUT4_N` + `DN_OUT5_N`），24/32 `NO_PATH`。
- 判读：**非结构性失败** —— 先通之 2 条（`DN_OUT4_N`/`DN_OUT5_N`）取**绕板南缘 y≈70** 之超长迂回（>100 mm），吃掉后续车道走廊 ⇒ 级联失败。**瓶颈 = 布线顺序与拥塞代价**，非几何不可达。

### 10.5 **§10.3 判读更正**（同日 · 单车道路由实测 → **瓶颈容量**主导，非仅顺序）

> 更正动机：§10.3 曾判 v1 失败『**系顺序级联 · 非结构性**』；**单车道路由实测推翻该判读**。

- **单车道路由（`--only <net>` · 板上无其他车道新走线）实测**：
  - `PCIE_UP_OUT0_P_J2`：**OK** · 余量 **0.02 mm**（blocker `GND`）· 路径 = A(84.8,54.9) → 西折至 **x=83.5** → 北上 → 45° 东北至 y=44.2 → 东行 → B。
  - `PCIE_UP_OUT3_N_J2`：**OK** · 余量 **0.00 mm**（`GND`）· 同经 **x=83.5** 窄口。
  - `PCIE_DN_OUT4_N_MCIO`：**OK** · 余量 **0.02 mm**（`MCU_VDD`）。
- **判读**：单车道路由**只能挤过余量 0.00–0.02 mm 之「单车道宽」窄口**（如 x≈83.5 之 U6 孔墙缝隙）。⇒ 失败主因为 **瓶颈容量**（16+16 车道争用同一批单车道窄口），**非单纯顺序**；顺序仅是**次因**（不同顺序会改变哪几条通）。

- 因此 §10.4 之 (a) 除『拥塞感知布线器』外**必须**含『**腾挪他网走廊**』（否则窄口容量不足）；(b)/(c) 不变。

**根因（解析）**：U6 扇出内 32 条车道之 **A 锚（F–In5 过渡孔）列距 0.6mm · 行距 0.943mm**；
一条 In5 走线穿越两枚相邻锚孔需 **0.86mm**（0.43+0.43，`0.43 = r_via 0.175 + hw 0.08 + req 0.175` 为探针语义之硬几何）
⇒ **锚孔之间无通道**；仅可经**行间缝**逃逸，而 0.943mm 行缝之可用自由宽 ≈**0.08mm** ⇒ **每缝仅容 1 条**（2 条需 1.195mm）
⇒ 逃逸容量 ≈ 行缝数 ⇒ **远小于 32**。（= #K2-68 §2.1/§10.9「锚孔笼」判读之**独立复现与扩大**：笼不止缝合孔，**含车道自身锚孔**。）

**含义**：
1. 若坚持「长走零改层」之字面最小改动，则 In5 路径**不可能达 32/32**；
2. 欲走 In5 ⇒ 必须**先做完整版锚孔笼重构**（重排 32 条车道之 A/B 过渡孔位置以扩开逃逸通道 ⇒ 牵动 F 侧扇出与等长）——
   即 #K2-68 §2.4(a)-2「锚孔笼重构（**不止 3 锚**）」之**完整化**；
3. 该项属 **L2**（走廊/过孔策略/叠层使用 = 监理自裁面），但**路径取舍建议监理复裁** ⇒ 已递 `PENDING_RULINGS_DELTA_20260921_v38.json`（owner 项 = 0）。
4. **不阻塞**：ENG 继续做**只读**之锚孔重构可行性设计。
- 证据：`K2_68_R2I_IN5_SUFFICIENCY_FAIL_ANCHOR_CAGE_CAPACITY_20260921_v1.json`。
