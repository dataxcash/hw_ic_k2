## 一、Plan 三问（人类工程师路径 · 大白话）

**① 信号怎么走**：
A 焊盘（西侧梳齿里的球）→ **自己口袋**里下钻到**自己的竖井**（列 `d`）→ 沿**自己那条腰带行**（行 `H`）一路向东 → 过 **col60 断面槽位**（同一行继续）→ 到**墙前** → 沿**自己的竖列**纵取到**自己那个墙缺口行** → **穿墙缺口** → 到出口槽 → 到 **B 焊盘**。
要害：**中段与尾段共用同一条腰带行 `H`**；**墙只能在各线自己的缺口行穿过**。

**② 挡路的是什么**：
- **不是**板子没地方（守恒余 **+37**；行/列容量都够）。
- **墙带**（col ≈114–119）**在绝大多数行被封**，只有各线自己的缺口行能穿（R571-F5 机核：西组缺口行 = 各自 `exit_row`）。
- **耦合**：中段腰带行必须**同时**满足"口袋→col60 全合法"与"col60→墙前全合法"。
- **东组出口槽都挤在 row 36**（`(114,36)` 是墙）⇒ **一行只能服务一条**；东组须各自分行（墙东 **16 列 120–135** 可用，F3 机核）。
- **我方工具侧**：把"一条行/一条列硬贯通"当唯一写法（四连窗失败）；另有**两处脚本补丁作用域错**（连错 2 次的直接原因）。

**③ 人类方案（大白话）**：
**别指望一条直线走到底。** 让每条线**沿自己那条腰带行向东**，到**自己那个墙缺口**再**拐弯穿过去**——各行、各缺口，互不相抢。
拐弯段**不用直线**，用**"走廊"**（宽一点的路带，锚点间距 ≤20 格、带宽 ±6）：**由已验证的填充器在走廊里自己绕障**（硬预留、单遍、不回溯）；我们只把走廊的**入口 / 拐点 / 出口**标死。这与在册已验证的"入口前缀"同型（`fails=0`）。
