# ECO 文书链（宪章 v2 附件 · #K2-357 立 · 即刻生效）

> owner 根因判定：**「agent 发令给 agent ＋ JSON 盖章」不是工程流程**。文书链缺位是所有「说了没做／做了没证」的温床。
> **铁律：任何布局/网表变更，无 ECO 不许动板。缺一环即停线。**

## 一、五环（逐环留档 · 单号受控）

| 环 | 文书 | 内容 | 闸 |
|---|---|---|---|
| 1 | **ECO 变更单** `ECO-K2-NNNN-*.md` | 改什么 · 为什么 · **影响网清单（逐条网名）** · 受影响文档 · 回滚方式 · **验收判据（数字）** | 无 ECO ⇒ **禁动板** |
| 2 | **施工方案**（ECO 内 §7 或附件） | 拆线清单 · 重布方法与顺序 · 风险 | **方案批准才许出图**；驳回须**具名哪条不成立** |
| 3 | **施工图** | 按**批准的方案**出 · 逐网走线图 · **图与方案逐项对号** | 图不对号 ⇒ 打回 |
| 4 | **过程质量记录** | 每步判据＋读数＋时间＋执行者（含判卷表读数） | 无记录 ⇒ 不收 |
| 5 | **施工** | 照图施工（连连看 · **禁现场找路** · 承 #K2-232 图纸纪律） | 现场找路 ⇒ 停线 |

## 二、监理依据 = **对单式**（ECO-方案-图-实物 **四单一致**）

- 监理逐环核：**变更单有没有 · 方案批没批 · 图与方案对不对号 · 实物与图一致不一致**；
- 任一环缺失或不一致 ⇒ **停线打回**，**不受理后续任何件**；
- **判卷表随 ECO 预先锁定**，事后按表读数（不得事后改表）。

## 三、本目录

- `REGISTER.md`：受控单号总表（**唯一事实源**）；
- `_TEMPLATE-ECO.md`：模板（**必填字段即机器闸**，见 `tools/k2_eco_form_check_v1.py`）；
- `ECO-K2-NNNN-*.md`：各单。
