# K2 · 工序资产 ④《交付件离线跑通前置闸》（v1 · 关闭能力账 C13）

> 依据：#K2-309 §一.5（登记 C13「交付脚本以交付件身份在飞试错」· 补法＝本资产）＋ §四（「下一窗必须见资产」）。
> 适用：**任何以「交付件」身份提交的脚本/生成器**（出图/认证/证书/登记类）。

## 1. 三道闸（缺一 ⇒ 不受理为交付件）

| 闸 | 动作 | 判据（可机核） |
|---|---|---|
| **S1 离线 smoke** | 在**非交付件**的临时口径上，用**小例**（1–2 线/子集）把**全码路**跑通（构造→判据→出件格式） | 小例一次跑通；失败只许改**离线**脚本 |
| **S2 冻结** | 把脚本**定稿落 `k2/`**（此后**只读**） | 落库 hash ＋ 时间戳 |
| **S3 恰一次执行** | 冻结脚本**恰跑一次**，直接产出交付件 | rollout **单次执行**可核；件内 `construction_runs=1` |

## 2. 硬规则

- **在线改脚本 ＝ 未出件**：一旦对在册交付脚本作任何编辑，该轮**作废**，须回到 S1。
- **禁改参重跑**：同脚本同参 ≥2 次即违规（宪法第八章 §8）。
- **件内自证**：交付件须带 `construction_runs`、生成器 hash、执行时间戳，供 rollout 复核。

## 3. 与既有资产的关系

- 资产①《立项即成品对照》（C6/C9）· 资产②《参考件适用性预检》（C9）· 资产③《整版分配 SOP》（C7）**不变**；
- 本资产 **④** 只管**交付纪律**（何时才算「出件」），与前三者**正交**。

## 4. 关闭判据（§22§3 · 硬）

**资产（本件）＋ 同类回归件 PASS**。回归件 = **下一份交付脚本：离线跑通后恰一次执行**（rollout 单次可核）。
**口头「已改进」不算关账。**
